# Retired GitHub Pages delivery

GitHub Pages is intentionally disabled for `mekhovov/revealline`. Do not deploy,
retry, dispatch, validate, or troubleshoot a Pages publication from this repository.

The repository still preserves source, releases, tags, artifacts, and historical
publication records. They are evidence and download history only; none authorizes
or requires a Pages deployment. Use the normal source validation and release
artifact workflows where applicable, but never treat a Pages URL, Pages capacity,
or a Pages environment as a release or merge gate.

If public browser delivery is required in the future, establish a separate hosting
decision and add its workflow, credentials, review criteria, and verification in a
new, explicitly reviewed change. Do not revive the removed Pages workflows or
assume a private repository can serve a public Pages site.
