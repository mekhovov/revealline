# P00 asynchronous entry and loading baseline

Inspected source: `9a9fc8f7a3c129a8e2c4fbfd2caef27056a25554` (P00 candidate v0.55.0). This is a source-only inventory, written after that candidate commit. It does not report throttled browser journeys, measured first paint, cancellation experiments, or physical-device acceptance. No P01 runtime changes or tests accompany it.

The inventory follows player/admin entry points into asynchronous work rather than counting every internal `await`. Shared hashing, decoding, storage, replay verification and download helpers are grouped with their callers. Build/CLI production tools are outside the player loading contract. The ordinary runtime, direct authoring routes, imported content, and both Couch routes are included. Repeat the entry-point search against the exact P01 candidate; later features must join this inventory.

## Reading the findings

- **Present:** a source-visible status is written before work and useful ownership guards exist. This still needs delay, cancellation, focus and responsive verification.
- **Partial:** feedback exists but lacks a meaningful phase, a reachable cancellation/recovery action, or an adequate connection to the activating control.
- **Gap:** the inspected operation disables controls or waits without writing a new loading state at that entry point.
- A missing UI cancellation affordance is separate from missing stale-result protection. Several operations correctly discard obsolete results but cannot stop the underlying fetch/decode.
- A completed durable write cannot be described as cancelled or rolled back. Existing transaction/coordinator semantics remain authoritative; P01 must display the actual outcome.

P01 implementation owners below are feature slices, not new release phases. `P01/boot`, `P01/flight`, `P01/presentation`, `P01/content`, `P01/data`, `P01/offline`, `P01/studio`, `P01/media`, `P01/replay`, `P01/couch`, and `P01/tools` must be accepted together before P02. Sound intent/authority remains P02; catalogue redesign remains P06; map/art parity remains P08-A.
