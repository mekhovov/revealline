# Navigation research follow-up — 2026-09-17

Rechecked Microsoft [Xbox Accessibility Guideline 112](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/112). Its recommendations remain aligned with the next P03 gates: predictable focus and shared Confirm/Back conventions, keyboard/digital-pad journeys, reflow that keeps navigation order consistent, searchable larger collections, and an available route back from every submenu. Scaling should avoid two-direction scrolling.

Implementation inference: prioritize saved Continue cancellation/late completion, Team terminal Retry/Change setup/Return, and genuine multi-page Collection/score navigation before expanding campaign production. These are remaining verification targets, not newly accepted behavior. Current Practice/Playground checks establish only their documented scope; synthetic input is separate from physical controllers and real touch.
