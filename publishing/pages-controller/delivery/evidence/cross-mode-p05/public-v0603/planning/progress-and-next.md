**[v0.60.3 is accepted for the named supporting-tool correction](../README.md).** Production and Viewport have consistent reading controls and recoverable startup; both are source-workspace tools, not public game routes. ## What this delivery changes

- **Production readability:** the supporting catalog uses shared text-style, size and reduced-effects preferences without becoming another preference owner. Reading changes preserve the selected original, current preview and filter/Back destination.
- **Viewport recovery:** failed startup offers Reload; a delayed operation may focus its result only while it still owns the foreground action. Mode or size changes do not implicitly load a new preview. The five authored iframe presets remain exact.
- **Maintainer guidance:** Production/Viewport guides, shared-host contracts, related skill and prompt guidance are included with the source. This is a local authoring correction: Production and Viewport are excluded from the public build, so there is no claimed GitHub Pages tool journey.
- **P03 regression coverage:** the Team won-terminal and saved Continue cancellation/late-rejection tests are integrated into this qualified source. Their focused cohorts contain 40 modeled checks per runtime, not 80 unique behaviors, and found no runtime defect. They do not establish a real browser Team victory or a native delayed-blob rejection.
