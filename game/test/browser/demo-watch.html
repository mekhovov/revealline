Observe the real demo

This local test page embeds the ordinary Legacy game. Use a disposable browser profile if you want its normal settings and saved-flight activity isolated from your own profile. The observer reads the game; it never starts, pauses or steers it.

  1. Wait for the game below. Open Settings → Help & Extras → Watch demo (or Watch demo on the classic home).
  2. Choose the observation duration, then press Start observation. Source hashing takes a moment before the clock starts.
  3. Use the actual game buttons below: test demo and music Pause independently, Next level/song, practice and Return. Enable sound and play music yourself; entering this page never unmutes it.
  4. Move to another tab or application and return during the run. Record physical audio/device findings separately. Do not reload or edit served sources while observing.
  5. After automatic completion or Stop observation, download the JSON. Leaving this page discards the in-memory report.

Five-second samples are bounded to 1,500. Long callback gaps are recorded as unobserved time, never invented activity. A completed duration is observation evidence, not automatic release acceptance, proof of audible output, or proof of execution while an OS freezes JavaScript.
