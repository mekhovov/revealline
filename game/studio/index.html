Opening your local workbench…

Create a community game · step-by-step guide

Start with one playable mission, then build its community identity. This workbench saves local drafts. Publishing and ordinary player installation are separate steps. Authoring uses a keyboard or pointer and a file chooser; keep downloaded backups.

1. Create or inspect a project

Choose a unique Local project ID and New project, or use Inspect import for a ContentProjectV1 backup. Review the inspected source before Apply inspected source. Inspection does not replace your accepted draft. Export existing work before reusing its identity. Use Organize missions, campaigns & packs to name and order the journey.

2. Make one clear challenge

Define the lesson, route decision, threat and counterplay. Add one meaningful change at a time. Target territory and countdown change the objective; challenge ratings describe your design and do not change enemy speed. Gentle, Standard and Expert use the shared presets. A picture does not define walls or collision.

3. Play and revise

Use Play exact Solo preview, then Start mission. Test a legal capture, loss, Retry and a complete clear. Pause stays explicit. Close preview returns to your workbench. Check each supported difficulty and mode separately. Practice does not award player progress; a compiled mission or an authored rating is not a playtest.

4. Save and recover

Save checkpoint / retry creates local history. Inspect saved lets you review an earlier checkpoint; applying and saving it creates a newer checkpoint without deleting the intermediate ones. Export backup downloads the current project JSON, not every checkpoint or all artwork and audio. Verify the actual download. In a clean workbench, Inspect import, Apply inspected source, save and reload to test recovery.

5. Prepare the community presentation

In Asset Studio, select a slot and read its dimensions, palette, transparency, anchors and affected screens. Preserve authorized originals and record creator, source, rights and generation/edit prompts. Prepare replacements before staging; a changed crop must be prepared again. Geometry changes need a fresh review. Save and export a separate .rltheme bundle, then test its import and retained image bytes. A palette or logo alone does not complete actors, terrain, HUD, effects, objectives, reveal pictures and audio. Keep this project backup with its media originals.

6. Test Team deliberately

A Solo mission is not automatically a Team mission. Inspect Team Signal greybox provides a compatible starting point. For each selected preset, Export exact Team test mission and open that download in the Team test player. These exports contain geometry and rules; the player identifies its test scenery. Check both players, Support, rescue, Pause and Retry. The exported preset is fixed: change it here and export again to test another difficulty.

7. Qualify before publishing

Finish every required asset and review the actual game at play scale. Verify clear progression, all advertised modes, keyboard, touch and physical controllers, small portrait and landscape screens, readable text and reduced effects. Keep saved and earned originals intact. Test catalogue installation, offline dependencies and recovery. The release workflow then versions, tests, freezes and deploys the exact source, followed by public play. Uploading a draft here does not publish it.

            Organize missions, campaigns & packs
            
        
              Choose an untested Solo / Versus island or a two-seat Team island template. Duplicate
              copies missions and whole campaign/pack contents with independent IDs; maps and
              artwork remain shared immutable pins. Editing geometry creates a private revision.
              Shared child membership is preserved within a copied pack. Archived children remain
              archived. Add to parent keeps existing memberships. Remove from parent detaches only
              that membership. Delete refuses referenced or nonempty items and never removes shared
              maps or assets. Archived items stay editable here but are omitted from candidate
              Journey lists. Changing a campaign band never retunes its missions: every member must
              already fit that band or the next (capped at 12), or the edit is rejected.
