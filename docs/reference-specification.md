# XPOSED comparison specification

Execution reference for [the implementation roadmap](implementation-roadmap.md), 2026-09-12. This records evidence and implementation choices separately. Existing frame inspections remain in `docs/research/evidence/round-05` through `round-07`; no claim of a new full-video or soundtrack audition is made here.

| Surface/mechanic                         | Evidence classification                                                                                                                                                                   | RevealLine implementation target                                                                     |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Pack discovery / reveal rewards          | Documented: [official Reloaded listing](https://store.playstation.com/en-us/product/UP2538-CUSA28099_00-XPOSEDRELOADED01) describes area capture, unique backgrounds and unlockable packs | A clear pack → map → reward loop, not a configuration webpage                                        |
| Title/settings                           | Observed in saved manual frames                                                                                                                                                           | Restrained dark title, Start/Continue, music/SFX, help and legible focus                             |
| Gallery                                  | Observed: black surroundings, cyan selection brackets, magenta stars and best scores                                                                                                      | Mystery cards, earned art, distinct three-star conditions, explicit preview suitable for touch       |
| Movement persistence                     | Original-game review reports compulsory movement outside safety; Reloaded release semantics unresolved without an input overlay                                                           | User-specified continuous movement, both Immediate and Grid + buffer, no release-to-stop             |
| Field / line / exposed / erosion enemies | Documented in inspected manual                                                                                                                                                            | Separate registered behavior roles, not palette variants                                             |
| Wall / slow / lethal terrain             | Documented in inspected manual                                                                                                                                                            | Walls block both; slow/lethal affect player as declared independently of enemies                     |
| Four pickups                             | Documented in inspected manual                                                                                                                                                            | Extra life, player speed, enemy slowdown, enemy freeze                                               |
| Live cut / capture                       | Observed in paired frames; full fill algorithm unresolved                                                                                                                                 | Bright trail head, readable active trail, deterministic tested capture; no invented reference parity |
| Failure / recovery                       | Observed: unfinished cut disappears, secured land retained; timing estimate only                                                                                                          | Clear failure explanation, brief animation, fresh input after recovery                               |
| Victory                                  | Observed: full image before star/results presentation                                                                                                                                     | Win recorded first, full still, optional story, results; replayable from Collection                  |
| Speed objective                          | Footage continues at zero time in inspected example                                                                                                                                       | Clearly distinguish speed medal from an explicitly authored lethal timer                             |
| Music / SFX                              | Unresolved: actual listening pass outstanding                                                                                                                                             | Original licensed/owned sound only; persistent music and separate effects/cinematic buses            |

Three geometry studies are required: Reloaded opening board; Pack 1 wall/slow region around 4:33; Pack 6 Level 7 bars/rectangles/mixed terrain. They reproduce observable routing geometry for comparison, with unknown timing/collision/fill parameters labelled. Production variations and campaign pictures are original.

Sources: [manual recording](https://www.youtube.com/watch?v=SKKvpZ2DvUY), [Pack 1](https://www.youtube.com/watch?v=8L3PwVcvg40), [Pack 6](https://www.youtube.com/watch?v=-qG4k6dkd-c), [original XPOSED review](https://www.playstationcountry.com/xposed-ps4/). The original review's life, time and movement observations are not automatically Reloaded facts. Player reviews do not measure retention.

Technical reference: [MDN play()](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/play) requires handling playback rejection. Session-owned music starts after a permitted interaction, preserves saved mute and never treats a stored preference as browser permission. Later MP3 and video tests include actual decoder/network failures.

The supplied drone folder contains 22 reference images, including illustrative sheets rather than only photographs. Inventory every image before final sprite production. The supplied video-example folder was empty at planning time; use owned fixtures and inspect new examples when present.
