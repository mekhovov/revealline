# Team relay-anchor authoring

Studio's **Prepare Team anchor slots** creates `team.anchor.available` and `team.anchor.captured`. These are objective roles, separate from pickups, Support and Scan. Each accepts the current `team.anchor.v1` procedural recipe or a 24×24 transparent image. Preparation creates immutable source-stage revisions; it does not approve a theme, touch player saves or publish the game. Historical documents and selections remain readable.

Choose a role, read its prompt and requirements, then upload an image or edit theme tokens. Standard crop, source preservation, sprite editing, local history and bundle operations apply. Runtime keeps the real capture position, border and letter/check. Cosmetic images are at least 24 CSS pixels, stay in the arena with their declared pivot, and reserve space before labels are placed. Image display size never changes collision or capture geometry.

Use Field context → Couch Team → Relay Yard. Inspect **Initial field** for available anchors and **Anchors captured** for captured ones. First Connection reports this role as inactive and invents no objectives. Solo/Versus context gives a mode-specific explanation. Native/transparency image previews remain available. A malformed declared image rejects preparation without discarding the previous presentation. Recipe defaults remain explicitly procedural.

Import validates the exact pair of slot contracts and retains immutable history. A selected pair must have both assets reviewed with evidence before the production declaration gate passes. This is compatible with the separate 32 Team actor-state slots; body state and anchor role counts remain distinct.

## Crowded imported objectives

Valid imported maps can place anchors closer than a 24px decorative icon. The painter checks all prospective anchor image footprints before drawing. Where images collide with another anchor image, an anchor's real target, or a core's target, it omits that decoration and retains the exact capture border and letter/check. Both conflicting images are omitted; ordering never selects a misleading winner. The same rule protects recipe-only neighboring anchors. Capture geometry, progression and artwork ownership do not change.

Core labels preserve their relay number and SHIELD/CAPTURE/SECURED state. A relay excluded from the authored victory goal adds **OPTIONAL**; in a coverage mission every relay is optional to victory. Optional means it is unnecessary for completion, not that its threats are inactive.
