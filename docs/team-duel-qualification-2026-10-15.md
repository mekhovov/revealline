**Repeatable delivery and desktop observation.** The new [delivery verifier](../scripts/verify-multiplayer-delivery.mjs) checks exact mission identities, original picture hashes, all transitive offline groups and every distinct dependency URL against a stable manifest. It fails on corrupt/missing bytes or a rolling deployment change. Both tools have targeted regressions and run in hosted feature verification; the new gameplay/audio/launch regressions are also registered there.
