# Team feedback authoring

Asset Studio → Prepare Team effect slots creates four optional contracts in the selected theme. Each starts with the existing procedural appearance and source-stage provenance; preparing a slot is not production approval. Current/Draft, upload/crop, single-layer sprite editing, immutable revisions, Undo/Redo, save/reload and bundle import/export use the existing isolated Studio workflow.

| Slot                   | Actual state                                                               | Earned preview                   |
| ---------------------- | -------------------------------------------------------------------------- | -------------------------------- |
| `team.effect.support`  | A live 0.3-second pulse at its stored origin; not damage or proof of a hit | Support pulse, both arenas       |
| `team.effect.slowed`   | Active enemy with a live slowdown; outlasts the pulse                      | Slowed enemies, both arenas      |
| `team.effect.rescue`   | Active helper holding rescue of a downed teammate                          | Rescuing player 1/2, Relay Yard  |
| `team.effect.recovery` | Active revived player during grace; distinct from hunter recovery          | Player 1/2 recovered, Relay Yard |

Replacements are transparent 32×32 PNG images with retained source/provenance and exact frame/pivot validation. Runtime displays an optional 24-CSS-pixel badge near its real source, outside player/enemy contact positions and relay objectives. On crowded boards a badge may be suppressed rather than moved far away or placed over an actor. The authoritative ring, range, numbered identity, text, rescue progress, timing and HUD remain intact. Reduced effects keeps the same real state; no cosmetic wall clock extends it. Pause uses the host's existing input-release behavior, including rescue cancellation.

Field context → Couch Team shows actual command-earned scenes; inactive scenes say so. Native size previews show uploaded artwork; recipe defaults explain their procedural role and direct the author to the live scene. First Connection has no earned rescue/recovery specimen yet. Reserve and team recovery causes need separate coverage; the existing recovered scenes establish revival grace only. Solo/Versus do not adopt these Team-specific badges.

Imported contracts must contain the exact complete four-slot family. Declared images prepare atomically even if their state is inactive in the selected arena; a broken required image keeps the old snapshot. Historical themes without this family retain their existing presentation. A publication selecting any feedback slot must supply reviewed declarations and evidence for all four; that gate is not proof of artistic quality.

Qualification must cover real image decoding, active/inactive scenes, both players, light/dark pictures, phone/desktop sizes, crowded objectives, reduced effects, undo/reload and export/import byte preservation. Keep modeled state tests, native browser observations, physical devices and public acceptance separate. Emitter/spark, joint-capture and shield authoring are subsequent work; these four slots do not complete P04/P08 or five-edition production.
