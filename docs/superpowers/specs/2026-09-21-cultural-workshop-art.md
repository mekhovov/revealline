Follow-up to the reviewed eight-map spatial arcs. All eight have compiled topology,

## Art direction

Eight distinct continuous2:1 pixel-art pictures, one per mission, using the built-in
image tool and original generated PNG bytes. Deliberate square clusters, restrained
shading and separated focal discoveries; not smooth photographic or painted assets.
No text, UI, gameplay markers, luminous projectiles or artwork-derived collision.
Broad quiet regions must allow active trail, walls, reclaimed surfaces and threats
to remain legible when the image is partially revealed. Inspect each output before
accepting its bytes; a failed image is not a placeholder for a completed picture.

| Mission | Picture direction |
|---|---|
| Cross-stitch crossings | Linen vyshyvanka, original stepped-diamond embroidery, hoop and thread; quiet tabletop between discoveries |
| Rushnyk bands | A long folded rushnyk across a wooden chest near a sunlit window; original red/charcoal bands, distinct cloth folds |
| Pysanka sections | Several decorated eggs in a shallow ceramic bowl, one larger foreground egg; original segmented patterns, calm table surfaces |
| Dnipro crossings | Wide river, green islands and layered riverbanks at soft daylight; geographic inspiration, not an exact historical reconstruction |
| Four motor landings | Inert hobby quad frame and four broad motor forms on a work mat; decorative still life, no functional assembly diagram |
| Circuit lanes | Abstract unpowered board, component trays and copper-like traces; non-functional decorative geometry, not a wiring guide |
| Twin lens chambers | Resting FPV goggles, paired dark lenses and a simple controller on a spacious bench; no people or live display text |
| Toolbench weave | Pliers, precision screwdriver, closed parts boxes and broad work mats; distinguish tools through large silhouettes |

The ornament set uses warm linen/honey wood, muted madder and charcoal-blue. The
workshop set uses slate/navy mats, warm wood, copper and muted teal. Both share
pixel-cluster scale, moderate contrast and quiet-space treatment. Pictures are
decorative rewards under gameplay, not miniature game boards or obstacle maps.

Primary references rechecked21September2026: [Ivan Honchar Museum's rushnyk
collection](https://honchar.org.ua/collections/view/rusniki) documents varied textile
objects; the [Ukrainian culture ministry's pysanka account](https://mincult.gov.ua/en/news/the-ukrainian-tradition-and-art-of-egg-decoration-recognized-as-the-cultural-heritage-of-humanity/)
identifies egg decoration as a distinct tradition. Use original inspired motifs;
do not trace collection objects or invent regional/symbolic authenticity. No museum
image is a generation input. Workshop pictures convey materials and silhouettes,
not build instructions, targeting, weapons or nationality caricatures.
