# Browse optional worlds

Open **Missions → More chapters** to browse optional worlds. The entry stays beside Back in the sticky Missions heading while the selected chapter retains focus in the scrolling content. Game mode can remain collapsed. It uses the existing download browser and launch handler; changing modes is not a prerequisite for discovering chapters. Briefing hides the chapter action, and Training retains its existing availability rules. The concise Missions title reuses the navigation translation key without reducing Standard/Large text sizes.

The browser uses native Theme and Mode choices and small pages. All themes and All modes show the original deterministic catalog order. Desktop pages contain four cards; widths at or below 900 px or viewport ratios at or below 3:2 contain two. Previous, Next and a visible page count make every choice reachable without typing. Back returns to the main menu. Each control retains a minimum 44 px target; viewport and physical-device acceptance are separate checks.

The filters are temporary menu state for this page. They do not write player settings, install content, remove packs, switch the selected mission, save a flight or resume it. The existing controller adapter previews a native select choice, Confirm applies it and Back cancels the preview. Hidden cards leave digital focus traversal. A resize that hides the focused card returns focus to Theme.

An active card remains visible while the player filters or turns pages, using one of the page's card slots. Its name appears above the cards. Filter/page changes do not abort or repeat a download. Completion leaves that same card visible for Play or retry; the next deliberate idle filter/page change releases the retained card. An explicit Cancel or Back keeps the existing operation cancellation contract. A completion cannot steal focus from a player who moved to a filter or other control.

If the remote list is unavailable, the last accepted list is retained and the source-owned cards still inspect installed originals. Remaining installed packs offer Play without a download. That action captures the activation before preparation and passes the exact currently prepared pack object to the host, which rechecks current membership and refuses registered external owners: their own source card continues to enforce descriptor and original readiness. Remote list failure grants no new download authority. Use Refresh to retry the list or Manage packs & backups for existing management and recovery.

Trusted external choices have a ceiling of **36**, independently of the **12 installed packs**. The stored index and pack library remain bounded, with 48 MiB for installed gameplay/index data, 24 MiB for an ordinary pack and 256 MiB for the shared managed-media store. External descriptors retain their stricter 16 KiB metadata, 1 MiB gameplay and three-original contract. The external catalog remains exactly equal to the code-owned source registry: increasing the parser ceiling does not admit arbitrary remote owners or add chapter bodies. The legacy catalog and explicit build producer membership are unchanged. No automatic eviction or optional-body precaching is introduced.

The implementation is [the panel](../game/ui/optional-chapters-panel.mjs), [view projection](../game/ui/worlds-browser.mjs) and the existing exact host/backup authority. Relevant qualification covers every page/filter intersection, 36-choice versus 37-choice refusal, unchanged 13-installed refusal, delayed failure and retry, select preview/cancel, offline installed access and a real paused-flight checkpoint. Source tests model DOM/input/storage boundaries; actual browser layout, touch and physical controllers require their own recorded journeys. No release or device acceptance is implied by this source guide.

The touch layout uses stable labeled controls, safe-area spacing and nearby operation status/Cancel, following the platform-independent design principles in [Apple’s touch game guidance](https://developer.apple.com/videos/play/wwdc2026/358/) and [Game Accessibility Guidelines on temporary information](https://gameaccessibilityguidelines.com/avoid-placing-essential-temporary-information-outside-the-players-eye-line/). This is an HTML interface using the existing browser input adapter; it does not integrate Apple’s Touch Controller framework. The reading is design support, not a phone, controller or viewport test.

The Solo host enables the [Download & play contract](more-worlds-flight-selection.md). A page/filter change keeps an installation running but retires automatic play from the earlier activation. Manual exact-pair recovery only installs. A stable primary action changes from Download & play to Play and remains the focus return target after Stay or failed preparation. Complete cross-mode catalogue consolidation remains separate.
