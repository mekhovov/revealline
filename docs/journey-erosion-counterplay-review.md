# Journey erosion counterplay review

Status: authored-signal review complete; human route/balance review pending.

All eleven current Journey missions containing a territory eroder were reviewed through the shared
compiler. Every one has at least one permanent foundation or relay connector, an explicit route
choice, erosion teaching/practice evidence, coverage at or below 85%, and an authored escape or
return strategy. Repair is never a required completion objective.

Four later combination missions mechanically used erosion but omitted it from their practice ledger:

- Cooling loop;
- Return currents;
- Final broadcast;
- Dawn circuit.

Their successor records now state the intended choice: repair a reopened cell only when it preserves
a useful planned route; otherwise continue through a permanent landing, connector or circuit. This
prevents the authored objective from implying that every isolated loss must be chased.

`JourneyErosionCounterplayAuditV1` exposes these authored facts through the same compiled project used
by gameplay. It does not run an alternate balancing simulator and does not claim that a route is fun
or viable while enemies move. Those questions remain explicit human-play gates.

The `whole-spatial-v9` successor changes no actor, movement, coverage, objective, geometry, artwork or
runtime rule. Its four revised missions retain the exact v8 simulation identities for every preset
and Solo/Versus mode. v8 and every older route remain immutable and selectable.
