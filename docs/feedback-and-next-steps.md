**Capacity is the next concrete engineering constraint.** The five optional packs hold fifteen original pictures and total 56,383,865 prepared-pack bytes. Their installed-library envelope is 56,383,914 bytes (53.77 MiB), above the unchanged 48 MiB limit by 6,052,266 bytes. The four earlier theme variants reuse three Pressure Lines layouts; Route Choices adds three distinct Tactical layouts. The fifteen exact originals total 42,245,711 bytes; embedded data URLs account for most of the overhead. The first capacity step should externalize those unchanged originals into managed storage with validated references, before adding optional runtime derivatives. Reviewed source pilot `9f04a849` now supplies a versioned install descriptor, exact-original compiler and recoverable publication journal. Its three-original example accounts for 10,927 bytes of pack-library JSON plus durable descriptor index, while 8,024,867 exact PNG bytes remain in the shared media budget; 122 affected Node 22 and 36 new Node 20 checks pass. Game-host adoption, installation of the intended catalogue and existing-user migration are still pending. A source pilot does not free existing storage or change a saved picture. Keep source originals, runtime derivatives, installed pack bytes, earned Collection storage and backup sizes separate. A working refusal with no automatic eviction is valuable, but it does not satisfy the final interchangeable catalogue. Browser storage is origin-wide and can be evicted; reported space is an estimate, so successful downloads need explicit recovery and backups. [MDN storage guidance](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria).
