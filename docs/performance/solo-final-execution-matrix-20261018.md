## Overhead method: narrow prospective improvement, not a changed verdict

`solo-diagnostics-analysis.mjs` already requires every raw running sample and computes nearest-rank p95. It then bounds every pair using the largest log allowance and expands that allowance by `1 + t/sqrt(n−1)`. `solo-journal-cost-analysis.mjs` first uses the maximum endpoint count from the whole arm as every p95 error allowance. These are deliberate conservative bounds; replacing a HUD histogram cannot fix them because neither overhead assessor uses that histogram.

A bounded prospective analyzer study can preserve the exact estimand and gates:

1. For each retained journal window use its own already-recorded endpoint count to form the original assumed error interval, including quantized-zero hooks and assigned tail counts. Nearest-rank p95 of the lower and upper sample bounds encloses every permitted true p95; it need not charge one extreme window's endpoint count to every window. Retain all samples, phases and failures.
2. Form each pair's log-ratio interval from those p95 bounds (app uses its existing duration bound). For the unchanged ten pairs, evaluate all1,024 box vertices for the existing `mean ± t·SD/√n` endpoints. The upper endpoint is convex, so its maximum is at a vertex; the lower endpoint is concave, so its minimum is at a vertex. This computes the worst case over the same bounded errors instead of the current global triangle-inequality slack. It does not assume independent timestamp errors or average uncertainty away.
3. Validate in a new prospective method: exhaustive small-box comparison, asymmetric/error-correlated endpoints, reordered p95 ranks, zero-duration hooks, missing/censored samples, tails, quality mismatch, all-pair requirements, scale invariance and monotonic widening. Keep10 pairs, normal browser policy, raw p95, ≤5%, fixed workload and original failed results. Old reports retain their original assessor/verdict; any supplementary calculation is separately labelled.

Under ten hypothetical equal pairs with zero sample variance, the current expansion versus exact box bound is5.73%→4.06% for p95=6.3 ms/error=0.1 ms,12.41%→8.71% for3/0.1 ms, and342.13%→189.02% for3/1.2 ms. These are algebraic illustrations, not observed passes. Sample-specific endpoint bounds may further help the journal, but no retained cohort was reclassified. Both methods still rely on the original sensitivity assumption that the observed quantum bounds duration error; the minimum clock step is not a guaranteed privacy-jitter bound. No COOP/COEP, timer/security change, added load, outlier deletion, pooled frames or post-result repetition increase is proposed. If normal precision remains inadequate, the ≤5% gate remains unresolved.
