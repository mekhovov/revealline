# Importing Team collections into an older workspace

A fresh Studio can contain a release registry predating Team asset roles. Import now adds the running release’s exact approved Team slot definitions in the same atomic draft transition as the imported collection. You do not need to find and press Add Team presentation slots first. Existing immutable records remain unchanged; Undo returns to the original workspace.

Unknown slot IDs and changed new contracts are rejected with a compatible-release message. A team prefix alone grants no support. This does not install executable renderers or silently reinterpret imported requirements. Exported data from a newer unsupported Studio still needs its compatible runtime.

Qualification must use an actual browser-downloaded file in a fresh workspace, verify its payload hashes, save/reload and exercise Undo before claiming an export/import round trip. Include already-upgraded and unknown/altered-contract cases. Browser download requests alone do not prove transfer.
