# Soundtrack originals as discovery audio

Soundtrack Studio can prepare the currently selected MP3 as an explicit original
download for a discovery reward. This requires permission for web playback,
offline storage and redistribution, plus the existing reward duration bound of
120 seconds. It never clips, re-encodes, begins playback, changes a playlist or
assigns music to a map. The original soundtrack library and `.rlsound` backup
formats are unchanged.

The shared **Recording discovery** editor appears in Company Studio and
Level/Campaign Studio. In Level/Campaign Studio, first import the existing owning
Company source draft; Company Studio already supplies that context. Choose a
reward, the MP3 original and English/Ukrainian `.txt` transcript originals, then
inspect them. All three must already be approved assets in that campaign's
selected inventory, with permitted dependencies and the correct publication
classification. Filenames and a local rights declaration cannot create approval.

Select each exact matching asset and enter the two recording titles. Preview uses
the same native reward media viewer as Collection, requires explicit Play and
respects its shared audio ownership. Editing or closing the preview releases its
player and owned URLs. Instrumental recordings should have useful descriptions
in both transcripts; do not invent spoken words. Source and rights review still
belongs to the edition's existing asset inventory.

Apply uses the existing immutable reward edit/rebind operation. It adds or updates
an ordinary `audio` payload with exact recording and transcript hashes. Promised
completion requirements, gameplay and the player's completion state are not
changed. Export/import and selected player compilation therefore reuse the
existing audio dependency, MIME, source eligibility and missing-media recovery
paths. The combined originals remain within the unchanged 32 MiB edition budget.
Longer tracks require a separately approved shorter original or a later optional
package; the handoff does not raise any cap.

This slice transfers one recording. It does not introduce a playlist reward type,
automatic sequential playback or an earned soundtrack installation store.
