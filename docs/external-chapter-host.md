# External chapter host authority (isolated source)

`createExternalChapterHost` in [external-chapter-host.mjs](../game/external-chapter-host.mjs) surrounds the [exact-original pilot](external-chapter-originals.md). It supplies storage authority for later host wiring; it does not register a world, change the app, install on startup, add a database, modify backup formats or publish the pilot. The initial supported operation is additive installation of an explicitly registered, separately identified edition. Existing embedded packs are neither rewritten nor migrated.

## Injection and methods

```js
const chapters = createExternalChapterHost({
  indexedDB,
  profileKey,
  packsKey,
  storage: localStorage,
  lockManager: navigator.locks,
  writer, // already held real profile writer; ownership stays with the caller
  getManagedStore: () => sharedManager, // createManagedMediaStore({ storyMedia: true })
  registeredEntries: [baseEntry], // exact authored inputs, owned at construction
  knownDescriptors: [reviewedDescriptor], // explicit trusted registration, not an ID heuristic
  decodeImage, // optional native default; injected decoders are trusted capabilities
});
```

Construction opens neither database. Ordinary unindexed pack inspection/mutation never invokes `getManagedStore`. The first external operation lazily borrows the current DB4 manager and creates a borrowing still adapter. It never closes that manager or releases the caller's writer. Main, practice, course, music and Workshop must continue sharing their current compatible manager. No fallback to a v2/v3 opener is made. `close()` cancels owned pending work and closes only the borrowing adapter and owned pointer adapter.

| Method                                                      | Contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `inspect({signal})`                                         | Reads pack pointer, descriptor index and both recovery journals in one assets transaction; also checks the profile's local backup marker. Returns `status:'recovery-required'` with `mixed-journals`, `backup-recovery` or `external-recovery`, or a branded `status:'checked'` snapshot with validated packs/index/execution catalog and `usage` (normalized pack bytes, actual persisted index bytes, unchanged limit). An absent index contributes zero bytes. Checked means exact metadata/owner closure, **not** proof that every original Blob is available. |
| `readiness(snapshot, id, {signal})`                         | Requires a current checked snapshot from this host. Reads combined still/story metadata and authenticates all three descriptor originals using the existing selected-asset byte/hash/header/decoder path. Returns ready pins plus this borrowed store's metadata snapshot. Changed pointer/index/journal/media generation, missing original or decode failure refuses.                                                                                                                                                                                             |
| `authoredPicture(snapshot, request, {signal})`              | Request is exactly `{executionKey,levelId,levelRevision,themeId}`. Returns the descriptor's exact revision-1 managed still pin and acquisition context after readiness. Standard/Gentle resolve through the verified owner. This is an authored default for a **new** attempt, even when today's assignment is B or cleared. It does not accept saved/earned pins or rebind them.                                                                                                                                                                                  |
| `prepareMutation(snapshot, nextPacks, {signal})`            | Owns input before awaits, validates ordinary packs, all unchanged indexed gameplay and the combined 48 MiB cap. Returns a branded single-use review. External removal/replacement, known compact JSON without its descriptor index, occupied recovery state and stale snapshots refuse. No writes.                                                                                                                                                                                                                                                                 |
| `commitMutation(review, {signal})`                          | Rechecks authority and executes a native assets-store compare-and-swap of the pack pointer while preserving the exact descriptor index and refusing either recovery journal. A failed transaction preserves old state. The review is consumed even on refusal. A completed native commit remains `status:'committed'`; no subsequent read can mislabel it as rolled back. Caller adopts once, only if its current selection still permits it.                                                                                                                      |
| `install(prepared,{signal})` / `recover(prepared,{signal})` | Require the pilot's branded exact-payload preparation matching an explicitly registered descriptor. Delegate once to the existing installer outside the host's backup lock, avoiding a nested-lock deadlock. Return its durable completion receipt; call `inspect`/`readiness` separately before UI adoption. Recovery requires exact original inputs; mixed journal/marker states refuse.                                                                                                                                                                         |

All asynchronous methods are mutually exclusive within this host instance and use the existing profile backup lock where appropriate. The real writer is required for every mutation. Snapshots and reviews cannot be serialized and reused as authority. Supplied descriptors and authored catalogs are validated/owned at construction. A descriptor is declared content/provenance, not proof of licensing rights. Its original byte hashes and exact authored owner mapping remain mandatory.

`knownDescriptors` is a bounded explicit registry of supported external editions, not a search by ID prefix or empty artwork. The module refuses an indexed descriptor outside that registry. A known compact gameplay pack without its index is refused before opening media; unrelated ordinary packs keep their existing behavior. Future arbitrary external imports need an explicit registration/adoption contract, not silent registration from a file name.

## Pictures, recovery and budgets

The descriptor names an immutable authored original A. Installation/recovery retains the pilot's strict requirement to establish A's assignments. After installation, checked metadata/readiness deliberately allow valid B or cleared current assignments: those do not erase authored A. Later app wiring must choose its normal per-attempt B selection when appropriate, or call `authoredPicture` for the original-art/default path. It must never substitute generic scenery for an unavailable external original. Existing saved A and first-earned A continue through their existing pin resolvers, regardless of today's assignment; legacy receipts retain their unchanged interpretation. No receipt/session/story format is changed here.

The pilot's media-first journal remains the only installation implementation. Before native media commit, refusal leaves prior media intact; after that commit, incomplete publication can retain counted originals and a journal. Exact explicit recovery completes publication once. There is no destructive cross-database rollback, automatic journal clear, inferred eviction or removal of immutable identities. Missing/foreign inputs retain recovery evidence. Storage-unavailable cleanup can leave a bounded lease until its existing expiry. An already committed installation is not undone by a late Back/Cancel.

This is a cooperative protocol across two databases, not a global atomic transaction. Same-channel callers must use the existing writer/backup locks and route **all** pack/Workshop/backup operations through compatible guards. LocalStorage markers are checked with the transaction but are not part of its IndexedDB atomicity. Other profile channels can legitimately change shared media after a readiness check, so acquisition still validates exact selected originals. The returned borrowed store must not be closed by consumers.

Caps remain 48 MiB for normalized pack-library JSON **plus descriptor index**, twelve packs, the existing descriptor/index bounds, 4 MiB/1920×1080 per poster, 256 MiB committed-plus-staged managed storage, 2 MiB shared still/story metadata and 512 physical original rows. The existing installer reserves the entire prepared media inventory conservatively, including originals already present. A deduplicated final fit does not promise a repeated/occupied-store install will fit staging. No budget was raised.

## Next shared wiring and acceptance

The adapter intentionally refuses writes while a backup journal exists, including a backup's own journal. Do not replace `backupAdapters.writeAsset` with this API and bypass that refusal. First permit only proven index-preserving backup operations or design a separately reviewed own-journal capability/companion recovery contract. Existing JSON backups do not carry the descriptor index; restoring their compact external pack alone is insufficient. Retain descriptor+gameplay and `.rlmedia` plus game JSON; `.rlstory`/`.rlsound` remain separate when used. A source distribution package is not a backup of later user assignments/history.

Wire checked snapshots into startup, pack reconciliation, Install/Choose, all pack writers, Workshop catalog `read`/`withCurrent`, transfer source/target and backup/Undo/recovery together. Keep pending flights paused, preserve input ownership, and never auto-Choose after Install. Then test a real native install → separate Choose → first win → saved/reload → exact first-earned Collection journey and paired recovery on a fresh origin. External removal/retained dependency history, existing embedded-user migration, public distribution/defaults and stopped-server acceptance remain separate gates.

The focused tests use the actual pilot compiler/original hashes, DB4 manager, still/story/audio adapters, pointer store, writer and finite serialized IndexedDB model. They exercise physical Blob corruption/removal, assignment A/B/clear, retained audio/story data, interrupted publication/restart, stale/single-use mutation reviews, native CAS failure, quota refusal and cancellation/timeout. Repeated PNG decodes use authenticated header dimensions as a modeled decoder; these tests do not establish a browser codec, native disk persistence, downloads, hardware, playable host integration or public/offline availability.
