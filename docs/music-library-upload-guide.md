# Play, download and import the music collection

This edition includes **70 creator-licensed recordings in 15 built-in albums**, also available as individual MP3s and downloadable album files. For immediate listening, open **Settings → Audio → Music library & playlists**, choose an album in **Playback playlist**, then **Play this playlist**. Use **Sound controls → Unmute master sound** if muted. No manual import is needed. See [Music in RevealLine](hosted-soundtracks.md) for online listening, mixes, offline installation and how the two repositories connect.

The separate **80-filename / 77-recording UA-FPV private collection** still requires local import. All 70 creator recordings remain musical audition candidates with **zero listening-approved recordings**. The downloadable packs retain their preview status, including the six older titles without that suffix. AI-generated music production is paused; neither rejected sketch nor any generated original is included.

The **15 album files** work with the **RLSTB3 / soundtrack v3 framework in v0.78.0 and later**. The older **v0.77.0** and v0.76.1 editions read RLSTB1 only and cannot import these packs; they can import individual MP3s. In the current Studio, **Backups & album files → Add album file to draft** adds a pack; **Filters & custom mix → Music selection → My Mix** configures a genre mix. Direct built-in access to these 70 recordings is introduced in v0.80.0; v0.78.0 and v0.79.x use the manual imports below. Keep a saved-library backup before changing storage versions. The [UA-FPV guide](ua-fpv-upload-guide.md) also explains the older edition's MP3 and playlist controls.

### Import individual downloads

1. On the archive, choose a recording's **MP3 ↓** download link and retain its displayed filename and credits. If the browser saves a hash-based filename, use the catalogue to identify it; changing a filename does not change the MP3 bytes.
2. Open **Settings → Audio → Music library & playlists**. Save and back up existing music first. Expand **Add & edit music**; under **Add MP3 files**, select the downloaded files and choose **Import selected MP3s**. Wait for validation; use small batches if storage is tight. Import each file once to avoid duplicate library rows.
3. Select each imported recording in **Tracks**. Raw import starts as **Personal local upload** and does not fetch the archive's credits or tags. Copy its **Track title**, **Artist** and **Credit** from the archive; choose **Source declaration → Licensed work**. Put the license name and URL in **License / permission**, and the creator recording-page URL in **Source / provenance**. Preserve the complete credit and conversion notice with your downloaded files. Choose **Apply track details to draft**, then **Save all changes**.
4. In the new framework, set **Primary music family** from the preview catalogue if you want genre selection. Leave **Fusion with** empty unless the entry declares a second genre. Raw imports otherwise remain unclassified. These metadata edits preserve the original MP3 bytes and do not create trusted catalogue or Recording mode permissions.
5. Select a song, expand **Create playlists** and choose **New playlist with selected track**, then add the other songs with **Track to add → Add selected track**. Set **Shuffle without repeats until every entry played** and **Repeat all**, apply the playlist details, and **Save all changes**. Choose the playlist in **Playback playlist**, then **Play this playlist**. Unmute master sound if muted; **Next** advances the queue.

The current steps use the simplified v0.81.0+ controls. Earlier editions use **Save & use playlist**, followed by **Play music**. The older v0.77.0 and v0.76.1 editions support MP3 imports and manual playlists, but not genre tags or My Mix. Their provenance field initially holds the original filename, so retain that filename separately before replacing the field with a source URL. In the new framework, preserved filenames are separate from editable titles. Open licensing does not establish Content ID clearance; Recording mode excludes these recordings while that status is unknown.

## Add an album and play it

1. Open **Settings → Audio → Music library & playlists** in Solo, or **Music library** from the Couch audio controls. Save the current draft and prepare/download a saved-library backup if it contains music you want to keep.
2. Expand **Backups & album files**. In **Soundtrack recovery or album file (.rlsound)** choose one file from the table. Click **Add album file to draft**, wait for validation, then **Save all changes**. Repeat only for the albums that fit. **Review backup as replacement draft** replaces a library; it is not the additive action.
3. Choose the imported album in **Playback playlist**, then **Play this playlist**. This saves the draft and starts playback; master mute stays independent. Browser playback may require that explicit interaction.
4. The supplied album playlist shuffles without repeating an entry until the other entries have played, then repeats indefinitely. It contains only that album; it does not automatically continue into another album's playlist.
5. To mix installed styles, expand **Filters & custom mix**, choose **Music selection → My Mix**, enable the desired genres, optionally enable **Installed only**, then **Save listening preferences**. This clears the explicit playback-playlist choice while preserving Pause; choose **Play music** when ready. Music can play in menus and gameplay after sound activation. Music pause is separate from master sound and sound effects.

For a personal playlist, select a track under **Add & edit music**, then expand **Create playlists** and use **New playlist with selected track**. Set the title, playback order and repeat setting; apply the details, add further tracks, then **Save all changes** and **Play this playlist**. Recording mode is a separate rights filter; an open license does not establish a recording's Content ID status. The [UA-FPV guide](ua-fpv-upload-guide.md) covers its personal-use declarations and duplicated filename aliases.

The public packs retain the earlier local packs' track and playlist IDs but include fuller license URLs, creator links and conversion notices. If you already imported an older local pack or edited its metadata, additive import can report an identity conflict. Keep your saved copy and backup; do not use replacement import merely to add the revised pack. The recording bytes are unchanged.

Keep the downloaded packs and original source folders outside browser storage. A local file import does not grant a download URL or install an automatically restorable Community album. To remove locally imported tracks, back up first and use the Studio's track/playlist editing controls; those deletions affect references. **Remove offline download / Download again** apply only where a trusted Community album is available and identified by that UI. Do not assume those operations are available for these manually imported preview files.

## What was verified

The earlier 15 local preview files were independently read one at a time, with length and SHA-256 matching both `catalog.json` and the generation receipt. Each native **RLSTB3 binary** passed the then-current game importer using an explicitly **structural MP3 probe**, then the actual additive-share merge into an empty v3 library. All 70 track IDs, byte hashes, sizes, titles, artists, filenames, genre tags, credits, licenses and creator-source links matched the source register; each supplied playlist retained shuffle and repeat-all settings. No duplicate audio files were created by this check.

This was a Node binary-format/metadata check, **not a browser import, device playback or listening approval**. Separate CoreAudio passes fully decoded the [18 new creator MP3s](../authoring/library/licensed-audio/provenance/expansion-mp3-decode.json), [22 new MP3 derivatives and their OGG sources](../authoring/library/licensed-audio/provenance/expansion-derivatives.json), and [30 retained runtime MP3s](../authoring/library/licensed-audio/provenance/retained-runtime-decode-20260921.json), with byte pins unchanged. Thus all 70 now have technical native-decode evidence; none has listening approval. Final import runs the chosen browser's media probe and storage checks.

The separate MP3 preview staging check verified all 70 source/delivery hashes, creator-license evidence, exact permission policies, attribution and conversion lineage, followed by output readback. Its [preview-only authorization](../authoring/library/licensed-audio/preview-authorization.json) and historical [local production publication list](../authoring/library/licensed-audio/publication.json) remain separate from the new [hosted catalogue integration](verification/hosted-soundtracks-2026-09-21/README.md). Staging does not prove public deployment, full browser playback or musical suitability. Full-track and repeated listening, transitions, loop seams and the in-game mix remain pending; catalogue availability does not mark those reviews approved.

The [public delivery audit](verification/music-publication-2026-09-21/public-delivery.json) verifies all 70 MP3s and eight served metadata/site files on GitHub Pages. [Deployment and browser evidence](verification/music-publication-2026-09-21/publication.md) records the exact archive commit and limited playback checks.
