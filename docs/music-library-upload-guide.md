# Download and import the music collection

There are **70 creator-licensed MP3 previews**, also arranged into **15 local album files**, plus the separate **80-filename / 77-recording UA-FPV private collection**. All 70 remain musical audition candidates: **zero listening-approved recordings and zero admissions to the game's built-in catalogue**. “Preview” applies to all 15 albums, including the six older titles without that suffix. AI-generated music production is paused; neither rejected sketch nor any generated original is included.

The **15 album files** require the **RLSTB3 / soundtrack v3 framework from PR #209**, or a later release containing it. The accepted **v0.77.0** source (`432110b51c570b838cdae390790b67dfa76f0785`), like the earlier v0.76.1 base, reads RLSTB1 only and cannot import these packs; it can import individual MP3s. **Add album file to draft** and **Music selection → My mix** identify the new Studio workflow. Use a separate browser origin/profile for a framework preview and keep a saved-library backup before changing storage versions. The [UA-FPV guide](ua-fpv-upload-guide.md) also explains the older edition's MP3 and playlist controls.

## Individual MP3 preview downloads

The separate [licensed music preview archive](https://mekhovov.github.io/revealline-soundtracks-01/) provides **70 individual MP3 downloads and browser previews**. **Publication verified on 21 September 2026:** GitHub Pages deployment passed and every public MP3 matched its expected bytes and SHA-256. The new framework links to it through **Community soundtracks → Browse licensed MP3 previews**, which opens a separate tab. The archive does not update the game, install music automatically, or add entries to its Community soundtracks album list. The 15 `.rlsound` album files below remain local artifacts and are not published there. UA-FPV remains private until recording-specific redistribution permissions are verified.

Each recording's page entry includes title, artist, creator/source link, license link, credit, conversion notice, original delivery filename, byte count and SHA-256. Keep the [credits and license notices](https://mekhovov.github.io/revealline-soundtracks-01/CREDITS.md) with downloaded music. The [preview catalogue](https://mekhovov.github.io/revealline-soundtracks-01/preview-catalogue.json) retains per-recording metadata; the [inventory](https://mekhovov.github.io/revealline-soundtracks-01/inventory.json) pins the exact `objects/<sha256>.mp3` files. All nine Zander Noriega credits link the creator's requested [artist page](https://twitter.com/ZanderNoriega).

The archive contains **354,986,122 audio bytes**: 37 exact creator MP3s and 33 documented OGG-to-MP3 conversions. Publication makes no further audio edits. A conversion notice is not a new composition or a claim of creator endorsement. Download a subset that fits the storage limits below; the complete collection exceeds one profile's 256 MiB shared budget.

### Import individual downloads

1. On the archive, choose a recording's **MP3 ↓** download link and retain its displayed filename and credits. If the browser saves a hash-based filename, use the catalogue to identify it; changing a filename does not change the MP3 bytes.
2. Open **Settings → Music library & playlists**. Save and back up existing music first. Under **Add MP3 files**, select the downloaded files and choose **Import selected MP3s**. Wait for validation; use small batches if storage is tight. Import each file once to avoid duplicate library rows.
3. Select each imported recording in **Tracks**. Raw import starts as **Personal local upload** and does not fetch the archive's credits or tags. Copy its **Track title**, **Artist** and **Credit** from the archive; choose **Source declaration → Licensed work**. Put the license name and URL in **License / permission**, and the creator recording-page URL in **Source / provenance**. Preserve the complete credit and conversion notice with your downloaded files. Choose **Apply track details to draft**, then **Save all changes**.
4. In the new framework, set **Primary music family** from the preview catalogue if you want genre selection. Leave **Fusion with** empty unless the entry declares a second genre. Raw imports otherwise remain unclassified. These metadata edits preserve the original MP3 bytes and do not create trusted catalogue or Recording mode permissions.
5. Select a song, choose **New playlist with selected track**, then add the other songs with **Track to add → Add selected track**. Set **Shuffle without repeats until every entry played** and **Repeat all**, apply the playlist details, and **Save all changes**. Choose the playlist in **Playback playlist**, then **Save & use playlist**. Unmute master sound and press **Play music** if paused; **Next** advances the queue.

The accepted v0.77.0 edition and older v0.76.1 edition support the MP3 and manual-playlist steps, but not genre tags or My mix. Their provenance field initially holds the original filename, so retain that filename separately before replacing the field with a source URL. In the new framework, preserved filenames are separate from editable titles. Open licensing does not establish Content ID clearance; Recording mode can exclude these previews while that status is unknown.

## Add an album and play it

1. Open **Settings → Music library & playlists** in Solo, or **Music library** from the Couch audio controls. Save the current draft and prepare/download a saved-library backup if it contains music you want to keep.
2. In **Soundtrack recovery or album file (.rlsound)** choose one file from the table. Click **Add album file to draft**, wait for validation, then **Save all changes**. Repeat only for the albums that fit. **Review backup as replacement draft** replaces a library; it is not the additive action.
3. Choose the imported album in the playback playlist selector, then **Save & use playlist**. Turn master sound on and press **Play music** if paused. Browser playback may require that explicit interaction.
4. The supplied album playlist shuffles without repeating an entry until the other entries have played, then repeats indefinitely. It contains only that album; it does not automatically continue into another album's playlist.
5. To mix installed styles, choose **My mix**, enable the desired genres, optionally enable **Installed only**, then **Save & use music selection**. This clears the explicit playback-playlist choice. Music can play in menus and gameplay after sound activation. Music pause is separate from master sound and sound effects.

For a personal playlist, select a track and use **New playlist with selected track**. Set the title, playback order and repeat setting; apply the details, add further tracks, then **Save all changes** and **Save & use playlist**. Recording mode is a separate rights filter; an open license does not establish a recording's Content ID status. The [UA-FPV guide](ua-fpv-upload-guide.md) covers its personal-use declarations and duplicated filename aliases.

Keep the downloaded packs and original source folders outside browser storage. A local file import does not grant a download URL or install an automatically restorable Community album. To remove locally imported tracks, back up first and use the Studio's track/playlist editing controls; those deletions affect references. **Remove offline download / Download again** apply only where a trusted Community album is available and identified by that UI. Do not assume those operations are available for these manually imported preview files.

## What was verified

All 15 existing files were independently read one at a time, with length and SHA-256 matching both `catalog.json` and the generation receipt. Each native **RLSTB3 binary** passed the current game importer using an explicitly **structural MP3 probe**, then the actual additive-share merge into an empty v3 library. All 70 track IDs, byte hashes, sizes, titles, artists, filenames, genre tags, credits, licenses and creator-source links matched the source register; each supplied playlist retained shuffle and repeat-all settings. No duplicate audio files were created by this check.

This was a Node binary-format/metadata check, **not a browser import, device playback or listening approval**. Separate CoreAudio passes fully decoded the [18 new creator MP3s](../authoring/library/licensed-audio/provenance/expansion-mp3-decode.json), [22 new MP3 derivatives and their OGG sources](../authoring/library/licensed-audio/provenance/expansion-derivatives.json), and [30 retained runtime MP3s](../authoring/library/licensed-audio/provenance/retained-runtime-decode-20260921.json), with byte pins unchanged. Thus all 70 now have technical native-decode evidence; none has listening approval. Final import runs the chosen browser's media probe and storage checks.

The separate MP3 preview staging check verified all 70 source/delivery hashes, creator-license evidence, exact permission policies, attribution and conversion lineage, followed by output readback. Its [preview-only authorization](../authoring/library/licensed-audio/preview-authorization.json) is distinct from the unchanged, empty [game publication list](../authoring/library/licensed-audio/publication.json). Staging does not prove public deployment, full browser playback or musical suitability. Full-track and repeated listening, transitions, loop seams and the in-game mix remain pending before catalogue integration.

The [public delivery audit](verification/music-publication-2026-09-21/public-delivery.json) verifies all 70 MP3s and eight served metadata/site files on GitHub Pages.
