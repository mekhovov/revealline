# Common Couch mode choices

This internal P03 work package shares the Solo / Versus / Team mode row across the two existing Couch pages. It does not replace their distinct setup, mechanics or Start/Resume owners, and it does not complete the broader common-lobby or Title design. [Scoped evidence](verification/cross-mode/p03-lobby/README.md) records the exact candidate on `1f53e829de7ec5db387ef5803b3622a10816e028`.

`mountModeChoices({ root, current, actions })` in `game/ui/mode-choice.mjs` receives an existing navigation container, a fixed `solo`, `versus` or `team` value, and the two existing destination anchors keyed by mode. It validates the required anchors before changing their contents, then places the three choices in the same DOM order. The current mode is a static span with `aria-current="page"`; it has no href, tabindex or activation handler. Selecting it cannot restart an attempt.

The presenter owns labels and presentation only. It accepts no URL, creates no departure handler, polls no input, and cannot start, pause, resume or save a game. Preserve the exact existing anchors and their hrefs, IDs and listeners. Versus keeps the A1/A2 departure owner and captured v2 Solo return. Team keeps its fixed-action discard owner and validated v1 return when applicable. A mode change does not create a return stack or propagate one mode's hint into another.

Team moves the same `coop-mode-actions` node between `coop-lobby-modes` and `coop-pause-modes` through `placeTools`. The row is hidden during live play and belongs to the active panel while paused or showing a result. Keep the existing navigation root, Stay opener and explicit Resume behavior; do not clone links or proxy-click hidden controls. Versus keeps the row inside its main lobby/pause screen. Existing controller allowlists already contain both destination IDs; the static current span is excluded from actionable controls.

`game/ui/mode-choice.css` uses Field Kit font, size, color and target tokens. Its scoped selectors deliberately override the older host anchor defaults, including padding, alignment and current-mode border color. Keep hover/focus and current-state specificity coherent when changing the base rule. The native desktop record checks these computed styles and roughly 64px card heights; it is not a full contrast, zoom, phone or physical-input assessment.

On composition, preserve R5's one-shot initial Ready focus and P08's picture preparation, Cancel/Retry, lease and interrupted Start guards. R5 is not present in this package's base. Title's checked outgoing mode actions are a separate integration: do not infer a Title-origin v1/v2 hint from this presentation helper. Team's header, briefing, palette, artwork and broader P05/P08 work remain separate. No version, strict game format, scoring, simulation, producer approval or public release is changed here.
