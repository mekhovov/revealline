These asset references were inspected in official page source. The exact mark images
have not received visual review in this audit. Observed SVG fill colours are not a
verified brand palette. A publicly reachable file is not, by itself, a redistribution
licence or approval to animate a logo.

The current editions use original fictional presentation and state their independent
educational context. They do not substitute generated artwork for an official mark
or imply community endorsement. Organisation context stays attributed to the
official pages; fictional game workshops are not documentary evidence of real events.

Any later official-mark admission must record the applicable reuse basis, exact source
bytes and hash, a reviewed supported raster derivative, and its immutable asset revision
through the existing asset pipeline. Confirm any animation treatment separately;
this audit establishes no rotation exception. Existing historical appearances and
earned cosmetic references must remain recoverable.

See [the experience research record](discovery-experience-research.md) for other image
eligibility decisions and [the cosmetic reward guide](discovery-cosmetic-rewards.md)
for the shared character-presentation framework.
