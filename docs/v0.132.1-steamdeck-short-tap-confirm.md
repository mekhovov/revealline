# v0.132.1 Steam Deck short-tap Confirm repair

## Hardware evidence

On the Steam Deck's built-in controls in Game Mode Chrome, holding A activates a menu action once,
but a short tap changes a toggle on A-down and changes it back on release. The v0.130.0 DOM-event
transaction guard did not repair this physical behavior.

Valve documents that Steam Input activators can emit actions on start, regular press, long press, or
release, and that a long-press activator can interrupt a regular or release activator. That matches
the reported short-tap/long-hold difference:
<https://partner.steamgames.com/doc/features/steam_controller/activators>.

The Gamepad API exposes sampled button state rather than a physical-gesture identifier. A short
neutral sample followed by another pressed sample therefore previously looked like a new press:
<https://www.w3.org/TR/gamepad/>.

## Repair

The Solo host now owns a Confirm lifecycle until the controller has remained neutral for 120
milliseconds. A press pulse, a one-frame neutral gap, and a release-side pulse are one activation.
A separate press after stable neutral is accepted immediately. Keeping this policy at the host
boundary leaves the shared router's established Versus, Team, remapping, and accessibility timing
unchanged.

The existing DOM transaction guard remains responsible for keyboard, pointer, touch, pen, and click
compatibility events. The host reports the complete lifecycle to that guard, so release events stay
inside the same controller-owned transaction even during the neutral settling interval.

## Verification boundary

Focused lifecycle and guard tests model a short tap as
`South pressed -> neutral -> West release pulse`, a five-second hold, native release clicks, and a
later real press. The real Solo host verifies that Home Sound changes once for the short-tap
sequence and remains usable after stable neutral.

Automated browsers cannot reproduce the Steam Deck's physical Steam Input stream. Final acceptance
requires the public build in a Game Mode Chrome shortcut: tap A on Sound, Start mission, and every
Pause action; then verify long hold and touchscreen input.
