## Content accounting and storage

The complete targets remain **29 wide maps, 116 map/theme originals, 12 victory stories, 40 reserve illustrations, 56 character presentation sets and 24 finished/auditioned tracks**, plus all supporting assets. A picture theme adds no new collision geometry. The public v0.39 production register has **48 produced candidates across twelve proposed physical families**. Countercurrent's integrated candidate reaches **60 candidates/fifteen families**, leaving 56 picture targets and fourteen map slots; it confers no human quality approval. Moving Edges adds twelve separate source candidates outside that runtime count. Original role art, proof routes and generated prompts do not count as completed animation sets.

The existing 36 external originals plus all 24 source tracks total **243,656,792 bytes (232.37 MiB)** before metadata/staging; Countercurrent would increase that combination to **275,349,293 bytes (262.59 MiB)**. The shared 256 MiB media budget and twelve installed-pack slots must not be silently increased. Optional advertised chapters, installed pack slots and resident original media are separate counts. A granted or denied storage-retention request does not add offload support. Protect originals needed by older profiles and retain first-earned history; no automatic eviction, reset or cross-profile mutation is authorized by this plan.

## Useful follow-ups discovered during verification

1. Collection now has a separately verified source improvement that distinguishes picture best score from level best medal and preserves the original earned receipt. Source tests and the real retained v0.40 profile preview passed; adoption in a frozen release remains pending.
2. Teach each new pressure role through a short readable scenario before stacking threats. Include a brief reason for failure and visual counterplay in Field Guide.
3. Preserve chapter selection and progress when browsing large catalogs, and expose download size/readiness before installation. Never replace an active flight merely because a card is focused.
4. A separate touch steering-hand preference is being implemented. It moves the original pad/control groups into matching visual and focus order, preserves arrow orientation and arena size, and does not enable controls when Auto/Off hides them. Confirm the complete journey on actual hardware.

These follow the primary guidance in [Apple game controls](https://developer.apple.com/design/human-interface-guidelines/game-controls), [Xbox focus/navigation guidance](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/112), and [browser storage/eviction documentation](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria). The [official XPOSED Reloaded listing](https://store.playstation.com/en-us/product/UP2538-CUSA28099_00-XPOSEDRELOADED01) supports the exposure/unlock premise; exact enemy timings and release behavior require separate observed evidence.

## Tracking and publishing

Every item records ID, priority, status, player-visible result, evidence, playable version and remaining issue. The current sequence is **finish v0.40 → archive v0.39 and qualify Countercurrent → compatible historical reading/offload → optional albums → remaining maps/roles/stories → full browser/device gate → native distribution**. Independent authoring and source tests continue alongside release checks.

Each complete logical feature receives a Git commit and a new immutable release. Delivery requires source gates, frozen artifact/native review, PR CI/merge, Pages deployment, public verification and actual public play. A source-only commit is labelled as such until those gates close. Keep previous versions and unsuccessful attempts; do not retag or overwrite them. Update shared workflow, relevant AI skills, prompts and CLI examples when an interface changes. Evidence for a narrow slice never marks the entire phase complete.
