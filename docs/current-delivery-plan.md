6. Add an optional plain, non-stylized font alongside the pixel default, then qualify text scaling across title, HUD, warnings, dialogs, guide, collection and error messages. [Microsoft XAG 101](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/101) recommends a plain-font option and scaling through 200%; current Standard/Large checks do not establish that coverage. Measure rendered glyphs and layout at intended display sizes instead of equating CSS font size with readable character height.
7. Extend the complete-journey matrix to stick and D-pad menu navigation as well as keyboard and touch. [Game Accessibility Guidelines](https://gameaccessibilityguidelines.com/ensure-that-all-areas-of-the-user-interface-can-be-accessed-using-the-same-input-method-as-the-gameplay/) recommends the same supported input methods throughout gameplay and menus. Preserve clear focus, context-sensitive Back and deliberate Resume across every screen; a navigable flight alone is insufficient.

The already-reviewed [Apple handheld game interfaces transcript](https://developer.apple.com/videos/play/meet-with-apple/243/) supports adaptive components, safe areas, readable text, reachable controls and scrolling instead of shrinking content. Its platform-point guidance and analog examples are design references; they neither certify our CSS on a phone nor change direction-only Arcade rules. [Microsoft XAG 112: UI navigation](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/112) supports focus that follows the visible layout, digital navigation and consistent Confirm/Back without traps. Use those principles for native selects, control-group reordering and scaled text, then verify actual player journeys. The [WWDC26 touch session](https://developer.apple.com/videos/play/wwdc2026/358/) is further design support, not adoption of Apple's native framework. [Browser storage documentation](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria) does not establish the cause of this project's retained-data incident.
