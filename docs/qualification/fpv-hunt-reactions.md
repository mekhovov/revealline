# Native SIM Hunt reactions

Native FPV World contact catches now drive the shared contextual reaction director. Moving native patrol targets use the Patroller family; stationary targets use Lookout, matching SIM artwork. No additional arcade behavior or combat is inferred from a target's name. EN/UK captions, portraits, generated speech, shared reaction preferences and replaceable voice recordings use the existing services.

Each accepted flight step is observed before the next step, including a successful final catch. Restores seed the previously caught IDs and tick; verified playback is silent. Pause, replacement, master mute, dialogue-volume zero and native danger interrupt speech. Only one dialogue source owns the page's channel. Flight simulation, timing, replay identities and result evaluation are unchanged; speech preparation is asynchronous and never delays flight or results. The dialogue controls live under **Hunt target reactions** in the flight options.

## Unchanged package limits

The package retains its 104-file and 16 MiB limits. A deterministic projection combines the shared reaction services with four existing canonical presentation utilities (audio, hangar, actor editor and progress presentation). Persistence, replay and simulation remain ordinary native modules. The projection preserves isolated module scopes, hashes every projected source and embeds the exact eight supported Patroller/Lookout clips plus sixteen existing fallback clips. Tiny original portraits are embedded too. It never fetches a missing voice outside the package.

Canonical sources remain authoritative. Regenerate with `node scripts/refresh-fpv-reaction-runtime.mjs`; `--check` verifies exact generated bytes and is included in `npm run validate`. No canonical source or licensing record is replaced by the projection. Existing voice-library integrity checks and decoded-cache budgets still apply, and Studio replacements retain their original stable line IDs.
