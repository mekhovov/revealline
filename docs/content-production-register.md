The [production snapshots](../authoring/production/index.html) and [CLI guide](../authoring/production/README.md) expose current slots and outstanding checks. Compilers and manifests are authoritative for exact admitted owners and dependencies. Do not infer current publication counts from an old release's totals.

A retained picture's original payload and attribution remain unchanged. When a shared source document is projected to a smaller catalog, it receives a new content hash and an explicit migration record; it is not labeled as the original verified release. Historical execution evidence does not automatically certify a derived document or rebuilt artifact.

Run the selected compiler's verification and the production dependency validator before publication. Inspect the generated artifact in the browser, including reduced motion and the overlays used during play. Artwork registration alone does not establish mission quality or human accessibility.
