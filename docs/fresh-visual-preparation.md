## Ownership and recovery

A dedicated preparation controller cancels initial visual readiness together with picture readiness. Result and chapter preparation tickets own any newly prepared visual lease until commit. Cancellation, stale completion, navigation, focus loss or required-asset failure must not start a new flight, advance its timer, discard the accepted result or overwrite a saved attempt. Unadopted resources are released; an adopted lease remains independently owned until that attempt retires.

A missing declared collection is an explicit preparation failure. Successful loading of the decorative page presentation does not authorize a fallback or a different revision. Cancellation keeps a deliberate Retry available. Fresh preparation uses selected-theme wording; restoration uses saved-theme wording.
