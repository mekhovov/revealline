# Embedded practice navigation

A Field Guide or enemy Workshop lesson is owned by its parent page. The parent creates a same-origin practice URL with an unpredictable session token, and validates the exact child window, origin and token before accepting Return. The child remains reward-free throughout; changing its menu cannot acquire campaign write authority.

The lesson uses one explicit **Return to field guide** or **Return to workshop** action on its briefing/pause/results overlay. The duplicate Main menu action is hidden. The logo uses the same existing Return action. Its Missions header opens only the current authored lesson brief; More chapters, Mode and campaign selection stay hidden. Closing the brief restores its opener and never starts or resumes the flight.

Only a validated embedded return action opts into this navigation. Standalone Playground previews retain their existing menus, Controller practice keeps its separate focus bridge, and First Flight keeps its lesson menu and End course lifecycle. Ordinary Solo menus remain unchanged. No new message format, parent authority, save format or simulation rule is introduced.

Maintenance example: launch a Field Guide lesson, open Mission brief and return with Escape, then open Missions and verify only the same brief appears. Return by keyboard, controller Confirm and the logo; the parent must retire the iframe and retain its guide selection or unsaved Workshop draft. Repeat from a paused exposed cut, confirm one return message and zero campaign writes, then recheck ordinary Solo and First Flight. Model tests do not replace browser or physical-device qualification.
