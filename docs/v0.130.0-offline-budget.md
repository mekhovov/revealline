# v0.130.0 offline budget repair

The first merged-source v0.130.0 freeze failed the unchanged 64 MiB offline-core guard. The
measured inventory was 75,358,267 bytes across 1,079 files after the accepted 8,641,768-byte
Shchedryk opening recording entered the core.

`homeward-skies.json` is an indexed, explicitly installed Library pack whose 11,371,849 exact
bytes remain in the hosted site, distribution ZIP and manifest. It is now declared in
`optionalOffline`, alongside the existing installable FPV packs. This removes only its automatic
service-worker precache entry; it does not alter the pack bytes, campaign identity, progress,
pictures, mastery records, installation flow or removal behavior.

The complete production build now measures 64,015,743 bytes across 1,078 offline-core files,
below the 67,108,864-byte limit. Its manifest still carries the exact 11,371,849-byte Homeward
Skies payload with SHA-256
`4793e07a45484238bae483e2a2e9354c6d29e0ad2ba2d8d708169bd9e0250b8b`, while the generated
service-worker inventory omits that path. Homeward Skies must remain downloadable and installable
while online, and an installed copy must retain the existing offline behavior.
