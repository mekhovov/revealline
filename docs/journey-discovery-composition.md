# Journey and chapter discovery integration

This joins Journey's opt-in direct mission flow with optional Solo chapter discovery. It is source integration guidance, not release acceptance.

- Resolve a mission from its exact authored pack, then apply the chosen difficulty without replacing that owner with the first equal simulation identity.
- Preserve world-download and result-preparation cancellation. Adoption keeps the verified current attempt until both gameplay and its exact image are ready. An old request cannot clear newer controls, resume after focus loss or award a second result.
- Keep both prepared-attempt contracts: world selection resets authored theme/music choices; direct Next and Retry retain their intended result and selection behavior.
- Contain registered Practice return before dispatching Journey's Missions callback. Pause/brief/Back preserves the existing cut and requires explicit Resume.

The combined validation runs the complete Journey model, authority and host files, optional-world Play and result-continuation files. Separate full Practice briefing and controller-practice pause files cover both turning modes and held-input neutralization. These are finite browser/controller models; actual browser navigation, physical hardware, audible media and public release qualification remain distinct gates.

The authentic authored-picture check validates decoded width/height and natural dimensions. Test Image doubles must model all four from the embedded original header. The initial integration failure and its fixture correction remain recorded; no runtime validation was relaxed.
