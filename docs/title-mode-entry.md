# Title mode entry — P03-M candidate

The Solo title presents Solo as the current mode, plus real Versus and Team links. The shared presenter from P03-L labels and orders these existing actions; the host still owns navigation, pause, saving and starting. This internal P03 work package starts at `5aceb1b` and uses presenter commit `8078796`. It does not accept a public phase or change the First Signal default.

| Entry and state                   | Action and return                                                                                                                                                                    |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Title, ready or finished          | Versus opens `couch/?return=solo`; Team opens `couch/relay-rescue.html?return=solo`. Neither starts a run. Their Back route opens Solo Title.                                        |
| Title, unfinished ordinary flight | Pause and verify the existing flight using the shared departure owner. Stay keeps the attempt and actual Title opener. Explicit Leave uses the same fixed route.                     |
| Title, pending Start              | Retire the launch before requesting departure. A late picture cannot start or claim focus.                                                                                           |
| Title, pending saved Continue     | Cancel the restore intent. Its busy cleanup can temporarily refuse departure; a fresh mode action works once cleanup completes. Stored bytes and the current run stay authoritative. |
| Missions, Team or Versus          | Existing v1/v2 exact-selection return contracts remain unchanged.                                                                                                                    |

Title departure writes no return hint and does not make session storage a prerequisite. The origin is the retained Title visit, not a hidden Missions link. Closing/reopening Title, changing its active child, a newer action or lifecycle suspension retires that origin. The host checks the origin with its run, recorder, selection, library generation, abort owner and foreground before saving or navigating. Stay restores the actual opener only if its visit remains eligible.

Unfinished-flight retention reuses the existing replay verification, writer, backup lock, saved-slot comparison and bounded readback. A quota/readback refusal says the flight is session-only; explicit Leave may lose it. Changed saved bytes after verification require another deliberate Leave and remain untouched. Pausing, returning or closing menus never silently resumes the flight; the separate named Title Continue keeps its existing explicit behavior. Modified link gestures retain native defaults.

Generic modal restoration still removes a closed dialog from the stack while inactive. It schedules opener restoration only from a foreground close and checks foreground again in the queued callback, alongside existing current-top, reopened-dialog and newer-focus guards. This is not an observer for every blur/return occurring between those checks. Title separately owns persistent cancellation of its departure intent.

The candidate includes actual host coverage for fixed routes, Immediate/Grid cuts, Stay/Escape/controller Back, pending media/restore, foreground and stale-origin changes, save failures and newer writers; modeled key defaults are not physical keyboard/controller certification. The existing paused Workshop challenge test is updated to explicitly confirm R3 replacement before checking its original ready/focus/no-advance result.

Combined P01/P02/P03/P05/P08 qualification, the remaining responsive/browser matrix, public/offline acceptance and physical-device evidence remain separate. The M preview uses Git `5aceb1b` Couch runtime with the two exact shared presenter files; it does not certify the successor Couch L/R5 composition.
