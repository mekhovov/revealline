01 / FRESH ACTIVATION

A held switch is not a new command.

S3–S6 act on a fresh OFF → ON in flight. Menu confirmation and Back use a fresh ON → OFF cycle. After pause or reconnect, reset active controls before reuse. Switch numbers show roles; setup uses the player’s actual control names.

02 / FLIGHT STATE IS EXPLICIT

OFF pauses. ON requests flight.

Flight OFF opens the paused deck. Flight ON can arm or resume only from the resume-ready root after checks; it cannot bypass nested pages or settings capture.

03 / SEPARATE PAYLOAD COMMANDS

Deploy or arm. Then detonate.

S5 deploys the selected payload or arms a drone charge. S6 is a distinct detonation command. The paused menu provides the same choices without any chord or double tap.

Design exploration only. This file uses local illustration and example feedback. It does not read a controller, connect to a radio, save SIM preferences, arm a drone, fire a weapon, or implement these controls in the game.
