# Same-map Gentle difficulty — proposed bounded next increment

Accepted for isolated implementation after root and peer review, 2026-09-12. This is a design contract, not a completed implementation or release claim. ROOT v0.20 source and verification inputs stay frozen. This adds one useful alternative to Standard solo campaign play, including the installed illustrated chapters and Sentinel. It does not extend Couch, Challenges, First Flight, or arbitrary Practice scenarios in this increment.

## Player benefit and evidence

The current `game/challenges.mjs` Open skies option changes a separate generated daily board: slower bouncers, five lives, and a lower coverage target. Authored campaign maps have no equivalent choice. First Flight and Practice teach the controls but deliberately grant no campaign rewards. Players who want the original pictures can therefore remain blocked after learning the mechanics. Same-map Gentle play addresses that gap more directly than another diagnostic or a result-to-Theater shortcut.

[Microsoft XAG 108](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/108), checked against the primary text on this date, recommends difficulty choices that reduce barriers to the same game content, descriptive names, and saving. It distinguishes a separate creative/practice experience from difficulty within the main game. This proposal implements two presets and retains existing saves; it does **not** satisfy its broader recommendations for four or more presets, individual assists, ultra-low difficulty, or changes during an attempt without losing that attempt's territory. Human accessibility, difficulty balance, and enjoyment remain unmeasured.

## Two finite presets

**Standard — “The original mission rules. Earn Standard scores and optional equipment seals.”** This is the default for old profiles. Its exact level data, roster, identities, outputs, timers, and existing acceptance proofs remain unchanged.

**Gentle — “Explore the same pictures with more lives, slower moving hazards, and fewer limits. Pictures and chapter progress count; scores are separate and equipment seals require Standard.”** A details list shows the actual applicable changes for the selected map:

| Existing field                                             | Gentle v1 transformation                                                                                                                          |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Normalized `rules.lives`                                   | `max(original, 5)`; never reduce an authored allowance                                                                                            |
| `timeLimitSeconds`, `cutTimeLimitSeconds`, `maxTrailCells` | `0`, using their existing unlimited meanings                                                                                                      |
| Bouncer `vx`, `vy`                                         | Multiply each by `0.6`, preserving sign and zero                                                                                                  |
| Border patrol `speed`                                      | `(speed ?? 4) * 0.6`, matching the current core default                                                                                           |
| Legacy lane boss                                           | With existing defaults `w=1.5`, `a=0.7`, `p=6`: `w'=min(10,2*w)`, `rest'=min(60-w'-a,2*(p-w-a))`, `period'=w'+a+rest'`; active duration stays `a` |
| Sentinel descriptor                                        | Double `shielded.warningTicks`, `shielded.restTicks`, `exposed.warningTicks`, `exposed.openTicks`, each capped at the existing 7,200-tick limit   |

All other mechanics remain the original recipe: coverage, required objectives, topology, spawn, seed, supplies, signal regions, actor counts/radii, movement, Boost, class equipment/capacity/cooldowns, grace and recovery, score formula, time-medal thresholds, lane widths/active durations, initial/transition delays, Sentinel release threshold and isolation rule. Ordinary contact and self-crossing can still cost lives; Gentle is not invulnerability or a guaranteed win. Boss warnings and openings still have clocks. No new behavior names, state flags, events, mutable run edits, altered `FIXED_DT`, or global slow-motion multiplier.

Create owned bounded data, apply these finite transformations, then run the existing full content/core validators. Unknown types/versions or an invalid result reject before selection; no permissive fallback. Verify the formula at minimum/maximum schema boundaries, including absent patrol/lane defaults. The descriptor version `gentle.v1` becomes immutable when shipped; a future tuning revision needs a separate derivation while retaining old saved-flight reconstruction.

## Exact execution identity, shared access

Introduce a pure `game/campaign-difficulty.mjs`, independent of DOM, packs, storage, and mastery modules:

- `resolveCampaignDifficulty(value)` accepts only `standard` or `gentle`.
- `createDifficultyContext(baseCampaign, mode)` returns an owned context `{mode, policyVersion, baseCampaignKey, campaign, campaignKey}`. Standard is an exact owned copy, with no added level fields.
- Gentle derives a stable token from `{policyVersion:'gentle.v1', baseCampaignKey:campaignKey(baseCampaign)}` using existing `dataIdentity`. Its campaign ID is `gentle-v1-<token>`, revision `1`; each level keeps its original ID/name but receives a bounded revision `gentle-v1-<dataIdentity({token,levelId,sourceRevision})>` plus the transformed fields. Retain the original campaign title/name without appending text inside bounded content fields; UI adds the mode label.

The changed **level revision** also makes accidental calls to Standard `awardCompletion` reject, while campaign/board hashes partition the full actual rules. The current replay v3/core v2 and replay v4/core v3 pairs already serialize and verify the derived levels and roster. Session v1 already carries the exact campaign key. No core, replay, session, pack, or score-record format bump is needed. Never relabel a Gentle summary as Standard or synthesize a Standard completion to unlock a picture.

Keep two existing library progress entries and score partitions where both modes have been played. `recordLibraryCompletion` runs against the actual execution campaign. Gentle awards never rewrite comparable Standard aggregates, medals, score values, or mastery records. Existing bounded retention remains: the shared 1,000-score cap and ordinary merge policy can evict older Standard or Gentle rows. Do not promise permanent score retention, introduce another budget, or clip results; test mixed-mode additions and backup merges at the cap. Gentle gets its own truthful medals/scores; no Standard seal observer/award submission is installed for Gentle, including restoration. Existing seals remain visible under their original definition and setup. Prefixes or user-provided mode labels alone never establish a recognized difficulty: match a context reconstructed from the exact installed base campaign and roster.

Add a separate pure **access projection**, not a persisted award record: union distinct declared map IDs cleared in either exact context. It supplies next/previous mission access, completed-mission replay access, chapter continuation, the one-clear and `min(4,mapCount)` appearance tiers, and overall chapter completion. Unknown IDs, unrelated derived campaigns, changed base recipes, and archived editions do not contribute. Do not union best times/medals/clean flags into Standard stats. Noncompetitive first-clear/pathfinder/full-chapter achievements may use the union; clean/gold achievements and score displays retain an explicit mode label. Live appearance notifications use the union before/after a real new completion; loading/importing/Undo do not emit them.

Gallery groups recognized Standard/Gentle entries for the same base campaign/map/theme into one picture card. Keep the stored rows, histories, original art bytes, and existing capacity limits; the view reports which modes were completed and offers labelled results, preferring Standard for the primary result when present without comparing cross-mode scores. Gentle-only wins show the full original painting and celebration and unlock the next original mission. Replaying a result uses its mode; an explicit choice can start the other. Missing-pack records remain archived/unavailable rather than being guessed as Standard. A later art-only pack replacement resolves both contexts to the current sidecar, just as original gallery records do today.

## Host, persistence, and transition contract

Separate visible base-campaign selection from execution-context lookup. `catalog()` currently serves selectors, restores, gallery, and imports; do not simply insert duplicate Gentle campaigns into all four. Keep Pack/Level lists at the existing authored-map count. Build a bounded internal context registry from trusted installed entries, mapping both execution keys to the original visuals/music/source pack. Do not feed derived entries into authored mastery registration or broaden its limits. Detect conflicting exact keys before adoption. Rebuild this registry on pack replacement, import, and Undo; release old asynchronous work through current generation guards.

Add `preferences.campaignDifficulty:'standard'|'gentle'` using the established omitted-only additive migration in library v2. Missing old data becomes Standard; present invalid values fail. Preserve existing preference merge/Undo/session-only behavior, and adopt the actual merged value. This is forward-only preference compatibility: older strict applications may reject the added preference, although replay formats remain readable. Existing record/progress schemas and all old Standard values remain unchanged.

A native labelled Difficulty select lives beside the campaign setup, with a readable description and a compact mode cue on Ready, Pause, results, saved-flight previews, and score views. It works with current keyboard/touch/controller navigation and reading surfaces. At Ready, a selection prepares the same map at tick zero without starting. While running, recovering, or paused, show the current mode plus “For the next attempt” selection; choosing it changes only the next-attempt preference. **Resume always resumes the unchanged current mode. Retry explicitly starts a fresh attempt in the selected next mode**, with fresh run ID, starting loadout, and an adjacent reset consequence. Selecting another mission follows the existing explicit replacement flow. Changing difficulty alone never overwrites the suspended slot or discards current territory.

On successful load, infer current mode from the verified exact execution context, show it, and start paused with neutral input/Boost latch released. It overrides the current attempt regardless of the preference; display any different next-attempt mode clearly. The same rules apply during recovery and at an active cut. Save/export retains the actual campaign key and actual derived replay bytes. Ready stored export keeps its read-only behavior; missing-pack rescue remains replay-only export, with loading blocked until the exact base campaign can reconstruct the saved variant. Removal, different-physics replacement, and malformed metadata never downgrade validation. Complete backup includes both existing progress branches and the preference through its current transaction/Undo path. No extra storage slot, mid-run conversion, automatic checkpoint rewind, or reward from loss/Practice/Theater.

Long Gentle play has two distinct existing boundaries. After the 30-minute recorder budget, play and ordinary local picture completion can continue within collection limits, but a discarded recorder cannot produce a recoverable save or replay. Progress/gallery/score validators separately cap elapsed time at 7,200 seconds: a later win can reveal its current picture but cannot retain that completion in the library. Keep the existing failure atomic, show a truthful collection-update warning, and do not claim the picture was collected. State both limits in Help; never clip time, raise formats/budgets, impose a new punitive mission deadline, or promise unlimited saving/collection. Simulation seconds continue at fixed ticks. Audio, gallery celebration, reduced-effects, and DOM animation use their existing presentation clocks; a slower hazard never slows controls or creates a second clock source.

## Small implementation and acceptance sequence

1. Land pure transformation/context and access-projection helpers plus focused tests. Pin all existing Standard campaign/board identities and exact replay outputs. Derive every shipped map, validate original geometry/recipes/sidecar references unchanged, and test every actor/default/boundary transformation. Test hostile data ownership, forged/wrong-base contexts, and stable derivation IDs.
2. Integrate internal context registry, preference, save/load, and completion access before UI polish. Verify real Gentle wins in both steering policies, independent Standard score/mastery preservation, Gentle-only picture/chapter unlock, mixed-mode duplicate-clear counting, out-of-order restored clears, capacities, backup merge/import/Undo and remove/reinstall. Test exact replay + paused restore at live-cut/recovery boundaries for both core versions, including a wrong original campaign rejection. Use an actual host regression to prove changing next-attempt difficulty during a live cut/recovery leaves raw suspended-slot bytes and current run/recorder identity intact; reusing `pause(true)` would autosave and violate this contract. Clear held controller inputs independently of autosave. Test the 30-minute recorder and 7,200-second collection boundaries separately. Old frozen fixtures remain untouched.
3. Add the setup cue and grouped gallery/result labels. Retain actual input/router/reading contracts. New public legal-input traces should prove all 29 shipped maps can finish in Gentle in both policies; these are new proofs, not regenerated Standard goldens. Include Sentinel missed openings/recovery and preserved required objectives. No assertion that multiplying an old route necessarily preserves its capture outcome.
4. Browser acceptance: actual Standard→Gentle Ready selection; failed Standard attempt→explicit Gentle Retry; mixed-mode chapter completion; save/reload at active cut and Sentinel recovery; missing-pack export/reinstall; old/new picture grouping and four celebration families with reduced effects. At actual 320×640, 844×390, and 1280×720, confirm readable mode/reset descriptions, reachable controls, no horizontal overflow, controller neutral transitions, and source-specific export cancellation. Emulated controllers and CSS viewports do not establish physical-device accessibility or human difficulty balance.

Stop for review if implementing the projection requires weakening existing completion/restore validators, changing original identity, raising storage budgets, or making a missing context authoritative. Those are architecture changes beyond this finite preset.
