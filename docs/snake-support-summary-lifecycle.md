# Snake support-summary visit ownership

This phase adds shared lifecycle hooks and applies them to Snake’s existing Settings Data report. Leaving Data for another category, compact navigation, a modal, a breakpoint change, or an inactive page retires the previous observation. Returning to Data requires a fresh Prepare action. An export already requested retains its single owner; its eventual result cannot label a newer report. Desktop bookkeeping changes that leave Data visible retain the current report.

The host reuses the existing Settings, dialog, focus and page lifecycle owners. Nested Recovery, tool and music dialogs notify only a newly committed native open. Rejected or already-open attempts do not notify; a successful open still retires the report if initial focus immediately closes the child. No new controller polling, readiness claim, save permission, collector field, locale text or persistent state is introduced. This phase integrates Snake only; other host integrations are separate work.
