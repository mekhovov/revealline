# Field Kit title palette revision

Two separate v2 title derivatives match the reveal family's fixed 36-color palette and integer clusters. Landscape is 960×540 from a 320×180 sampled grid; portrait is 540×960 from 180×320. Both enlarge 3× without fractional clusters, total 49,796 PNG bytes, and stay at `quality.stage: produced` until real menu acceptance is recorded.

Native visual comparison found that v1's fine hardware and orchard texture looked smoother and denser than the reveal family. V2 keeps the FPV camera, four-motor silhouette, bench, goggles, open orchard door, and quiet menu area while simplifying that texture. The camera's finest details are reduced. V2 is recommended for the compiled presentation after testing the actual desktop and portrait menu. The original P4/v1 CSS fallback remains a separate preserved revision.

`node scripts/prepare-field-kit-title-v2.mjs --check` reproduces the preparation and verifies exact original, historical v1 and v2 hashes. Without `--check`, it creates missing new files, refusing to overwrite a differing revision. The source metadata is `authoring/library/fpv-field-kit/prepared-scenes-v2.json`; source-checkout comparison is `authoring/library/fpv-field-kit/prepared/titles/review.html`. These source paths describe authoring artifacts; they are not guaranteed public release files.

Full generation prompts remain in the existing title source README and portrait source JSON. The new preparation reads their pinned original bytes, applies the same centered aspect crop as v1, samples pixel centers, maps colors using the reveal palette's weighted RGB distance without dithering, and enlarges on an integer grid. All operation parameters are recorded. It does not edit or regenerate an original, does not alter any v1 artifact, and does not claim that downsampling made the source a hand-authored pixel drawing. The production compiler may copy the selected v2 image into its hashed asset directory; source derivatives need not ship twice.
