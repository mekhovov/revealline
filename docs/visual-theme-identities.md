# Accepted visual-theme identities

This module slice depends on catalogue foundation patch `f73ee4f8`. It changes no runtime, save, progress, network or storage authority and exposes no theme selector.

`prepareCampaignVisualThemeContext({entry, level, association}, {signal})` consumes an actual `createExecutionCatalog` entry and selected authored execution level. It re-derives the standard/gentle context and verifies the existing base campaign key, execution key, policy and full projection. It hashes the original authored level with canonical JSON and the existing presentation SHA-256 helper. Solo, Versus and Gentle retain that original identity; transformed runtime levels never become artwork owners. Journey and dated challenges must use separate adapters.

`prepareTeamVisualThemeContext({pack, level, association}, {signal})` validates the accepted pack and exact full level membership, then hashes the entire pack and selected level. Historical numeric revisions stay numeric; foundation strings stay strings. The two starter arenas reproduce their existing reviewed binding hashes. Presentation stays outside historical pack schemas.

Association `{editionId, contentThemeId, mode}` comes from the host's code-owned content catalogue, not an upload or cosmetic selection. The adapter validates shape and mode, not authenticity. Existing installation verification must finish first. Pass the selected authored level, never the mutated simulation run. Inputs are bounded and owned before asynchronous hashing; pre/post-hash cancellation cannot return a context.

Tests cover all First Signal levels across two modes and two difficulties, both starter Team hashes, an official authoring-template pack through `readCoopPack`, edited owners/levels, invalid geometry, cross-mode misuse, cancellation, hostile data and exact catalogue coverage. These are module checks, not visual review, physical-input or release evidence.

Journey is the primary player flow and remains required in this workstream. Add its own compiler/policy identity adapter and explicit catalogue owner before theme selection or complete-content claims. Verified assets, staged attempt resources, complete retained pins and the two-collection benchmark also remain required.
