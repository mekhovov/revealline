The display owner survives persisted departure and rereads current shared/system settings; terminal departure disposes it. This does **not** promise that an earlier selected profile or prepared link survives a full Recovery return. No profile migration, repair, restore, writer permission or backup scope is added.

The page reuses packaged Field Kit fonts, semantic text sizes, square controls and the keyboard/controller focus treatment. All new runtime dependencies are already under the existing `game` distribution include. No authoring-only helper, external font service, new art or build/version change is required.
