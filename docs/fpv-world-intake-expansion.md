# Free-world intake: Coaster Practice Park

## Candidate and provenance

The next bounded optional-world candidate is an original **Coaster Practice Park** assembled from [Kenney's Coaster Kit](https://kenney.nl/assets/coaster-kit), not a pre-existing complete world and not a streamed regional world. The official pack lists 180 models and CC0; the exact downloaded archive includes its own CC0 license text. The source receipt in `authoring/fpv-worlds/free-worlds/source/downloads.json` pins the original download URL, archive SHA-256, model list and license text. Only static GLB geometry and embedded palette textures enter the player; source scripts are never executed.

The authored composition has a broad central beginner avenue, twin steel loops, a timber hill, flume, station, stalls, entrance arch and trees defining the perimeter. Free flight can explore the ride geometry within the existing 160 × 160 metre course bounds. This is a compact preview of the planned large Coaster Park, not delivery of the 4 × 4 km regional target. Rides are explicitly described as static scenery. Both Self-level and Acro remain available.

The scene is generated by the existing offline builder. Per-world EN/UK descriptions are now supported so this map does not claim to be a generic building layout. Existing layouts and world identities are unchanged.

## Reproduction

Use the pinned `authoring/fpv-worlds/package-lock.json` dependencies. Download the exact archive from its receipt into a preparation directory, verify its SHA-256, and safely extract its GLB models and license. Do not extract on top of changed local source files.

```sh
node authoring/fpv-worlds/free-worlds/build.mjs SOURCE_DIRECTORY authoring/fpv-worlds/free-worlds/source/downloads.json cc0-coaster-park
node authoring/fpv-worlds/free-worlds/qualify.mjs cc0-coaster-park
node authoring/fpv-worlds/free-worlds/qualify-coaster-geometry.mjs
```

`SOURCE_DIRECTORY/coaster-kit/Models/GLB format/` must contain the original models. The builder records each placed model's hash, validates the resulting GLB, creates collision, validates the course and verifies pack/editable-project round trips. Qualification flies ordinary commands through the unchanged simulation in both modes and independently replays the resulting recordings. Browser visual/install checks remain a separate publication gate. Do not list this candidate in the default catalogue until that gate passes.
