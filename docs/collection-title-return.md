# Collection returns to its entry screen

Picture collection opened from the title or Main menu keeps that menu underneath it. Opening an earned picture keeps Collection underneath the picture, including while its artwork loads or fails. Back returns to the recreated card for the same picture; closing Collection returns to the original title opener. Collection opened directly over a paused flight retains that flight context.

Replay is an explicit destination: it closes Picture, Collection and the title, then focuses the selected ready briefing without starting flight. Choose appearance closes Collection and the title and opens Missions setup. Existing media-generation guards still prevent stale reads or queued close events from reopening a screen after navigation.

This isolated source correction preserves saved state, completion records, simulation and frozen v0.42. Focused host coverage uses the actual app, shell, library and core with native dialog/controller/canvas boundaries modeled. A legal core completion provides the new earned-picture fixture. Full browser top-layer behavior and touch focus remain native verification work; no release build is included.

The Collection footer names its actual return destination on every ordinary entry: menu, Missions or field. Picture Back retains that label with the underlying Collection. A direct paused-flight visit after a title visit is covered to prevent a stale menu label.

Pictures and search stay in the primary Collection view. Achievements, chapter progress, reading controls and appearance rewards are grouped under the native **Achievements and appearances** disclosure, initially closed. Opening it does not navigate or change a saved preference. Keyboard and controller navigation skip its contents while closed; opening it exposes the existing reader and appearance action.

Closing the disclosure ends active achievements reading without resuming flight. If focus would be hidden inside it, focus returns to its summary while Collection is still open. A delayed toggle preserves later focus or the restored dialog opener. The existing reader still scrolls to the last line, and its first Back/Escape exits reading before a separate action closes Collection.

Pagination appears only when filtered pictures require more than one page. If a focused pager disappears after filtering or a collection change, focus moves to search. Other focus and the picture's stable return identity remain intact.
