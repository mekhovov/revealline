# Reachable language and readable narrow menus

Worlds now places the existing EN/UK language selector in native Settings, where
players can reach it. The selector uses the available width. Mission navigation
uses readable columns on narrow screens, the embedded header scrolls with its
content, and footer actions wrap. At 320 CSS pixels the Settings Close and
Fullscreen controls also wrap instead of clipping.

The change contains four production files: the Worlds HTML, canonical shared
fullscreen CSS, its exact generated CSS projection, and Worlds-specific CSS.
No runtime JavaScript, flight rules, packages, limits or Library downloads change.
