## Next implementation and review

1. **Check a real phone/pad and a short human challenge session early.** Use ordinary native menus, a full readable brief and failure/retry observations before bulk P6 production. Our recommendation applies accessibility guidance on using the same input for gameplay and menus, user-paced text and interactive teaching. It is not evidence that this game already meets every guideline. Continue independent work when hardware is unavailable. [Game Accessibility Guidelines](https://gameaccessibilityguidelines.com/full-list/).
2. **Keep requested seek and observed frame evidence independent.** MDN describes `currentTime` as playback position/seek control; `requestVideoFrameCallback` supplies the presented frame's `mediaTime`, and callbacks can arrive late. Persist the captured PNG, reject invalid ranges, preserve cancellation/epochs, and label the non-callback fallback approximate/unavailable. One decoder's sample does not guarantee another's frame choice. [MDN currentTime](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/currentTime), [MDN frame callback](https://developer.mozilla.org/en-US/docs/Web/API/HTMLVideoElement/requestVideoFrameCallback).
3. **Test text reflow independently of the arena.** Use actual 320 CSS-pixel width with Standard/Large text, long lessons and visible Back/Read controls; do not shrink the lesson to fit unrelated chapter cards. W3C's reflow guidance distinguishes necessary two-dimensional content from surrounding text/UI. Our canvas can preserve its geometry while the briefing reflows; modeled style assertions are not visual or accessibility certification. [W3C Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html).
4. **Then extend stored stories through a versioned contract.** Keep all current v1 `story:null` schemas exact until original-video inventory, reservation/migration, independent segment selection, optional skippable/replayable playback and paired native recovery exist. The [media design](../media-library-design.md#next-video-and-story-slice--proposed) remains a proposal for this part.
