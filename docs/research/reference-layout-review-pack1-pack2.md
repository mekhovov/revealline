map is claimed. These notes were prepared while candidate 9375eb59 qualified;
they are incorporated with the subsequent reviewed source correction.
This supplements, not overwrites, the original observation ledger and file hashes.

All 24 numbered stills from packs 1 and 2 were directly displayed in this task,
6144×2560 originals downscaled by the viewing tool to 2048×853. The observations

## Decisions for the shared framework

- Surface behavior is explicit authored data, never inferred from texture color.
- Geometry families are metadata, not a mandate to ship repeated silhouettes.
- Every proposed chamber layout needs the shared component/anchor preview before
  preview play, including remote empty regions that fill on the next valid closure.
- Difficulty review compares exposed route length, meaningful alternate returns,
  threat domains and escape space. Do not sort solely by actor count or reference
  filename order.
- Studio should report zero-interest cleanup: compare required-objective locations
  and residual eligible coverage after the distinctive interaction. Human review
  still decides whether that cleanup is tedious.
- A foundation changes route possibilities, not earned coverage. Do not reproduce
  the reference HUD's starting percentage as our scoring rule.
- Cosmetic arrow shapes must not compete with the future directional-zone icon.
- Proposals above are provisional. Final disposition needs compiled geometry,
  automated topology checks and real play evidence; no shipped-count quota.
