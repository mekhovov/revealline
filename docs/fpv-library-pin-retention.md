## Evidence and limits

The adjacent JSON records the exact main/library source hash, descriptor pins, ancestry comparison merge bases, timestamps and preserved refs. GitHub commit/content/compare/ref APIs were used without fetching large Git histories. All descriptor bytes were verified; payloads were not redownloaded, since their existing immutable package/source evidence is a separate gate.

This is source reachability evidence, not a promise of permanent hosting availability or a new flight/offline/device qualification. Keep preservation refs while any supported installed or offered revision depends on them. Do not delete them as ordinary merged feature branches. Future offered pins should either have ancestry in retained main or an explicit preservation ref before a source branch is rewritten/deleted. Never silently change an old pin to a new commit merely because content appears similar.
