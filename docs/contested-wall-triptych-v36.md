# Contested Ukrainian wall triptych — `whole-spatial-v36`

Status: implemented candidate; balance review and release pending.

This copy-on-write successor to `whole-spatial-v35` redesigns three existing
Journey identities whose current maps still had no walls. It changes geometry
and mission design notes only. Actors, pressure cadence, foundations, terrain,
spawns, objectives, bonuses, reveal artwork, campaign order and every earlier
edition remain exact.

| Mission           | Cultural vocabulary                                                      | Route decision                                                                                                             |
| ----------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| Side-door bays    | Opishne painted-bowl records inform interrupted contour rhythm only      | Short western mouth during the near patrol's departure, or the longer broken-shoulder transfer to the reversed eastern bay |
| Staggered reserve | Borshchiv embroidery records inform alternating visual density only      | Slowed northern anchor through the western shoulder, or the exposed east repair gap before erosion reopens the route       |
| Crossbar depot    | A Kyiv-area woven-belt record informs separated narrow-band cadence only | Short north-south links across repeated row warnings, or the longer east-west crossbar under alternating axes              |

No source object, ornament, motif, palette, meaning, outline or coordinates are
copied. The walls are original gameplay geometry. They remain blockers, never
return surfaces.

## Acceptance boundary

- Both Solo and Versus resolve the same effective actor, objective, bonus and
  rules state for Gentle, Standard and Expert.
- Every changed map retains one communicating field component.
- A stationary craft survives the first 180 fixed ticks for all three presets.
- `whole-spatial-v35` and every older route retain their prior byte snapshots.
- This candidate is opt-in and must not become the default before human route,
  fairness, cultural and retry-quality review.

Automated checks cannot establish whether either documented route is enjoyable
or whether the visual reference reads authentically. Those remain human gates.
