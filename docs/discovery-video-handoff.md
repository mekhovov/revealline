# Exact clips from Picture Workshop to discovery rewards

Open Picture Workshop’s video tool, inspect a local MP4 or WebM and capture its
poster. **Prepare clip and poster for reward authoring** provides two explicit
native downloads: the complete original clip and the exact PNG capture. Selecting
a playback range does not change the downloaded original. For a physical trim or
conversion, download the existing optional transform output, inspect that new
file and capture its poster before preparing the reward transfer.

The producer checks the inspected clip hash, captured poster hash and the
capture's source binding. It does not play, publish, assign or store the clip, or
approve redistribution. Source replacement, capture, cancellation, page hiding
and disposal release its prepared URLs. The ordinary Picture Workshop does not
import Company authoring or reward-editing dependencies.

The shared **Video discovery** editor in Company Studio and Level/Campaign Studio
accepts six originals: clip, raster poster, English and Ukrainian `.txt`
transcripts, and English and Ukrainian plain `.vtt` captions. Level Studio first
needs the existing owning Company source draft; Company Studio supplies its live
selected draft. Each original must match an approved asset in that campaign's
asset inventory, including dependency and publication classification checks.
Local file names or source assertions cannot create approval. Review rights and
attribution through the existing Company source eligibility process first.
The receiving editor checks the six selected originals independently; it does
not carry the producer's capture history across manual file selection. Review
that the chosen poster and bilingual text accurately describe the selected clip.

Inspection verifies each hash, byte count, supported MIME/header and bounded text
format, then uses the existing muted native video acquisition to inspect actual
metadata. Clips must fit 1920×1080, 120 seconds and the existing 32 MiB limit;
posters stay within 4 MiB and each text file within 64 KiB. All six originals
together must also fit 32 MiB, with the complete edition budget checked again by
the compiler. Captions may not run beyond the decoded clip duration. Native
acquisition is disposed after inspection, including failures and cancellation.

Choose an explicit matching asset for every role and supply EN/UK titles.
Preview uses the existing native reward media viewer and shared audio ownership:
poster and untimed transcript are available immediately, playback requires Play,
and changes or closing release the viewer and URLs. Silent clips still need
useful descriptions and captions; do not invent spoken dialogue. Studio previews
do not create completion, learning or reward evidence.

Apply performs the existing immutable reward edit/rebind operation and writes an
ordinary video payload with six exact references. Reward requirements and engine
identities are unchanged. Source draft export/import, player compilation,
retained reward recovery and Collection reuse their existing media paths. No new
storage, transfer format, earning rule, remote player or decoder dependency is
introduced.

Focused tests cover actual workshop download wiring, exact originals and source
binding, selected rights and audience rejection, caption duration, malformed
text, stale drafts, late cancellation, twenty preview/export cleanup cycles and
Company/Level source round trips through selected player compilation. Native
decode remains covered by the video acquisition tests; modeled host metadata in
Node is not physical-device playback qualification.
