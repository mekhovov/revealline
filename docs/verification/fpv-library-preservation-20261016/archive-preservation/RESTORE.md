1. Obtain this preservation branch and these files from GitHub. Source parent `b65d80f716b8db646bfdf5f714892f1c0f6409b0` and the earlier accepted 8ab source remain separate committed identities. The normal combined child has not acquired independent package/full-player acceptance merely because it is backed up.
2. Sign `gh` into an account allowed to read the draft release. Choose a **new, nonexistent directory** on an available filesystem. The destination's parent must exist.
3. Run `python3 restore-original-archives.py --destination /absolute/new/folder` from this folder. It defaults to the final 21-original manifest. An optional `--manifest` selects an explicitly saved manifest. The helper downloads by asset ID, hashes every byte, checks length/SHA-256, and writes a restore receipt. It refuses an existing destination or output file; failures leave their partial file for inspection. Manual cloud originals restore under `actions-b65d80f7-run38844826436/`; the distinct capacity PR wrapper restores under `actions-b65d80f7-run38844752667/`, each using its original Actions artifact name.
4. The helper restores ZIP originals only. It does not extract archives, recreate `/Volumes/alex`, open a browser, change player databases, build the app or start a renderer/server.
5. If a review runtime is later needed, choose the exact original distribution ZIP and extract it into a separate new empty folder after verifying its manifest hash and safe headroom. The 9213 and 9214 fixture files are preserved in sibling snapshot folders. Their recorded `web/runtime` links originally pointed to alex; a restored review must explicitly point to its newly restored runtime. Preserve the frozen fixture files and their identities.
