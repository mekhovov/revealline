## Implemented behavior

- The qualified live planner considers one- and two-cell closures within its existing 16-candidate / 1,200-tick-per-candidate / 12,000-total-tick budgets. It reserves attempts for short exposure windows instead of spending every attempt on similar large cuts. These small cuts are confined to the qualified live planner; broader improvised scenes retain their original geometric candidate range.
- Fractional capture stops retain real coordinates. The next leg follows its dominant axis, avoiding a brief reversal just to chase a nominal cell center. No craft snap or simulation change is introduced.
- Live search may stop after four attempted candidates once the best fully simulated route captures at least 4% with a bend or 8% with a straight cut; a verified win stops search immediately. Unsafe early candidates still leave the full original allowance available. The [bounded prototype](early-search-prototype.jsonl) completes all twelve cases, and the [work comparison](planning-work-comparison.json) records 458,072 instead of 831,757 simulated lookahead ticks (about 45% less). These work counts do not establish a wall-time speedup under uncontrolled load. The [18 focused planner/Worker tests](early-search-tests.log) pass after adoption.
- A capture pause ends before a nearby enemy reaches the stop. All retained neutral ticks and the next complete maneuver still run through the authoritative simulation. No waiting or movement is assumed safe from terrain ownership alone.
- The shared JSON validator no longer boots the UI translation engine in an isolated Worker. Standalone validation uses a tested English table inside the existing validator file; a booted UI resolves its current live translator, including Ukrainian/English changes. Error limits and validation semantics stay intact.
- Four exact Linux runtime replay alternatives use independently generated and replay-reconstructed checkpoints from [Actions run 38692623491](https://github.com/mekhovov/revealline/actions/runs/38692623491). Their witnessed input traces and installed levels are identical. The Orchard difference includes last-bit timing and multiple checkpoint sections; it is not admitted through the existing enemy-only runtime adaptation. Playback/import verification remains strict. The original files remain unchanged. See [the captured witness](linux-recording-witness.json) and the committed `ci-variant-provenance.json` for exact summaries and changed sections. Current Linux CI remains a separate acceptance check.
- Optional Legacy share-link lookup now builds exact public owner/edition links from the shipped metadata index. It does not compile unrelated playable Journey/Versus/Team catalogues after Start. A cold unrelated compilation had made the requested demo recording time out; fallback correctly selected a locked map, so the old failed-save test never reached a save attempt. The [temporary diagnostic witness](failed-save-temporary-trace.log) records that boundary; its temporary source instrumentation was restored byte-for-byte and was never committed or treated as qualification.
- Fresh start on an already-owned, original Legacy campaign reuses the existing checked world-launch path. It still authenticates the source, preserves locked-level practice, requires saved-flight replacement review, respects cancellation and arrives paused at Ready. Journey and other ownership transfers retain their existing library route.
