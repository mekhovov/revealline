# Pause Sound integration

Solo now offers Sound inside Pause, using the existing master authority. Its stable accessible name and pressed state match Home, Versus and Team. The toggle never resumes the flight or changes music transport.

The nine-file integration cohort passes 77/77 on each of Node 20.19.5 and Node 22.22.2. Tests cover a live paused cut, exact checkpoint retention, deliberately paused music, restored preferences, failed storage, embedded training and a controller-only route through Sound back to explicit Resume. Holding A changes Sound only once.

The retained browser observations apply to the earlier isolated candidate. They demonstrate keyboard and pointer reachability at four viewport sizes, including focus-revealed scrolling at 568×320 with Large/Plain text. They are not a final integrated browser check, physical-device certification or audible listening.
