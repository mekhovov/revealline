# Ornament and workshop original picture candidates

Eight original pixel-art-inspired reveal compositions, not eight newly released
or human-approved missions. Generated21September2026 using the built-in image tool,
with no reference images, museum tracing, copied game artwork or CLI fallback.
The user-requested picture work follows compiled greyboxes,48 no-loss route/replays,
equal races and desktop topology/launch inspection. Pacing issues remain open.

## What changes

`createCulturalWorkshopArtCandidates({ spatial: false })` creates an explicit
eight-mission picture edition; `spatial: true` uses the existing spatial revision2
of Dnipro and Four motor landings. Original factories/defaults are untouched. The
successor owns its project/assets and changes project, mission, campaign and pack
revisions, plus background bindings. Map geometry, actors, difficulty, objectives,
player handling and semantic theme roles are unchanged.

All eight PNGs retain their exact generated bytes at1774×887, total16,011,991bytes;
the largest is2,570,665bytes, below the existing4MiB per-picture cap. Every mission
has a unique immutable AssetRevisionV1 digest, size, dimensions and description.
The existing verified-byte loader/preview remains authoritative. No picture
defines collision, grants progress, installs a pack or enables a new game mode.

Pictures live under:

- `game/content-design/assets/ornament-study-r1/`: Cross-stitch crossings,
  Rushnyk bands, Pysanka sections and Dnipro crossings.
- `game/content-design/assets/workshop-study-r1/`: Four motor landings,
  Circuit lanes, Twin lens chambers and Toolbench weave.

Exact prompts, generation filenames, hashes and individual assistant observations
are in `docs/research/cultural-workshop-original-art-prompts.json`. No existing
asset is overwritten. Original generated files also remain in the image tool's
output directory, but project references use only workspace-owned pinned copies.

## Visual observations and boundaries

All eight were visually inspected. Continuous2:1 compositions have recognizable
large subjects, separated discoveries and no text/UI/watermarks. Pixel-cluster
styling is consistent across the warm linen/wood ornament set and navy/teal/wood
workshop set; these are detailed illustrations, not strict low-resolution sprites.
The embroidery pictures have dense fabric texture; copper circuit traces and dark
goggles on dark mats need particular partial-reveal/gameplay contrast checks.

The [Ivan Honchar Museum collection](https://honchar.org.ua/collections/view/rusniki)
informs the distinction among textile objects; the [culture ministry's pysanka
account](https://mincult.gov.ua/en/news/the-ukrainian-tradition-and-art-of-egg-decoration-recognized-as-the-cultural-heritage-of-humanity/)
informs egg-decoration attribution. Both primary pages were rechecked21September.
The motifs are original and inspired, not certified regional patterns or invented
claims about each symbol. Dnipro is a geographic inspiration, not historical
reconstruction. Workshop objects are inactive decorative still lifes, not working
circuitry, assembly instructions or weapons. Music remains explicitly paused.
