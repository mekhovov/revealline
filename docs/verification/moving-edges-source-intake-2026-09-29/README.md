# Moving Edges source preservation — 2026-09-29

## Disposition

Preserve the still-local Moving Edges authoring source and historical evidence.
This is **not runtime adoption, production approval, current-engine acceptance,
or public delivery**. The maps and pictures do not become selectable merely
because their source is retained on GitHub.

The user requested review and intake of all remaining local work. This bounded
source addition can travel with the original actor preservation PR rather than
create another playable-feature release. The content owner must separately
qualify and register any playable successor. Keep the existing release hold and
single-publisher order; no version is allocated here.

## Evidence boundaries

- Historical route, mechanic, chapter and visual receipts retain their original
  dates and claims. They are evidence for the donor source, not a new successful
  run against current main.
- Current engine, saved-session and replay code differ from the donor context.
  Twenty-four of the art receipt's thirty-eight protected context pins differ
  from the inspected main baseline. Do not rewrite those old pins to claim a
  passing current-main qualification.
- The recorded geometry controls cover Scout, Standard/Gentle and Immediate/Grid
  at the stated seed. They do not establish Expert, all selectable classes,
  additional seeds, native-device behavior or human enjoyment.
- Ignored `.cache/takeover` failure records referenced by the old README are not
  among these tracked files. The donor worktree is preserved; this intake is not
  a claim to have archived its ignored data.
- Scenic architecture, paths and warning-like light in the pictures are art,
  not collision geometry or active warning lanes. Ukrainian-inspired scenes are
  fictional, not authenticated historical reconstructions. Coupa scenes are not
  depictions of an official product or promises of financial results.
- No new rights grant or production-cleared claim is made. Original provenance,
  prompts, generation deviations and attribution language remain intact.

## Verification and remaining adoption

The preservation review checks exact allowlisted additions, Git blob identity,
lengths, SHA-256 and JSON parsing. Runtime, build configuration, catalog,
production manifests, versions and publication workflows are unchanged. Current
explicit build includes do not register these three source directories.

No recorder, chapter build, playback matrix, artwork decoder, native preview or
long suite is run for this intake. Historical pass counts are not repeated as
new results. The single publisher still owns final source admission and release
checks.

Before playable adoption, the content owner must:

1. Reconcile changed execution/session/replay dependencies through an explicit
   successor, preserving the original evidence and identities.
2. Recheck affected routes, pressure roles, saved/earned-picture isolation,
   ownership, all intended presets and retained media against the actual source.
3. Review visual rights, partial reveals, compact readability and human balance.
4. Add explicit catalog/production registration only in a reviewed playable
   change, then verify its frozen public build.

Source preservation must not delay higher-priority playable fixes or be mistaken
for completion of those adoption gates.
