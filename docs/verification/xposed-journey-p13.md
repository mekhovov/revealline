# P13 whole-Journey review — local technical preparation

Status: in progress, not published or human-qualified. The isolated branch follows
P12 checkpoint `cef79cb6`; this is not an accepted release baseline. Publication
ownership and the frozen v0.76 boundary remain unchanged.

## One review library, existing compiler

`createWholeJourneyCandidates` composes the twelve chapter factories into one
independent greybox draft: 83 missions, 24 packs and 25 campaigns. The core contains
71 missions including the three-mission Prologue; twelve optional Remixes follow
in the chooser, never in automatic core continuation. This is a quality-review
set, not fulfillment of a numerical content quota or a final retention decision.

Map/mission editions, authored order, IDs, revisions, physics and presets are not
rewritten. All 498 Solo/Versus preset manifests match their standalone definitions
exactly. Campaign execution keys and base keys remain unchanged. Each three-to-five
mission learning arc introduces at most one mandatory rule. Declared core bands
never fall or jump by more than one; no core mission currently has a countdown.
These declarations do not establish measured difficulty or enjoyment.

Studio adds an explicit **Inspect whole Journey greyboxes** action. It uses the
same Inspect → Apply draft boundary as individual chapters; it does not enroll
public content or authorize awards. The existing public candidate selector still
contains Horizon and Border only. This review draft deliberately binds no art.

## Navigation and compatibility checks

The shared sequence crosses all twelve core campaign boundaries, remains unchanged
by search/filter activity and ends at Home signal. Every optional Remix remains
selectable but has no automatic next mission. Component-level Solo and Versus
chooser tests render all83 selectable cards with25 campaign filters plus All,
progress state, authored bands and optional-goal descriptions. Global late-mission
search, return, empty results and focused-card refresh work without granting or
erasing progress.

These are compiler/sequence/chooser checks, not a claim of ten consecutive real
host clears. The real paired-board presentation host still requires each mission's
verified original image. That boundary has not been weakened to accommodate this
unillustrated review draft. Team still requires separately authored definitions.

## Bounded projection reuse

Resolving an already validated mission used to repeat normalization, topology
inspection and manifest construction. An internal WeakMap now reuses projections
only within an owned, deeply frozen compiled project, keyed by mission, mode and
preset. Raw edits must compile as a fresh revision. Unknown mode/preset/mission,
lookalike compiled objects and failed compilation still fail closed. The cache
stores no mutable runs, input, storage or awards; retired project ownership is weak.
