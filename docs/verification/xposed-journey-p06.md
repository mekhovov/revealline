## Shared erosion contract

`journey-actors-v3` explicitly extends v2 with the existing `eroder` runtime role.
Historical catalogue IDs and default behavior are not rewritten. The authored
Territory eroder retains its field region, threatens body/trail, reflects within
unclaimed field and pauses on eligible contact. A 60-actor-tick marked warning
precedes reopening one cell, followed by a 120-actor-tick erosion cooldown.
Permanent foundations and protected objective paths remain immune. The existing
runtime, replay, scoring and terrain contracts are reused, not reinterpreted.

Shared measured/standard/brisk tiers are 2.4/3.2/4 cells per second, with the same
explicit preset factors as field keepers. Per-level speed, warning and cooldown
overrides are rejected. Studio exposes the role only for the exact v3 catalogue;
Team remains field-keeper-only until separately qualified. No unsupported mode
is silently projected as Solo.

Studio and player mission diagrams now share one silhouette helper. Field keeper
circle, perimeter diamond, frontier triangle, roamer tracked square and eroder
toothed blade remain distinct without color. This also fixes the prior thumbnail
fallback that drew reclaimed roamers as frontier triangles. Existing gameplay
sprite identities and collision geometry are unchanged.

## Evidence and limits

Six legal recorded-input cases cover all three presets and both steering options:
closure, field retention, required-objective anchor protection, 60-tick warning,
one-cell erosion, immediate slow-terrain restoration, recapture, stable coverage
denominator and no repeated score. Each exported public replay verifies exactly;
the run is never modified to manufacture erosion or capture.

Additional tests cover immutable historical roles/physics, strict authoring,
Team rejection, Studio fields and stale/invalid application, distinct silhouettes
and their use by both actual renderers. Existing foundation and classic-engine
regressions cover protected-cell transactions and collision/closure interactions.
These are technical contracts, not campaign feasibility, timing, human enjoyment,
native visual readability, physical-device or release acceptance.
