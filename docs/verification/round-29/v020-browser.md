## Retained exception and diagnostic control

Three QA console captures contain the same error: **“Failed to execute 'observe' on 'MutationObserver': parameter 1 is not of type 'Node'.”** The [first wrapper](../../../.cache/round-29/v020-browser/viewport-console.json) recorded it at **18:59:34.819 UTC**; the fresh [couch-only wrapper](../../../.cache/round-29/v020-browser/followup-couch-console.json) at **19:01:20.514 UTC**; and a [blank iframe control](../../../.cache/round-29/v020-browser/blank-control-console.json) at **19:02:04.055 UTC**.

The [isolation record](../../../.cache/round-29/v020-browser/frame-exception-isolation.json) pins all four QA documents outside the packaged site. Independent inspection confirms the blank child contains no game scripts, its wrapper loads only that blank child, and the [blank server log](../../../.cache/round-29/v020-browser/blank-control-server.log) contains only the two document GETs. All **91 shipped JavaScript/module/HTML files**, including Phaser, were independently scanned with no `MutationObserver` occurrence. The [blank DOM snapshot](../../../.cache/round-29/v020-browser/blank-control-dom.txt) confirms the no-game control loaded.

Thus the failure reproduces without game code. Browser instrumentation is a plausible origin, but no originating call stack was established. The three exceptions and all earlier captures remain intact; no runtime workaround or all-QA-logs-clean claim is made.
