# Snake remaster requirements and evidence matrix

This matrix separates implemented behaviour, automated qualification, browser
inspection and external quality evidence. A working route does not establish
fair higher-star thresholds or enjoyment. Historical validation receipts identify
their own source revision; they are not presented as fresh results for later edits.

## External evidence and intentional limits

The final acceptance follow-up adds `browser-acceptance-followup.md` (all 240 Lively FPV starting boards and bounded alternate-look/mobile samples), `visual-acceptance-polish.md` (construction-family corrections), `pacing-acceptance-followup.md` (optional-courier clarity and route evidence), and `rating-calibration-followthrough.md` (no unsupported higher-grade publication). The combined suite passes 390 tests, followed by 98 final host tests after the catch-quota layout correction; 16 optional-package tests pass. `acceptance-validation.json` records the successful clean Main Pages production build and archive integrity. The archive-inclusive full distribution exceeded disk capacity; no fresh full-archive build is claimed. Physical testing and waiting for player feedback are explicitly deferred by user request; they are not implementation blockers or claimed completed observations.

1. **Physical devices — unverified, P1 external follow-up.** No physical-device test was performed in this run. Responsive desktop emulation
   covers layout, not thumb reach, touch latency, hardware disconnect behaviour,
   thermal throttling or low-end frame-time distributions. Run the same lab and
   gallery on representative devices before claiming those devices qualified.
2. **Player study — optional and previously waived.** Do not block independent
   implementation on another approval screen. No enjoyment, world-recognition or
   preference result is invented from screenshots or automated routes.
3. **New silver/gold budgets — intentionally unavailable.** Completion stars and
   personal bests fulfil the remaster baseline. Additional grades need compatible
   independent route/player evidence and a fairness policy for variable hazards;
   a single solver witness is insufficient. This is not an unfinished gameplay
   requirement or an undisclosed unlock condition.
4. **Browser sampling is bounded.** Reports name the screens, worlds, sizes and
   interactions actually inspected. Source/render-command coverage of 240 boards
   must not be described as 960 separately inspected look/board screenshots.
