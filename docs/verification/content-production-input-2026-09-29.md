## Product contract and reproduced defects

`/authoring/production/` and its `?snapshot=sentinel-themes` view are read-only
source registers. They have filters, pagination, recorded provenance/history,
explicit verified PNG previews and source-document links. They have **no browser
Save, import, approval, assignment or export**. Reopening means following the
actual snapshot link or reloading immutable source. CLI register editing remains
a separate tool. A preview object URL is not an OS download or a product export.

The baseline moved focus to a noninteractive heading after opening a slot or
changing pages. Neutral controller polling then moved focus to Sections. Pad
Back opened Sections without closing detail; native Escape could additionally
close detail after the shared owner consumed it. A pending Reload could replace
rows after a newer selection, detaching the exact return target. Long history
and provenance regions had no controller reading owner.

The fixes retain the existing shared authoring owner and Confirm lifecycle:

- A Production-local singleton supplies page Back and attaches the panel to the
  existing shared host. There is no additional poller or global router change.
- Rows and page transitions focus real, stable controls. Back restores the exact
  originating row. Sections targets the real filter/list control, including an
  empty result. Consumed reader Escape does not also close detail.
- Checklist, history and provenance use the existing bounded reader with an
  explicit entry and Back action. Reading, persistent selection and keyboard
  focus remain separate.
- Reload and preview leases retire on newer input/focus, explicit cancellation,
  blur, hidden state and pagehide. Timers, decode results and object URLs cannot
  overwrite newer state. BFCache return retains the host for an explicit Reload.
- Source links say **Current source file**, separately from **Recorded pin**.
  Four recorded source pins describe earlier mutable files; current linked bytes
  are not relabeled as those historical originals.

Two producer script links are served as exact, content-addressed `.txt` copies.
Their manifest, original source and registered pins match. This keeps source
text inspectable without treating CLI modules and their Node dependencies as
browser runtime. Ordinary executable dependency validation remains enforced.
