## Scope and remaining qualification

- This custom-theme slice distributes edited interface tokens/styles with **exact installed arcade and SIM collection dependencies**. It does not admit arbitrary new meshes, textures, fonts, shaders, CSS, or artwork into curated themes; Studio rejects changed selected source assets.
- The selected inventory is included in compiled offline edition data and retained presentation snapshots. This review exercises compiler output and closed readers, not a fresh service-worker installation in a physical offline browser.
- Admitted custom candidates now follow the active same-tab context into auxiliary pages for up to 30 minutes. This is bounded session continuity, not permanent global player installation: a fresh unrelated tab or expired context can still use the visible fallback. The separate explicit SIM handoff supports `noopener` new-tab launches.
- A single shared handoff envelope is intentional. A later launch can replace an earlier pending transfer; exact identity validation prevents the wrong theme being adopted, and a missing match falls back visibly.
- These tests use deterministic host/DOM fixtures and do not qualify physical touch/controllers, real GPU performance, texture shimmer, visual quality at flight distance, or every page/dialog. Those release gates remain separate.
- The earlier full-suite baseline inventory remains separate. This focused green run does not close its unrelated failures or constitute a full repository test pass.
