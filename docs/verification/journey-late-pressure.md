## Method and verification

`node scripts/probe-late-journey-pressure.mjs <mission> <preset> <steering> --max-ms=60000`

The bounded omniscient search uses actual engine input: reachable reclaimed-ground
approaches, straight cuts, discrete waits and existing first-return teaching paths.
It can resume a bounded, identity/checkpoint-verified input prefix, never an injected
runtime snapshot. Every candidate is rejected on first loss. The probe checks its
fresh checkpoint and public replay; independent fixtures reproduce metrics, event
order, actual closures, optional-goal evidence and equal independent race boards.
Time-budgeted search results can differ under machine load; recorded inputs are
deterministic. Failure to find a path is not proof of impossibility.

## Balance findings, not acceptance

- Long Wave now clears in53.15–101.35seconds; Returning Light in34.15–78.55seconds
  across all six configurations. Previous zero-clear status was a limitation of
  reused routes, not established impossibility under stronger pressure.
- Outer Loop Expert/immediate still clears in18.45seconds. Read the Arrows new
  Standard/Expert paths take20.25–28.12seconds; Home Signal27.25–31.15seconds;
  Final Broadcast24.55–38.95seconds; Apex Remix Standard23.45–34.55seconds.
  These remain concrete late-game spatial/pacing review targets. Different routes
  and enemy trajectories prevent using clear time alone to rank preset difficulty.
- Crosswind Remix captures its required relay early, leaving32.5–39.1seconds of
  coverage work; two new Standard paths use the connector and meet mastery, while
  both new Expert paths do not. That interval is a review flag, not proof that
  all remaining play is low-risk cleanup. Inspect whether the relay transforms
  meaningful later decisions before changing quota or adding mandatory objectives.
- Apex Remix has17–28.2seconds after required objectives on the new routes;
  both satisfy optional mastery. Home Signal meets quota7.3–7.6seconds before its
  final objective. Review threat exposure and encounter ordering, not just totals.
-28 new cases lack optional mastery evidence. No mandatory mastery gate is added
  to conceal bypassable route decisions. Further evidence and spatial redesign
  remain separate from ordinary completion feasibility.
