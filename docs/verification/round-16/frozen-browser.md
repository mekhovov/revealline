# Frozen v0.6.0 browser and offline checks

Verified 12 September 2026 in the Codex in-app browser, against source `e88bab7e9677c82419aca35557c858c670425f16` and the immutable `releases/v0.6.0/site` build. An owned server on `http://127.0.0.1:8804` applied the CLI’s release security headers. User profiles on port 8767 were not replaced by this verification.

Settings → Prepare offline play verified **107 files / 19,999,500 bytes**, with no missing or corrupt items. [The visible offline report](frozen-offline.json) records build ID `d83c1461133c5980cfa0ce4b9863edb8252a0f80c67c0acd0954976fc9e6ccd9`.

The normal file picker imported the existing Round 14 complete backup: eight pictures, three campaign histories, four installed packs and a suspended flight. The controller preference omitted by that older file migrated to defaults. Through Settings, Xbox labels, Ability LB / 4 and menu Confirm RB / 5 were applied and saved. The profile was exported through the visible Save JSON field as the pre-practice baseline.

The owned server was then stopped. A separate curl probe returned connection error 7. All following actions occurred while it remained stopped:

1. Controller Practice opened for the first time at this origin, loading the page, sixteen offered missions, seven classes, both steering choices, sixteen physical buttons, four sliders and the actual game iframe from cached files.
2. Connect plus a held South press deliberately joined and did not start. Release all followed by the saved RB mapping started the mission. Another release and held Down completed a full First Signal / Scout / Immediate run: **50.0% captured, 7,820 points, three lives, 0:23 displayed**. Inspection time on safe ground is included; this is not a speed benchmark. The result remained explicitly practice-only.
3. The settings editor loaded offline, showed the saved Xbox map and allowed a PlayStation-label change. Apply reported that this change was for the practice session only.
4. Collection still displayed all eight existing records, including the original Homeward pictures. Home Beacon opened from both the practice collection and the standalone game. The [standalone offline gallery screenshot](screenshots/frozen-offline-home-beacon.jpg) was visually inspected; it shows the original illustrated scene and its celebration/replay/return controls. An earlier parent-frame screenshot was replaced because it did not show the picture; no conclusion relies on it.
5. The standalone game reloaded with no server and exported its player library through the ordinary UI. Its full **9,884-byte** export matched the saved pre-practice export byte-for-byte. [Comparison hashes](frozen-practice-profile-comparison.json) cover preferences, campaign progress, gallery and scores together. The practice clear and label change did not mutate the saved profile.

Sampled warning/error logs from offline practice were empty. The broader [source browser pass](source-browser.md) also covers both turning modes with inverted right-stick flight, remapped Confirm/Back/ability, invalid and cancelled drafts, old-backup import/Undo, readable controller preview labels, session-only behavior and phone/landscape controls. [All 784 source tests passed](source-gates.md); focused reruns are subsets of that total. [Independent integrity verification](integrity-notes.md) reproduced every archived byte and confirmed all nine earlier releases and their tags unchanged.

These are actual browser and simulated-controller checks. No physical controller, Bluetooth, iPhone, native executable, public host or store was tested or deployed. Complete couch/Theater controller menus, hold alternatives, more authored content, optional mastery, staged bosses and representative human assessments of difficulty and enjoyment remain beyond this release. The version is a verified development milestone, not a claim that the entire public-release goal is finished.
