# Built-in Versus FPV picture parity

The regression in [couch-built-in-picture-parity.test.mjs](../../game/test/couch-built-in-picture-parity.test.mjs) covers all fifteen ordinary built-in maps: twelve First Signal missions and three Pressure Lines missions. Its literal oracle records each full campaign identity, level/revision, FPV theme, picture slot, original SHA-256, byte count and dimensions from committed field-kit@58. It authenticates the actual compiled PNG files and compares Solo flight/default/materialization modules with the shipped Versus reader. The three installable Pressure Lines maps also pass through the real installed chapter host and reader.

The actual Versus application host enumerates all fifteen maps and passes the same accepted image lease to both painters, while retaining separate simulations. The finite image decoder checks actual PNG headers and exposes the original bytes for digest comparison. IndexedDB and the DOM are modeled. Solo is its real picture preparation modules, not a full Solo application or saved-flight restoration journey.

The tests preserve the read-only Versus contract, unchanged embedded originals and Solo assignments. They do not change the existing strict generation fence for static/embedded Retry, or external Retry's ability to reopen an exact captured revision against fresh metadata. See [shared static pictures](../shared-static-pictures.md) and [installed chapter pictures](../couch-installed-chapters.md).

Native partial/full reveal, actual decoding and crop/letterboxing, bright-art readability, responsive Plain/Large layouts, physical controls, saved-A/later-B restoration, offline packaging and public release acceptance remain separate. This inventory does not approve new artwork or close P08-A.
