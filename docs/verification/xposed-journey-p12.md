## Candidate scope

Four band-twelve core missions and one optional Remix combine established rules.
No runtime schema, actor tier, player movement, timing recipe or mandatory mechanic
is added. All use the shared MapDesignV3 / MissionDesignV4 compiler and pinned
level.v8 successor; ordinary missions have an explicit null encounter. Home signal
uses the same three-shield Sentinel recipe introduced in P11.

- Crossing complete: terrain enclosure versus a direct marked crossing.
- Final broadcast: protected T returns, erosion and selective trail impacts.
- Returning light: arrow efficiency versus an awakened reclaimed-ground threat.
- Home signal: wing connections and a shield-linked permanent release dock.
- Dawn circuit: optional durable outer loop versus erodible inner spokes.

Each has authored counterplay, capture consequences, an optional mastery goal and
proposed—not measured—duration. Contact bonuses occupy optional detours; the first
returns need none. Whole-mission bonus independence still requires route evidence.
The core sequence ends at Home signal without automatically assigning its Remix.
Studio import remains Inspect → explicit Apply into a local draft; no public
Journey enrollment, award or publication is performed.

The reference crosswalk records direct inspection of all three assigned finale
stills, exact hashes, original adaptations and non-final dispositions. An initial
676-cell unoccupied Remix chamber was rejected and its field-retaining actor
placement corrected before route qualification. Current diagnostics contain no
unintended auto-fill or blocked-relay warning.
