# Settings panel scrolling

Keep persistent dialog navigation outside the scrolling settings panel. Verify long controller drafts as well as short appearance fields, with Large/Plain text at 390×844 and844×390. A visible Close target and a focused control must both remain inside the viewport after Tab causes scrolling. Compact decorative headings on short screens without shrinking action targets. Preserve Escape and exact/logical opener focus; when a responsive layout hides the original opener, restore a visible equivalent. This Solo correction does not qualify other hosts or physical input devices.

Use actual native select popup actions (Space, observed expanded state, direction, Enter) to qualify keyboard choice. A batched locator key sequence that leaves selected values unchanged is not a passed selection. Retain the attempt and verify the corrected values.
