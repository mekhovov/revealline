# Rover Yard original reveal candidates

Seven original pixel-art scenes were generated with the built-in image tool on
20 September 2026, after the seven greyboxes had full-clear, optional-goal and
sampled timing feasibility evidence. Full prompts, source dimensions and exact
hashes are in `../research/rover-original-art-prompts.json`; originals are stored
under `game/content-design/assets/rover-pixel-r1/`. Generator originals remain
intact. No third-party screenshot or literal collision layout was copied.

The subdued overcast repair-yard identity is intentionally different from
Neon's night city: cable workshop, offset repair berths, stepped terraces,
salvage rows, dock repairs, sorting hall and restored waterfront finale. The
seven PNGs are each 1774×887 and total 16,760,497 bytes. They are explicit
candidates, not human-qualified final artwork or a complete campaign theme.
Lighter water/sky and dense machine details particularly need in-game contrast
review against active reclaimed-ground roamers.

The factory's no-argument form remains greybox-compatible. Explicit
`createRoverCandidates({ artwork: true })` attaches one immutable revision per
mission; Studio's Inspect button prepares this form, followed by separate Apply.
Practice verifies the original bytes and dimensions before creating the scenario.
No actor-catalog identity, spawn, rule, scoring denominator, terrain, speed or
capture logic is changed. The existing Horizon functional theme remains pending
separate campaign presentation adoption.

The shared optional-artwork registry now contains 42 originals totaling
107,594,416 bytes. The image, source-registry, offline-cache and Pages byte guards
remain unchanged. Registered pictures remain online-only for core offline
preparation; full loose/ZIP distributions retain them.
