# Rendered landing-motion verification — 2026-09-29

Verified the source served at `http://127.0.0.1:8768/` in Chrome on the local macOS host. The earlier built page at `http://127.0.0.1:8976/game/` was used only to reproduce the previous behavior. Times inside the raw artifacts are UTC on September 28; the local verification date was September 29.

- [Native visibility samples](menu-scenes/motion-native-visibility-2026-09-29.json): exact JSON downloaded from a separate tab opened and operated through native Chrome UI only, without attaching browser automation to that tab. This proves actual hidden/visible suspension and includes a clean six-second timing sample after the final bitmap-cloud correction.
- Reproducible fixtures: [scene sampling](../../game/test/manual/menu-motion-evidence.html), [visible unfocused pane](../../game/test/manual/menu-motion-pane.html), and their [measurement code](../../game/test/manual/menu-motion-evidence.mjs). These test-only files use the production scene module and CSS; they do not install another game input router.

The fixture samples computed transforms, opacity, rendered rectangles, and actual CSS-animation clocks. Two browser screenshots of the same 700×600 scene crop additionally showed the drone crossing the sky. Those screenshots were observed through CUA; they are not represented as files in this report. The raw JSON was saved through the fixture's Download evidence button, then parsed and copied to the two files above.

The Reduced motion fixture control supplies the production host's `context.reduced` flag. It verifies real rendered static behavior through that supported input; it does not change macOS's accessibility preference. System `prefers-reduced-motion` routing is covered by the focused automated tests and CSS fallback, not a physical OS-preference check in this run.
