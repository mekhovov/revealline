The [accepted plan](../../round-28-save-export-plan.md) separates three boundaries:

- [The pure verifier](../../../game/attempt-export.mjs) owns the bounded session and optional trusted campaign before yielding. Available context is checked using its actual campaign key, map and complete class roster through the existing restore verifier; reconstructed run/recorder values are discarded. Missing context permits explicitly marked `replay-only` rescue after replay/checkpoint verification and an actual unfinished-state check. It does not establish an arbitrary outer campaign key or make the file loadable without its matching rules. Supplied invalid or mismatching context rejects without downgrade. No mastery certificate, storage mutation or game adoption occurs.
- [The host helper](../../../game/attempt-file.mjs) chooses a started unfinished normal flight ahead of an earlier stored slot. Ready/results select the stored checkpoint; a stopped current recorder cannot silently select that older file. Practice, First Flight, pending training entry and competing operations are blocked. The [app binding](../../../game/app.mjs) resolves the session's full key against actual normalized content, independently of the selected pack/level, and invalidates on resume, selection, adoption, close and lifecycle changes. A cancelled training handoff can export the retained paused normal flight without clearing its save hold.
- [The panel](../../../game/ui/library-panel.mjs) permits one pending verification, keeps **Cancel export** usable, and calls the returned synchronous `assertCurrent()` before publishing JSON or invoking the existing download adapter. Cancel, Escape and the controller Back callback cancel verification without closing into flight. Close/pagehide and late completion cannot publish stale output. Failed verification preserves the previous copy; adapter failure retains the newly verified copy. Existing protected Library transactions keep their cancellation behavior.

The **stored-source branch is read-only**. It distinguishes absent, unreadable, malformed and oversized data, checks raw UTF-8 bytes against the existing **2 MiB local-slot limit**, and preserves those raw bytes. It inspects the durable backup marker and IndexedDB journal under the supplied short backup-operation Web Lock, releases the lock during replay verification, and rereads the marker/journal/raw slot before returning. The final synchronous publication guard rechecks raw bytes and marker; it cannot synchronously query IndexedDB. A host without Web Locks performs the read checks through its pass-through adapter, with no claim of a cross-store atomic snapshot. No profile-writer lease, storage repair or automatic content installation is required or performed.

The **current-source branch retains ordinary pause/autosave behavior**, including the earlier Library-opening pause. It takes exactly one synchronous host snapshot after releasing inputs, remains paused, and checks the complete read-only replay/checkpoint projection before publication. It does not require stored-slot availability. A genuine 20,000-tick alternating-input recording verifies above the local 2 MiB budget within the existing portable limit. Later current-state or recorder edits reject; even a zero-tick resume/re-pause invalidates through the host transition hook. This is not a promise that opening Library from a live flight performs no autosave.

Tests use legal public core inputs and the unchanged Homeward/Sentinel route expectations for both Immediate and Grid-center steering, covering `xonix-core.v2`/`xonix-replay.v3` and `xonix-core.v3`/`xonix-replay.v4`. Live-cut/recovery exports retain every envelope field, release boundary and checkpoint; actual terminal recordings and tampering reject. Cancellation tests include final progress callbacks, queued/held storage locks, late journal completion, reentrant preparations and invalidated returned results. Panel tests execute the actual `downloadJSON` → web adapter with adapted DOM/Blob URL boundaries. Their controller case invokes the public cancellation callback; it is not physical-controller evidence.

Independent read reviews of the pure verifier, host helper/app binding and panel found no concrete defect at the pinned source. These reviews did not add test counts or establish browser layout, physical hardware, native-runtime completion, public hosting or successful file writes. **Download requested** is the adapter outcome; cancellation after the adapter has been invoked does not revoke a download already requested. Browser observations will be recorded separately, without rewriting this scoped result or earlier gallery-clock/frozen evidence.
