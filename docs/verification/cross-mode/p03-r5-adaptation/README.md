# P03 Ready focus adaptation

This source candidate adapts the earlier R5 one-shot Versus focus correction onto exact P03 `c5bccfc59e9b2dec2defc9d9202565ea3ccceae0`. Its only runtime change is `game/couch/couch.mjs`. It preserves current P03 loading until the actual initial preparation resolves, then clears the existing boot inertness before considering Start focus. A1/A2 fixed destinations, return hints, checked departure owners and normal input release are unchanged.

Initial focus intent is captured before the launch helper can hide a deliberately selected recovery link. Deliberate focus, blur, hidden state or any pagehide permanently relinquishes this one-shot intent. Start is considered only after a successful preparation, with the original match/generation still current, the main Ready panel active, content ready and not busy, no disposal/aborted lifetime, foreground and still-unclaimed focus, and a connected, enabled, visible, non-inert Start. It does not start a round or adopt a controller. Temporary observers are removed after boot settles.
