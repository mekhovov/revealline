The painter retains procedural callers, page-owned palette/font/motion, original Team state geometry and semantic cues. A prepared image stays complete 1152×576 with nearest sampling; unrevealed cells conceal it with opaque black independent of palette. The painter borrows images and never disposes them. Its level ID/revision guard is only defensive: the lease checks canonical pack/level hashes and exact theme/collection/asset identity; the future host must still own current attempt and explicit Start intent.

The lease has no default network reader, arbitrary URL, production binding, Solo storage or imported-art envelope. Owner-supplied validated bindings are not signatures or publication authority. Null picture is an explicit procedural registration; a missing required binding/read/hash/header/decode refuses. Retry keeps its captured identity; changed snapshots require a new attempt. Ready callbacks and injected readers are followed by ownership checks before adoption. Replacement cleanup is followed by a direct lifecycle check, so disposing a newly adopted image cannot return it as usable. A harmless throwing cleanup does not undo adoption. The full API/ownership notes were [recorded before commit](retained/HANDOFF.md).
