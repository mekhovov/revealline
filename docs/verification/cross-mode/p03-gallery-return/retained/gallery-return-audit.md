# Gallery return focus: source-only audit

Exact `87f0f49c84e2f92bceb24b0a317d5e6c79e64ac6`; inputs pinned separately. No edits, tests or native actions.

**Concrete source defect:** `library-panel.mjs:1394–1436` closes the picture, retains Collection, starts `populateGallery()`, then `finishReturn` focuses a successor using only population/view generations and open-dialog booleans. `populateGallery:1064–1085` can await `pictureMedia`. Focus Search or another Collection button during that wait without changing its value: neither generation changes, so settlement steals focus. Blur/hidden followed by return also passes those predicates. This is a deterministic source trace, not a new browser reproduction.

Existing `gallery-focus.test.mjs:1190–1246` only closes Collection or opens a new Collection visit while metadata waits; generation guards already handle those cases. Its custom Element `focus/close` adapter (81–96) emits no document focus event, clears activeElement and runs close listeners synchronously. It cannot qualify newer-focus/foreground ownership. In contrast, `collection-context-host.test.mjs:94–114` restores the native opener first and queues close listeners; its Back test (280–326) verifies normal context/focus/checkpoint preservation, with no held metadata interruption.

**Smallest normal-path fix:** keep a dedicated picture-return focus lease, separate from Parfit's pager/render owner. At the close event, before `populateGallery` can replace cards, capture the actual natively restored originating Collection card through `captureOperationFocus`, with a synchronous logical resolver. Preserve existing generations, current library/model identity and Collection scope checks before resolving the same stable key → enabled card → Search fallback. Cancel the lease on settlement, supersession or invalidation. The helper already retires on foreign focus/input, new dialog, true-window blur, hidden/pagehide, and rechecks same-root/current focus after resolution. It must not be captured from the now-closed child dialog.

Capture must require the actual expected origin owns focus; a Search/Close choice already made before the queued close listener is not a new origin to adopt. Store the original card reference with `galleryReturn` if needed. Normal removed/reordered-record cases still retain the old DOM card until this refresh, so the logical resolver can preserve their established fallback without permitting arbitrary focus ownership. If the original DOM card was already detached before native close and focus is BODY, the current helper intentionally cannot claim that origin. Characterize that boundary explicitly; do not add generic empty-focus admission or transient Search focus merely to satisfy the legacy synchronous adapter. Existing native/modal restoration stays authoritative when no verified return origin owns focus.

`modal-navigation.mjs:61–85` removes the old modal and queues its own restoration, admitting/rechecking foreground and preserving newer focus. Retain it unchanged. A Collection-owned operation lease survives the child's close event; subsequent new dialogs/Collection close retire it. An idle close callback must not replace the parent's explicit focus.

Acceptance cases: held metadata success and rejection after normal native Back return to the recreated keyed card; Search/Close focus (also focus→BODY), pointer/keyboard intent, blur→return, hidden→return and pagehide all veto late return without changing records or paused checkpoint. Test a newer focus choice between native default restoration and queued close dispatch. Retain reordered/removed/empty/disabled-key fallbacks, queued old-close/new-picture and Collection close/reopen negatives, explicit Replay field handoff, and releases of late decoded originals. Add a true detached-native-origin case to define its safe fallback. Use actual markup/native-default event ordering and a single Window identity; the old panel adapter needs focusin and dialog ancestry rather than relaxed production guards.

Ownership: this fix is limited to `galleryReturn` and the picture close/finishReturn adapter plus dedicated tests. Do not change `paginate`, `renderScores`, `populateGallery` or `renderGallery` in this slice, and do not create a second pager lease. Coordinate any gallery-focus fixture upgrades with Parfit, who currently owns that file.
