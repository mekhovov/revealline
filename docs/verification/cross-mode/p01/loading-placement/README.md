# P01 loading placement and focus evidence

This directory preserves original failed trials and corrected candidate-source evidence for the v0.57.2 feature. [copies.json](copies.json) maps each original cache path to its durable copy, byte length and SHA-256. Browser profiles, caches and large source bundles are excluded. The [parent review](parent-review.json) records independent byte and visual checks; it does not accept a release or P01.

- [Library correction](../library-operation-visibility.md): original public placement failure, r2 overlap, r3 landscape/focus/manual scrolling, and clean foreground portrait details/Close/reopen.
- [Craft correction](../craft-operation-visibility.md): original public hidden status, two retained layout failures, measured clearance and [final native review](craft-final/run/review.md).
- [Controller Apply](../controller-apply-focus.md): controlled original failure, corrected fixtures, and actual native Edit focus, Tab and Cancel observations in that final review.
- [Runtime review](final-runtime-review/review.json): current-owner and focus review with exact source pins and disclosed review independence.
- [Production review](production-review/preservation.json): immutable history and original payload preservation; [quality-only append](production-review/quality-only-review.json) keeps runtime recipe content unchanged.

Original screenshot names remain unchanged even when a name suggests completion but its pixels show Loading. Immediate DOM mutations, painted frames, delayed callbacks and terminal states are identified separately in each report. Existing failed observations remain failures; later scoped checks do not erase them. Exact-source gates, public correction and remaining P01 loading-host acceptance follow separately.
