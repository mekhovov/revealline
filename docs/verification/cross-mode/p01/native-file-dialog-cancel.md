## Native finding and cause

The retained [finding](file-dialog-cancel/finding.json) and [event excerpt](file-dialog-cancel/observed-event-excerpt.jsonl) describe public v0.57.1: selecting the retained picture-bundle file again emitted a trusted input `cancel`, immediately followed by Still Media's containing dialog closing. No picture restore committed. The complete original belongs to the earned-media browser run; the excerpt is explicitly partial.

File inputs emit a bubbling, non-cancelable `cancel` on picker dismissal or same-file reselection. A dialog close request instead targets the dialog, is cancelable and does not bubble. The prior handler treated both as Back. See the [MDN input event](https://developer.mozilla.org/en-US/docs/Web/API/HTMLInputElement/cancel_event) and [MDN dialog event](https://developer.mozilla.org/en-US/docs/Web/API/HTMLDialogElement/cancel_event).

The observed event came from native file selection through CDP. It is trusted browser evidence, not a physical OS-picker cancellation trial; an earlier unexpected browser Help target is separate automation evidence.
