# P01 Library operation visibility correction

The public v0.57.0 Library export completed but left feedback offscreen. The same Library modules, style and HTML fragment were preserved in v0.57.1. At 390×844, its active status began at y1689 after a visible Export action; at 844×390 it began at y945 and Cancel was above the viewport. These are original native DOM observations; the short busy interval was not captured as a painted screenshot. The [retained reproduction](../../../../publishing/pages-controller/delivery/evidence/cross-mode-p01/library-placement-v057/reproduction.md) includes terminal screenshots, completed exports and the excluded capacity-limited first attempt.

The correction adds a sticky operation area to the existing Library dialog. It moves the exact status and applicable Cancel nodes, preserving IDs, handlers, live announcements, disabled state and operation ownership. Full detail remains keyboard-scrollable. Closing restores exact sibling positions. Showing the same owner is idempotent and preserves focus; reopening a still-running detached task remounts its current status. A cancelled backup read retains its existing lock until settlement, and its cleanup can clear only its own presentation.

Save validation, durable commits, import/Undo, attempt source checks and downloads remain under their existing owners. The area creates no second task, presenter, store or cancellation policy. An ordinary Cancel retains its terminal message. Navigation clears that message when the relevant pending read has settled.

## Verification status

The actual source candidate initially passed 51 focused tests covering attempt export, backup-set host and profile transfer. The 24 attempt-export cases include the original 17 unchanged test bodies and seven placement/focus/stale-close cases; the cache-only negative control failed against the unchanged Library implementation as expected. The test DOM now models connected parent nodes, sibling order and blur after removal. Geometry remains modeled in these tests.

The broader host batch recorded 102 passes and three failures in 105 cases. All three failures came from the Gallery fixture: its local adapter tracked `parent`, while inherited node movement used `parentNode`, and the Library status had no parent. The fixture now connects the Library nodes and uses the same parent relationship for both APIs. All 41 Gallery tests pass after that correction. Every original Gallery and attempt-export test body remains byte-identical; runtime code and assertions were unchanged by this fixture correction. The failed batch is retained separately from the successful focused retest.

The first native correction trial exposed another required defect: at 844×390 with Large/Plain text, the sticky result occupied y33.75–225.75 and covered the focused Export button at y171.42–218.42. Native hit testing reached the status text instead of the button. The corrected helper measures the actual lower edge after layout and scrolls the current focused control clear without changing focus or ownership. Independent review also caught the 170-pixel textarea case; the downward adjustment is now bounded so the editor's beginning cannot be moved back under feedback. The focused export/Gallery suite passes 69 tests, including the recorded geometry, closed/current-focus guards, Close and tall editor cases. A first new Close fixture check failed because its button lacked the real HTML's `data-close` attribute; that fixture correction and initial failure are retained.

The final candidate's clean native Large landscape trial keeps Export at y288.42–335.42 below the operation area's y225.75 lower edge; all four corners and its centre hit the original control. PageDown reaches the full detail, rotation preserves visible focus, and 90 frames after a manual wheel retain the user's scroll position. Later observations from that trial remain provisional because an unexpected About Chrome tab hid the owned page; its cause is not established. Those original limits remain in the [R3 report](loading-placement/r3/run/review.json).

The [fresh foreground follow-up](loading-placement/foreground/run/review.json) closes the portrait gap on candidate 0.57.2: PageDown reaches scrollTop 25 for 363 pixels of text in a 338-pixel region; both message and label have equal client/scroll widths, without horizontal overflow. Native Close is 44 pixels and unobstructed. Escape returns focus to the Settings trigger, restores the original status parent and clears the area on reopening. The run's 125 before/after foreground checks stayed visible and focused with no unexpected page. Its separate craft obstruction is retained as a required failure, not merged into the Library pass. The final focused Library suite comprises 28 attempt-export and 41 Gallery cases.
