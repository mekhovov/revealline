## Implemented contract

The shared operation presenter owns status DOM only. Hosts retain the operation, generation, cancellation, controls, focus, resources and durable-write authority. The presenter shows a meaningful phase immediately, uses measured progress only when a denominator exists, changes polite announcements only with the message, and handles ready, error, cancelled and detached observation. Its signal remains understandable through text and stops animating under Reduced Effects or reduced-motion preference. It introduces no minimum delay, storage write, global interaction lock or audio activation.

Static launch text is available before delayed modules. The independent direct-tool loader reports dependency failure and same-page Reload while retaining Back; after attachment the host owns its real work. Slow work remains loading rather than becoming a false failure. Required original-picture readiness stays distinct from optional release decoration. Cosmetic loading remains nonblocking, and source fallback is never relabelled approved required artwork.

Offline preparation observes the installing worker immediately through a versioned opt-in progress/terminal protocol while preserving old terminal-only consumers. Worker/build/request identity fences, measured progress, timeout recovery and bounded subscribers distinguish work still running from an unconfirmed result. Stop waiting detaches one caller; it never unregisters the worker, deletes its cache or cancels shared installation. Integrity checks, ready-marker-last, concurrency 4, 64 MiB and 2,000-file caps remain intact; no skipWaiting is added.

Original media, immutable pins, existing single writers/CAS/journals, explicit Resume, input ownership and no-late-adoption checks remain authoritative. Non-abortable saves keep their lock after Stop waiting and reconcile the actual result. Download requested is distinct from a completed save/share on the operating system. A30 remains a synchronous draw of already prepared artwork and receives no artificial spinner.
