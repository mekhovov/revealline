Dense array indexes contribute no serialized keys. Container order cannot alter the total. Empty containers, negative zero, exponent notation, Unicode, escaped control characters and lone surrogates are accounted for correctly. Existing node, depth, array length, string length and field-name limits remain unchanged. Proxy reflection traps and ambient prototype tampering are outside the existing guarantee; this patch neither adds nor resolves those pre-existing limitations.
