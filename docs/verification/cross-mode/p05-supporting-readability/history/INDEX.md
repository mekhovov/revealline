## Evidence selection

All 241 files currently retained outside the selected packets' baseline/proposal dependency trees are archived byte-for-byte. This includes failed-attempt logs, temporary fixture/source snapshots when retained, superseded receipts, native request logs/bindings/closed records, exact proposed patches and read-only/adoption reviews. No captured dependency tree, production asset, source TAR or distribution ZIP is included. The excluded tree inventory is recorded separately; this curation does not reconstruct source bytes that an original investigation did not retain.

`member-manifest.json` identifies every payload by original relative path, member name, raw length and SHA256. It also identifies this generated index separately. The manifest excludes its own bytes to avoid a recursive hash; `receipt.json` pins both manifest and ZIP. Archive readback and a second read of every original confirm lossless copying. No original file, worktree or index was changed.
