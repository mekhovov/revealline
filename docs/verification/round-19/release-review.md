# Final targeted release review — v0.9 candidate

Read-only review on **12 September 2026**, immediately before the v0.9 source freeze. Reviewed the staged app/library-panel changes and current scenario, catalog, prepared-pack, Playground export and backup integration paths. **No new release blocker was identified within this scope.** No production code, prior evidence or frozen artifact was modified, and no completed test suite was repeated.

- **Practice isolation:** the immutable `practiceSession` flag is captured after validated scenario loading, survives campaign/map selection and restore, and keeps completion and mastery-award guards inactive. The original non-writing profile writer remains. The existing link-navigation guard is now enabled for ordinary Playground practice too; this is a UI safeguard, not a same-origin security sandbox. Local exports remain explicit file actions.
- **Catalog adoption:** startup, pack replacement and complete-backup application preflight the permanent base campaign together with prepared installed content. The cached entries/registrations are adopted after successful storage or coordinator commit. Pack import detects a changed source-library reference. Replacement cancels pending restore and mastery-verification work; current-catalog definitions, including explicit absence, govern restored observers and gallery labels.
- **Export and replacement:** v1 stays v1; explicit v2 definitions/null survive prepared scenario and mixed pack-library paths. An edited one-map export validates its retargeted definition and reports the new campaign context. Original-library export retains the loaded originals. Profile replacement and complete-backup Undo retain their separate replacement semantics and existing journal/writer protections.

The earlier [authoring review](authoring-review.md) records the practice-lifetime and library-format findings and their fixes. The [pack integration checks](pack-integration.md) cover the frozen-v0.8 oracle, prepared definitions, saved prefixes, archive/reinstall labels and rollback/Undo. Their counts are not new results from this final pass.
