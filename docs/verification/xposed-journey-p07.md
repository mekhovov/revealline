it on for Phaseworks would silently change existing field keepers and patrols.

existing field bouncers. Only those actors seed travelling impacts and omit
instant trail damage. Other actors keep their established contact rules. No
historical descriptor, level, actor catalogue or replay is rewritten.

The selected threat still retains field. The travelling fronts use the existing
polyline, speed, closure/collision ordering and recovery implementation. A strike
at the live endpoint is immediately fatal; this is not a universal grace period.
Only closure ahead of a travelling front clears it. Foundations still contribute
no earned coverage. Pending impacts and selected actor IDs survive public
suspension and deterministic replay, and editing the descriptor breaks replay
verification. No generic body-collision logic is disabled.

every prior role object and speed tier. The shared compiler selects only these

identity. Removing the last carrier removes the opt-in descriptor. Studio uses
the same validated heading/tier controls; arbitrary front speed is not a knob.
Unsupported Team carrier authoring is rejected rather than silently substituted.
