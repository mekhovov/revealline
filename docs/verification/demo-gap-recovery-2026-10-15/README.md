## Changes and their boundaries

- Improvised playback can wait through actual respawn grace and encounter phases. Every neutral tick is simulated independently, and a loss or unexpected cut rejects the wait. Captures that win during an encounter opening stop at the authoritative terminal tick, including wins without a `cut.closed` event.
- When local capture search cannot make progress, a bounded path over existing safe territory can approach a distant required objective. It must improve objective distance, retain safe heading clearance and survive the real simulation. It cannot snap the craft, draw an incomplete cut or manufacture a loss. These fallbacks are confined to improvised playback; the qualified live map whitelist and all simulation/planning limits remain unchanged.
- Worker replacement waits for an asynchronous termination acknowledgement when an adapter supplies one. Native browser Workers still return void. Generation and disposal checks prevent an older reset from creating a replacement. This fixes reset ownership; it does not prove there can never be a short native thread overlap between separately disposed scene players.
- The English JSON-validation fallback resolves its message suffix without a literal incomplete translation key. The old literal was interpreted by the real launcher catalogue builder as `errors:dataJson.`, breaking company-candidate and focused CI. There is no eager UI translation import in isolated Workers.
- The availability audit accepts an optional repeatable exact `--level` selector. Default complete-owner enumeration remains unchanged, and unknown selections are rejected. No loading deadlines, watchdogs, package caps or strict checkpoint assertions were relaxed.
