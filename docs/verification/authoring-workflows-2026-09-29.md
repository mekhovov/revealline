## Runtime corrections and automated checks

- Shared grid Back refreshes feedback immediately after cancellation. A pending
  line's first Back clears its anchor while retaining the canvas; the next Back
  exits. The real Sprite panel regression also verifies Undo/Redo, history focus,
  keyboard Escape/Space, and exact RGBA bytes passed to encoding.
- Asset Studio records the first invalid provenance field while its operation
  owns the inert panel, then focuses it after unlock. It does so only if the
  initiating control, body, or operation Cancel still owns foreground focus.
  A newer control and background completion retain their own focus. The rejected
  candidate and saved revision remain unchanged.
- The real Playground host test verifies cursor movement does not edit,
  Confirm calls the real paint command, Undo restores the exact model, invalid
  complete JSON cannot mutate the model/storage/preview, and valid reopen does
  not implicitly launch practice.
- The keyboard check exposed a preview taking focus after its iframe load event,
  when the child game completed asynchronous boot. The shared preview owner now
  guards late child focus until explicit Enter preview or deliberate pointer
  entry. It retains the latest visible editor control, does not reclaim
  background focus, preserves Return, and removes listeners on reload/disposal.
  Child window focus is also covered when no element receives `focusin`.
  A window-capture guard consumes an unentered first key before the child game's
  document handler; the regression proves unentered Enter invokes no child
  action, while Enter after deliberate entry retains the child's owner.
  The read-only browser trace also identified a queued child Enter delivered
  after the parent had already reclaimed focus. Such keys are consumed while
  the preview remains unentered; the independent focus-reclaim predicate leaves
  a newer parent control untouched. The regression covers this exact order.
  The iframe leaves the native Tab sequence while the visible Enter preview
  button provides keyboard entry. Its original tabindex is restored on disposal.
- Playground's existing section labels are semantic headings. Sections can now
  reach the actual map canvas, interaction preset, visual-role selector and
  preview controls. A named destination must be focusable, visible, and inside
  the heading's own region; choosing a section never activates that control.
