## Unfamiliar viewers

Give each viewer the same short sequence containing a bent capture, a danger and a completed capture. Do not explain the mechanic first. Let them choose how to start playing. Record their words and actions before offering help; repeat after any resulting changes.

| Observation                                       | Viewer 1 | Viewer 2 | Viewer 3 |
| ------------------------------------------------- | -------- | -------- | -------- |
| Which device/input and language?                  |          |          |          |
| Explains how to close a cut and capture territory |          |          |          |
| Identifies the danger to the craft or open trail  |          |          |          |
| Finds play/takeover choices without coaching      |          |          |          |
| Understands practice does not award progress      |          |          |          |
| Attempts a level and reconnects a cut             |          |          |          |
| Names an engaging scene and a confusing moment    |          |          |          |
| Reads the captions without losing the action      |          |          |          |
| Reports motion/noise comfort                      |          |          |          |

Record any assistance, failure or uncertainty. The release requirement is all three viewers understanding cut closure, recognizing the relevant danger and finding the play choices without coaching. Revise scenes/captions when those observations disagree with the intended teaching.
