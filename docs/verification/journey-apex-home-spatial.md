near shield opens a permanent, non-scoring transfer dock. The lower return becomes
contested when captured: its measured-tier ground roamer at42.5,22.5 wakes after
the established120-tick warning. Leave earlier or establish an upper return.
Walls remain obstacles, not return ground; grouped shields and isolation are legal.

The first baffle proposal formed a small seed pen. Its17.65/20.15second clears
and33/14-cell transition fields remain in a rejected-source fixture. Moving
receivers back near their old positions left a five-cell isolation shortcut.
Brisk-only, nearer-roamer and combined speed/placement trials did not change the
three old immediate-route outcomes, so those unhelpful speed changes were rejected.

A frozen open-baffle control reproduces six original clears. The accepted study
differs from that control only in roamer coordinates. All three old immediate
logs now fail specifically on that active roamer; all three grid alternatives
still win. This is evidence of a causal route interaction, not universal hardness.
