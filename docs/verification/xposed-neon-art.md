# Neon Contours original picture candidates

Seven original midnight waterfront compositions were generated with the built-in
image tool on 20 September 2026. The full prompts and byte/dimension/hash pins
are in `../research/neon-original-art-prompts.json`; project assets live in
`game/content-design/assets/neon-pixel-r1/`. Original generator files are retained.
Each scene has a distinct focal discovery: angled bridge, circular observatory,
four pavilions, dock bays, bent canal, roof terraces and crescent harbor canopy.
These are original scenes, not copied reference screenshots or map collision.

All seven are1774×887 PNGs, totaling17,444,421bytes. All remain explicitly
`candidate`; individual image inspection does not establish gameplay contrast,
human preference, accessibility or release qualification. Some compositions use
heritage architecture; campaign coherence and the Neon name remain subject to
whole-set review. No image has been silently resized or recompressed.

`createNeonCandidates({ artwork: true })` attaches one immutable revision to each
mission. Its no-argument form remains the historical greybox. Studio's explicit
Inspect button now prepares picture candidates; Apply remains separate and
Practice verifies exact image bytes before launching. Art cannot publish a
mission, change collision or grant an official clear. The existing Horizon
functional palette is retained until the separate presentation adoption is
qualified; this does not claim a finished campaign theme or music identity.

The combined Horizon/Border/Signal/Neon registry has35originals totaling
90,833,919bytes. Packaging previously had a32-item ceiling, inconsistent with
the shared512-asset content-project envelope. It now uses that shared limit.
The64KiB registry-source check,4MiB individual image limit, exact digest and
dimension checks, duplicate/path/symlink protections,64MiB core offline budget
and950MiB Pages guard are unchanged. Optional pictures remain online-only; loose
files and distribution ZIPs retain their originals. No bulk build was made for
this bounded source check.

The first broader43-test run passed42 and caught a stale Border aggregate-count
assertion (28instead of35). It was corrected to include the Neon registry, not

cancellations or skips in68.939seconds on Node20.19.5. It covers all Neon
ordinary/mastery/seed/delay and paired-board regressions, exact original preview
verification for Border/Signal/Neon and bounded packaging. Changed-source lint,
formatting and diff checks also pass.
