# Combined Journey: optional timed Border pickups

2026-09-21. P02/P13 technical integration, **not final balance acceptance or a
public deployment**. The explicit `?journey=whole-spatial-v3` review route places
the three trail-aware Border schedules in the complete Solo/Versus Journey.
Studio exposes the identical source through Inspect, then explicit Apply.

## Scope and compatibility

V3 extends the field-finale v2 edition. Behind the patrol gains the reviewed
slow-enemy window, Second landing the extra-life window, and Long rail the freeze
window. Each has three authored possible anchors, a one-second announcement,
ten-second availability and twelve-second cooldown, with at most three appearances
and one collection. Eligibility is checked against geometry and actual live
trails; this is not a promise every authored anchor always becomes available.
Only contact collects a pickup. Capturing its cell does not grant it. Existing
fixed items remain, including Long rail's player-speed item.

No new engine or bonus rule is introduced. The source explicitly selects
`timed-bonuses.v2` and the existing pressure-v2 difficulty catalogue, in the same
order as the reviewed isolated study. Exact mission revisions and simulation
identities are retained; editing schedules afresh could produce equivalent rules
but different identities and would not justify reusing the old pins.

The other 80 missions, all maps, pictures, actor materials, mastery descriptions,
coverage targets, player handling and difficulty factors remain unchanged.
The sequence is still 71 core missions and twelve voluntary Remixes. Team stays
separately authored. Cultural/workshop maps and optional robot combat are not
silently enrolled by this change.

Historical routes, default entry and suspended attempts remain untouched. V3 uses
`journey-whole-spatial-v3` for progress and
`revealline.suspended.journey-whole-spatial.v3` for attempts. Neither key contains
the release version. Foreign-edition backups are rejected; prior fixed-only
clears do not become timed-edition receipts. Solo/Versus progress remains separate.
