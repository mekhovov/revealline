# Candidate attempt preparation and exact Horizon presentation

P01 source work, 20 September 2026. Not a released Journey host or phase acceptance.

`content-design/attempt.mjs` prepares an independent Solo run and recorder from
the shared execution catalog. Selection is an exact catalog mission ID plus an
explicit preset, seed and steering policy. The compiler's canonical roster and
Scout start are retained; callers cannot inject Legacy difficulty transforms,
equipment recipes, rules or official eligibility. Pack ownership and authored
theme identity remain explicit. Source, theme and request inputs are copied;
the returned simulation and recorder remain mutable, separate engine objects.

Pinned artwork must pass the existing bounded byte/hash/dimension verification.
A copied data URL is not proof of verification. Cancellation, replacement,
external abort, disposal and a maximum 20-second timeout settle even if a loader
ignores its signal. Late results, callback failures and reentrant cancellation
cannot take ownership from a newer request. No storage, award or UI adoption
occurs in this preparer. The eventual host must also check retained run, focus,
save and presentation ownership before committing a replacement. Preparation
does not claim browser image decoding, paired-race adoption or Team support.

This exposed a real existing mismatch: the missions declared `horizon`, while
Studio loaded `retro` unconditionally. The candidate-only theme file now defines
Horizon School's coastal palette and role labels. It deliberately reuses the
registered craft and geometric actor family; these are not new actor assets.
Legacy's theme catalog is unchanged. Studio requests the mission's actual theme
and rejects mismatches instead of substituting a different campaign identity.
Theme transport resolves relative to its module, so the caller's page location
does not change the asset URL.
