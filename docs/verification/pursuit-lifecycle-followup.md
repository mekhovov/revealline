# Pursuit authoring and lifecycle follow-up

This follows the Living Routes expansion and PR #995's Company capacity/voice
work. It completes three locally actionable gaps found while reviewing the plan;
it does not qualify the 84 draft layouts or finish the online roadmap.

## Delivered changes

- **Native Contact Hunt authoring:** World Studio creates unarmed ground targets,
  ordered or unordered finite Hunt objectives, and optional bounded echo tails.
  Self-level and Acro keep separate accepted settings. Actor removal and role
  changes update objective references, with existing Undo and source bindings.
  See [authoring instructions](../fpv-contact-hunt-authoring.md).
- **Community ownership:** journal completion/rollback merges only the relevant
  edition in transactional profile storage. Classic recipes, exact edition
  receipts and local Studio ownership commit together; offload checks the current
  generation. Migration preserves recovery bytes and progress, and the UI explains
  retained local copies. See [ownership details](../community-native-families.md).
- **Private-room recovery:** failed connections suspend controls and presentation.
  Recovery obtains an authoritative snapshot and shared Pause before both players
  explicitly choose Ready. Bounded local queues and service-owned activation
  tokens reject controls delayed across pause/resume/rematch. Lost seats become
  abandoned instead of reconnecting forever. Native lifecycle/export adapters are
  reused; native endpoint approval remains a separate requirement.
