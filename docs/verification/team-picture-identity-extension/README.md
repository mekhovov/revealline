The current Team painter separates the authenticated authored picture level from
its derived gameplay-pressure level. That change correctly reopened the earlier
37-recipe and five-equipment source gates. This continuation reviews only that
admission change; it does not replace either original review or approve other
presentation work.

equipment dependencies, the old renderer bytes and the executable evidence.
Only `game/couch/coop-view.mjs` differs in those dependency lists. The original
review fingerprints remain accepted. Current production additionally requires
the exact continuation record and its complete current fingerprint; missing,
edited or unrelated evidence does not promote an asset.

current painters on 31 command-earned Studio scenes. Its 496 comparisons cover
both starter arenas, 390/1152 CSS-pixel widths, normal/reduced effects, pixel/plain
text and picture/no-picture renderer boundary specimens. All 42 Team roles are
represented. Every drawing command and canvas property assignment agrees; the
context and authoritative run are unchanged. This comparison uses modeled
canvas commands, not new browser pixel or timing observations.

picture lease and checks the newly supported authored-picture/derived-run pair.
Wrong revisions, IDs, versions, dimensions, snapshots, copied bindings and
retired owners are rejected. The historical painter did not support that new
pair, so it is not counted as a historical rendering-equivalence case.

inherited records and negative mutation checks. They additionally reject missing
