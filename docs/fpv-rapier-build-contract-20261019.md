# Rapier package feature boundary — 19 October 2026

This current qualification clarification leaves every historical recording, backend, measured result and vendor byte unchanged. It does not report an observed replay divergence.

The SIM pins **`@dimforge/rapier3d-compat` 0.21.0**, module SHA-256 `02dc6a4e2fffc013bab08fbb44fa68f501d8303615e9afe4c7d89ad4eedda0d0`. The official registry metadata matches the repository's recorded archive integrity and identifies upstream commit **`b716d375efc0201003f0cd9ef7168eee0b62c177`**. Its binding changelog and Cargo template map JavaScript 0.21.0 to **Rust Rapier 0.36.0 / parry 0.31**. The 0.35 solver caching and contact clustering improvements are already present, not an available upgrade remedy for the measured Firefox slowdown. [Exact bindings changelog](https://github.com/dimforge/rapier/blob/b716d375efc0201003f0cd9ef7168eee0b62c177/bindings/typescript/CHANGELOG.md), [Cargo template](https://github.com/dimforge/rapier/blob/b716d375efc0201003f0cd9ef7168eee0b62c177/bindings/typescript/builds/prepare_builds/templates/Cargo.toml.tera)

At that exact commit, the build generator maps ordinary `rapier3d` to `FeatureSet::NonDeterministic` with no added features. The `rapier3d-deterministic` variant adds `enhanced-determinism`; `rapier3d-simd` instead sets the WASM `simd128` target feature. The underlying 3D crate's defaults are `dim3,f32,std`, not `enhanced-determinism`. [Build generator](https://github.com/dimforge/rapier/blob/b716d375efc0201003f0cd9ef7168eee0b62c177/bindings/typescript/builds/prepare_builds/src/main.rs), [3D crate features](https://github.com/dimforge/rapier/blob/b716d375efc0201003f0cd9ef7168eee0b62c177/crates/rapier3d/Cargo.toml)

Consequently, the completed exact-hash browser fixtures remain evidence of **observed equality for their tested configurations and engines**. Generic upstream JavaScript determinism prose must not be substituted for validating the build flavor, initialization and surrounding calculations, or treated as blanket qualification of untested architectures. The absence of the feature is not by itself evidence that the observed flights diverge. [Rapier determinism documentation](https://rapier.rs/docs/user_guides/javascript/determinism/)

Any future deterministic/SIMD flavor experiment must pin its own artifact, retain the old vendor for historical playback, compare trajectories and snapshot compatibility, and pass new accuracy/contact/replay/performance/package gates before runtime adoption. No dependency switch or automatic promotion is part of this clarification.

The read-only upstream search found no matching Firefox 153 ARM64 contact-solver remedy. Mozilla's ARM64 prologue optimization shipped in Firefox 150; its later Intel-only 8bitbench regression is not a match. Neither establishes a cause for our fixture.
