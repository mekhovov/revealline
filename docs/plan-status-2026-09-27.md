# RevealLine — current completion and remaining delivery plan

Status checked **27 September 2026** against GitHub releases, merged source,
open pull requests, the Pages marker, and retained public-acceptance evidence.
This is the current status summary. Older dated plans remain useful design and
evidence records, but their version allocations and “next” labels are historical.

## Current release-coordination policy

The dedicated release-coordinator chat is the sole authority for merges, version
allocation, qualification freezes, archives, selector admission, Pages deployment,
and publication. The user's current direction is to deliver the latest compatible
reviewed batch rather than require every older version grouping or PR chain to
become its own serial release. Those older groupings remain preparation and
provenance records. A new release does not require deploying another historical
archive first. Existing immutable releases and archives remain preserved.

This policy changes scheduling, not acceptance quality. Focused behavior checks,
source and provenance checks, current public-byte verification, and scoped public
player journeys remain required. Waived or skipped suites are still reported as
waived or skipped rather than passed.

## Completion rule

A branch, green component test, merged PR, tag, uploaded asset, or successful
deployment is intermediate. A player-facing item is Complete only after:

**accepted predecessor → related-hunk reconciliation → focused verification →
reviewed source PR → immutable qualified release → selector admission → Pages
deployment → complete public-byte audit → scoped public player check → status
update.**

Existing archives remain immutable and preserved. Creating or deploying an
additional historical archive is required only when the currently reviewed
release policy explicitly includes it; it is not a universal prerequisite for a
new release.

Physical-device, human-playtest, listening, cultural, rights, and external-service
acceptance remain separate evidence categories and are never inferred from this
pipeline.
