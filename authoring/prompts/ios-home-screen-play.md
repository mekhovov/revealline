# iPhone and iPad Home Screen play review

Review the packaged Reveal / Line game in an iPhone or iPad Safari tab and as a
Home Screen launch. In the tab, keep the complete responsive game usable inside
the visible dynamic viewport. Since Safari does not provide document fullscreen
for this page, activate the visible full-screen help and verify that it explains
Safari Share → Add to Home Screen without claiming an automatic installation.
Reach and dismiss the explanation with touch, keyboard and controller navigation;
focus must return to its opener and the current attempt must remain unchanged.

From the installed Home Screen icon, verify the scoped start URL, standalone
display, safe-area insets, portrait and landscape rotation, complete 2:1 arena,
compact HUD, contextual touch pad, Pause and explicit Resume. The install help
must stay hidden. Check progress persistence within the same installed origin and
test an interruption/return without automatic gameplay resume. Record the physical
device, OS, browser, orientation and measured viewport. Browser emulation and user
agent fixtures are useful regression evidence but do not qualify physical Safari.
