# Qualify a composed navigation change

Use with the runtime maintainer skill and the authoritative cross-mode execution register.

> Inspect the exact current source and the navigation change. Bind the relevant complete test files and their real imports/fixtures, including dynamically fetched fixtures. Preserve unrelated work. Verify the intended whole files on the supported Node runtimes, retaining raw failed attempts. If a committed input was absent from a finite worktree, restore its exact Git bytes and rerun the affected complete file; do not change assertions to hide a missing fixture. Report passing coverage across files separately from one passing combined invocation. Pin HEAD/tree, canonical staged identities and physical inputs; raw index cache changes alone do not identify a source change or its writer.

> Through the actual player interface, exercise Title → selection → Start → Pause → nested Help/Library → Back → explicit Resume. Include a real unfinished cut and checked save/continuation. For asynchronous work, test Cancel, failure, retry and deliberate newer focus. For recreated controls, choose an exact logical successor in the active view and preserve later input. Keep modal return, operation completion and navigation ownership separate. Do not inject game state and call it a native journey. Record actual outcomes and correct premature action labels without rewriting historical evidence.

> Update the execution register with the exact source, result, remaining failure and playable candidate. Include related guides and prompts. Review and stage only related text hunks and complete related binary artifacts with hashes. A phase closes only after final-source gates, immutable version/release, the source and publication PRs, deployed-inventory checks and affected public journeys. Desktop screenshots and modeled controls do not establish physical touch/controller or mobile acceptance.

The [composed P03 record](../../docs/verification/cross-mode/p03-composed/README.md) demonstrates distinct failed, corrected, complete-file and desktop evidence. The [W3C dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) supports logical focus return when an opener disappears; [Xbox navigation guidance](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/112) calls for predictable keyboard/controller journeys. The game's particular operation-lifetime rules are its own implementation contract.
