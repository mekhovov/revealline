# Responsive Studio preview controls

Keep the Asset Studio preview controls readable on a narrow screen without changing DOM order, keyboard focus, scene selection or canvas size. Inspect both the toolbar layout rules and later shared host-role rules: a logical minimum size can override an earlier physical minimum. Use bounded responsive columns, native single-line selects and at least 44 CSS-pixel action rows. Preserve the existing wide layout.

Verify 390x844 portrait, 844x390 landscape and 1600x900 desktop, plus Plain/Large text. Measure actual control rectangles and document overflow, then Tab through all seven selects and Geometry overlay in order. Attribute native evidence to its exact source/overlay; responsive emulation does not certify physical touch, a whole authoring journey or public deployment.
