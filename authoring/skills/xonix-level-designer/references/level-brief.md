# Level / extension brief

Level: ID, ruleset ID, learning beat, arena dimensions, starts/spawns, marker roles, success condition, failure condition, difficulty parameters, expected session length as an untested estimate, seed/generator revision if applicable, validation result.

Extension request: proposed behavior name, player-visible trigger, required state, parameters and bounds, event order, deterministic tie rules, interactions with fill and captured markers, save/replay implications, capability version, three meaningful acceptance cases, and the narrow runtime/schema change needed.

Do not place proposed behavior IDs in a pack that claims to validate against the existing catalog.
