# Phase 6 generated Versus qualification

Current `creator-layouts.v3` generation declares Solo and Versus. Every one of
the six template families and both bounded variants is qualified by replaying
each accepted route on the real two-board duel engine for Gentle, Standard and
Expert with Immediate and Grid-center steering. Package preparation and import
repeat that proof for the exact generated mission and runtime seed.

Qualification requires two independent boards with identical initial
checkpoints, the same compiled level and runtime seed, a legal win on both
boards, no lost lives, a draw, and identical final authoritative checkpoints.
Image-only portable packages use `revealline-creator-runtime.v2`; packages
with victory stories use runtime v3 so story and dual-mode requirements remain
explicit. Both retain the exact dual-mode project through export and import.
Older `creator-crossing.v1` and
`creator-layouts.v2` packages retain their original Solo-only contract.

The candidate Versus host supplies authored campaign order, so Retry can create
the same mission/rules/seed again and Next resolves the next mission in that
campaign. A first-clear test also verifies a non-draw winner outcome when only
one player follows the accepted route.

This is bounded gameplay and transfer qualification. It does not claim human
balance, network multiplayer, mobile/controller certification, or Team support.
Team needs separately authored cooperative templates, spawns and objectives.
