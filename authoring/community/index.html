Create a campaign from one picture

  1. Open Picture campaign creator and select one image.
  2. Name your collection, choose picture fitting and review the credits.
  3. Choose Generate and review, then check the picture and generated map.
  4. Approve the exact result, then Install campaign or Download .rlpack.
  5. Play the installed Custom mission. A legal win earns its picture; unfinished attempts can resume after reload.

Four pieces of a collection

Map
The board: walls, terrain and starting places.
Mission
A map with actors, objectives, rules and a picture.
Campaign
Missions arranged in the order you want to play.
Pack
Campaigns and the files they need, ready to transfer.

1. Try a ready-to-install campaign

Download Two crossings

Two deliberately easy maps, procedural scenery, no enemies or personal data.

  1. Check that the JSON file is in your browser's downloads.
  2. Open the pack player, then Settings → Game data → Installed chapters → Install a pack file. Choose that download and wait for validation.
  3. Choose Play Creator guide · two crossings in the installed card, then Start mission. The link above opens the existing expansion player.
  4. Start and steer down to the opposite boundary. After the win, inspect the picture, choose Next, and try Retry on Second crossing.
  5. Reload to check installation and progress. Keep the downloaded pack for recovery.

2. Make a level with your picture

  1. Open Playground. Start with an included map, or enter a Generator seed and choose Generate map.
  2. Set Role to Reveal background, choose the background fit, then Choose PNG / JPEG / WebP. Select your image and review it.
  3. Optionally paint the map or adjust its coverage target. Undo restores the previous edit. The picture is a reveal reward; it does not determine the walls.
  4. Choose Play configuration. Finish a legal win and test Pause, Resume and Retry. This preview is practice, so it does not award campaign progress.
  5. Expand Complete pack JSON and choose Export map as expansion. Check the actual downloaded file, then install it using the steps above.
  6. Send the expansion file to a friend. They install their own copy the same way.
The current Playground embeds the image you supply. It does not promise metadata removal. Use a picture you intend to share. Share the expansion, not a complete player backup containing progress and other installed content.

3. Build an editable campaign

Download Studio example Open Content Studio

  1. Choose Inspect import, select the example and review it before Apply inspected source. Export existing work before reusing its ID.
  2. For your own collection, use a unique Local project ID and New project. Inspect and apply the starter.
  3. Open Organize missions, campaigns & packs to create, name and order your collection. Use Validate & apply structure after edits.
  4. Edit one mission at a time. Use Play exact Solo preview → Start mission and test every difficulty you plan to offer.
  5. Save checkpoint / retry, Export backup and reload to check recovery. Another creator can inspect and apply that source file.
Current boundary: Studio exports editable project source. It does not yet install that project as an ordinary modern Custom campaign. Use Playground's map expansion for today's manual install path. Automatic image/video campaigns and .rlpack installation are the next development phases.

A reference picture in the Studio map editor is an overlay, not an automatically bound reward. Themes, retained pictures and video stories have their own workshops and exports. A story playback range keeps the complete video; it does not trim the shared file.

4. Keep a recovery copy

  • Keep exact content editions, private originals and personal saves separately.
  • If saving fails or another tab has newer work, keep the page open and export your unsaved snapshot before deliberately reconciling it with the saved version.
  • To restore a Studio checkpoint, inspect it first, apply it, then save a new checkpoint. Earlier history remains intact.
  • “Download requested” means you must check the actual file. Test importing it in a separate browser profile before relying on it.

Installation is local. Sharing a file does not publish it on the game's website. Public release integration currently uses the maintainer workflow; the community upload and catalog service is planned.
