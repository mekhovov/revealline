# Playable comparison

Serve the repository and open `/authoring/playable-benchmark/`. This source authoring tool runs one actual `createRun` / `stepRun` simulation through native `attachInput` and two independent `BoardPainter` instances. The second pane uses the renderer's existing reduced-effects option. Both panes share the exact run; switching presentation cannot change movement, collisions, pressure, captures or results.

The current queryless Solo resolver chooses the route. The bounded cohort resolves `first-return`, `return-in-reserve` and `crossed-bands` from that exact source at standard difficulty. The page shows route, project SHA-256, mission/revision, simulation identity, setup and original artwork pin. The original artwork loads through `acquireCandidatePicture`, which verifies byte length, digest, dimensions and decode before accepting a replacement. Actors use the same approved FPV lease and Journey identity adapter as the ordinary default view; the separate appearance pin shows its loaded revisions. Actor appearance goes through the renderer's dedicated option, preserving the mission scene palette and original. A failure leaves the previous run paused and visible. No procedural substitute is admitted for a missing original or approved actor lease. Artwork metadata's candidate review status is preserved; this tool grants no art or publication approval. Candidate drone body v3 is not registered or loaded here.

Start, Pause, Retry, native keyboard steering/boost, the default D-pad, an explicit optional canvas Swipe mode and the existing basic gamepad input reader operate the real core. Continuous steering and the input reader's fresh-gesture checks are retained. Terminal results announce once and offer Retry focus after 600 ms only if focus still belongs to the same play control. Intervening navigation cancels the focus offer. A deliberate fresh Retry press/release recreates the same mission and seed with Scout/immediate turns, resets both painters' visual phase, and clears held controls. Its 600 ms ready cue advances no simulation, then starts automatically; held steering still requires release and a fresh press. Pause cancels the cue. A long browser frame pauses instead of skipping simulation time. Hiding/departing cancels pending work and the RAF. BFCache return remains paused with one RAF; final departure releases the original picture, approved actor lease, painters and input listeners. This isolated host imports no profile, awards, save or replay recorder and writes no persistent/session storage. Locale initialization may read the existing language preference.

The authored six-second [feedback sequence](../game-feel-lab/) remains a separate diagnostic. This playable comparison does not replace a campaign, saved attempt, recorded replay, player setting or artwork binding. Workshop, Poltava and Synevyr artwork directions are future candidates, not the displayed mission originals. Full product shell, settings, audio/haptics, physical-device controls and player-study acceptance remain separate.

Serve the complete repository or distribution with these original mission assets available. A Workshop tooling download alone does not certify the three missions or their original artwork for offline use; this tool does not promote those assets into the core offline pack.

Focused checks: `node --test game/test/playable-benchmark.test.mjs`. They exercise the actual standard-difficulty missions at `FIXED_DT = 1/120`, including capture/win, actual self-contact/loss, pursuit warning/commit/impact, heading interception and deterministic Retry. Host tests exercise native D-pad/swipe input, fresh steering/confirmation gates, delayed focus ownership and the ready cue. Resource tests verify the actual approved release transport, original digest checks, visual phase reset, replacement rollback, cancellation, stale decode disposal and final release. These source tests are not browser rendering or human-play evidence.
