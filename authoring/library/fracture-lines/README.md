# Fracture Lines · Arcade

Source candidate: three original 72 × 36 wall layouts. Split Ring offers four staggered gates between a basin and its outer circuit; Fault Fan branches into deep bays beside an open east; Frayed Causeway routes around three solid islands. These use the existing Classic core, contour patrols, warned pursuit, contact pickups, terrain and erosion. No runtime behavior is added.

The initial geometry validates and differs from the twelve pinned Pressure, Frontier, Route Choices and Sentinel exemplars, including their horizontal/vertical reflections. Wall components are four, one and three respectively; traversable space stays connected. This mechanical check cannot establish interesting play or human readability. Enemy positions, speeds and coverage remained unchanged through the bounded route search. They remain a source candidate for later native and human review.

The chapter uses stable IDs `fracture-lines-split-ring`, `fracture-lines-fault-fan` and `fracture-lines-frayed-causeway`; the pack and campaign ID are `fracture-lines`, revision `1`. It starts with the unchanged FPV theme and Scout recipe. Existing procedural scenery is a placeholder: there are no new illustrated rewards, media descriptors, stories or music. Other classes remain legal recipes, but Scout-only proof will not qualify every class. Expert is not an implemented difficulty; only existing Standard and Gentle contexts are generated.

`buildFractureLines()` returns `{pack, scenarios, inputPins, topologyFacts}` through the real pack and Playground validators. Run this explicitly from the checkout root:

```sh
node authoring/library/fracture-lines/build.mjs --out .cache/fracture-example
```

The new ordinary cache directory contains one pack and three scenarios. Existing destinations and symlink ancestors are refused. No startup generation, installation, registry, runtime catalog, production-register seed, release or site build is included. The generic legacy level generator stays unchanged.

`layouts.json` owns finite authored recipes. `controls.mjs` is a bounded controller that reads the real run and issues cardinal/neutral inputs only; it never patches state. `verify.mjs` replays the resulting inputs and restores serialized sessions with explicit authored/execution identity, legacy picture pins and null stories. A captured cut stops; the controller releases before a fresh direction. Manual ability, supply pickup and Boost are disabled by `arcade-actions.v1`; visible Classic pickups still require direct contact. The current renderer's opaque black concealment is inherited unchanged.

The recorded matrix is 48 contexts: three maps × Standard/Gentle × Immediate/Grid + buffer × two alternative wins, one first-life-loss control and one recovered win. That is 24 ordinary wins, 12 first-life controls and 12 recovered wins. Six separately labeled Standard game-over probes exhaust all three lives. The full record contains 121,942 simulated ticks and 204 saved checks: 192 nonempty suffix resumptions and 12 exact recovery-endpoint restores. `routes.json` carries the actual legal inputs, compact replay/checkpoint hashes, exact owner pins and observed outcome for every context. Check it with `node authoring/library/fracture-lines/verify.mjs`; `--record` can create only an absent proof and never overwrite this record.

Both difficulties have their own verified inputs; they are not timing-scaled promises. Split Ring’s southern gate closes at 62.1%; its longer northern route reaches 68.9% Standard or 66.9% Gentle. Fault Fan compares the east-first frame with an upper bay approach and collects the existing freeze pickup. Frayed Causeway compares an upper crossing with a lower island approach, traverses slow ground, and records actual erosion plus recapture in both difficulties and steering policies. Its score checks count only newly claimed cells. Warning/commitment, capture-stop, recovery, erosion warning and recapture saves are included when those states actually occur. The Ring speed pickup and Causeway enemy-slow pickup are authored options; the main route record does not claim they were collected.

Per-route simulation is bounded to 21,600 ticks, individual waypoint/wait segments to 3,600 ticks. Search is an explicit cache experiment, one process with a finite wall-time/candidate budget; it is not part of the verifier or normal tests.
