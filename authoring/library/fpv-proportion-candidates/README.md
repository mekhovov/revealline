# Preserved rotor source candidates

This directory preserves the exact source candidates and historical author evidence
from `fb26b059798d7e15169d3ff9c7e4653d13384970`. The V2 manifest and its sixteen
native PNGs are dependencies of the later V3–V6 comparison and regression tools.

These files are **not registered production artwork**. The concept and body-study
PNGs are retained source evidence, not native sprites. Their original JSON records
retain the author's design-approval statements and known limitations; copying them
does not establish a new independent approval, rights review, visual acceptance or
runtime qualification.

The original [reference review](../../../docs/drone-reference-review.md) is
historical research. It includes links to separate review pages and reference-photo
inventories that are not all part of this bounded source intake. No third-party
reference-photo pixels were added by this intake. The existing production ledger,
compiled asset set, collision shapes and simulation bindings remain unchanged.

The four candidate producer scripts are preserved for reproducibility. Their
default mode writes candidate output, so use their read-only `--check` mode for
later qualification. Retaining the scripts and tests is not evidence that they
were executed as part of this intake.
