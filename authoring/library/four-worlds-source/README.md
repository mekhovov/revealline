# Four worlds: first twelve original reveal pictures

This catalogue keeps the first three new source illustrations for each theme together without adding them to a game pack. All twelve raw PNGs are unchanged image-generation outputs, each1774×887 (2:1). Original files, exact prompts, references, hashes and observed deviations remain in their four source directories.

The [source index](catalog.json) records original bytes and prompt identities. It is an authoring catalogue, not the runtime still-library or pack schema. The source files total33,295,435 bytes. No gameplay geometry, campaign identity, score or collected picture changes merely because these sources exist.

The pictures were visually inspected as whole images. They still need per-map assignment, partial-reveal tests, actor/trail contrast checks on small screens, any requested image-tool refinements and explicit content packaging. The harbor has invented leaf emblems on cargo; these are not Coupa marks or a claimed Navi likeness. Ukrainian motifs and invented settlements are documented as interpretations rather than exact historical reconstructions. Static illustrations contain no independently animated objects.

Use the existing [source-media CLI](../../media/README.md) for byte-preserving original import and the [still presentation contract](../../../docs/media-presentation.md) for future exact map/theme ownership. Keep originals outside automatic runtime downloads. Use the image-generation tool for deliberate visual revisions, record the parent/output and effective prompt, and preserve the earlier file. Never use a pack build to resize or overwrite accepted art.
