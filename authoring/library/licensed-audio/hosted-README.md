# Direct hosted licensed music metadata

`hosted-publication.json` is the code-owned input for making the existing 70 creator recordings selectable in the game without including their 354,986,122 MP3 bytes in the game build. Its format is `revealline-hosted-licensed-publication.v1`. The project owner explicitly authorized this direct in-game inclusion. This new authorization is distinct from the earlier preview-only authorization, which remains unchanged.

Every `tracks` row retains the original creator recording `id`, album membership, exact production-register `asset`, title, artist, preserved filename, source/license URLs, credit, changes, conversion lineage, hash-bound policy and existing genre tags. Websites retain the register's entries and add the published preview's required artist attribution URL where it was absent; this adds nine Zander Noriega attribution entries. `archivePath` is exactly `objects/<asset.sha256>.mp3`. The compiler maps an original ID of at most 64 characters to `builtin.catalog.<id>`. Longer IDs use their first 47 characters, a hyphen, and the first 16 hexadecimal characters of the original ID's SHA-256 after the same prefix, staying within the runtime's 80-character identity limit. `policy.id` and collection references use that same mapping. The compiler must preserve the recording hash binding and use only the declared archive inventory; imported or user-editable URLs do not become authority.

`collections` retains the 15 public album IDs, titles and ordered original recording IDs. Each uses shuffle/repeat-all. The compiler maps collection IDs to `builtin.album.<id>` and recording references through the same runtime mapping. `download` describes the separately published native `.rlsound` file; it is provenance and a manual-download destination, not a game-build audio requirement. Collection titles still include any existing “Preview” suffix.

`listeningApproval` is false, every track's `listeningStatus` is `pending`, and Content ID remains `unknown`. Existing role and energy classifications are preserved rather than inferred from a new audition: 66 roles are `any`, four `gameplay`; energies are 62×3, 6×4 and 2×5. The pinned production register retains each classification's basis. This metadata does not admit private UA-FPV files or AI original candidates, certify musical quality, change loudness, or claim full listening/loop/mix acceptance.

The three `hosted-*.json` source snapshots preserve the public preview catalogue, archive inventory and 15-album release manifest byte-for-byte. Fresh HTTPS metadata responses matched those retained bytes on 2026-09-21; no MP3 was requested. `hosted-evidence.json` records their URLs, lengths and SHA-256 values, source/register/license evidence pins, the prior recording-rights audit and full public-audio hash audit. Original historical flags such as the preview catalogue's `gameCatalogueAdmission:false` describe that earlier publication and remain intact.

Compiler checks should fail closed on changed source pins, missing/extra IDs, duplicate hashes, mismatched MP3 facts or attribution, non-inventory archive paths, policy disagreement, unsupported licenses, or mismatched collection membership. Compiling these hosted entries must not require local MP3 originals or derivatives. Playback/offline downloads can subsequently verify the declared bytes and SHA-256 against the hosted objects. Offline storage remains bounded by the shared player profile's actual budget.
