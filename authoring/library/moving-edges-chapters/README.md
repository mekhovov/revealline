## Recording and replacing a reward

After source peer review and a coordinated CPU/disk admission, use the repository's pinned runtime. The first record requires all five generated descriptor/proof destinations to be absent; normal verification never overwrites them.

```sh
node authoring/library/moving-edges-chapters/verify.mjs --record
node --test authoring/library/moving-edges-chapters/test-chapters.mjs
# Later independent reproduction, only when needed:
node authoring/library/moving-edges-chapters/verify.mjs
```

For an explicit payload export, create the cache parent and choose a new destination:

```sh
mkdir -p .cache/moving-edges-pairs
node authoring/library/moving-edges-chapters/build.mjs ukraine .cache/moving-edges-pairs/ukraine
```

The other arguments are `fpv`, `retro` and `coupa`. Export produces `descriptor.json`, `pack.json`, `media.rlmedia` and `inputs.json`. Outputs stay outside tracked source; ordinary-path checks do not claim protection against hostile concurrent filesystem renames.
