# Illustrated Equipment Workshop sources

This source directory builds **Equipment Workshop 1.1.0** with two retained maps: Garden of Threads and Neon Switchboard. A successful builder check establishes source/embedding consistency and image-header validity; it does not establish browser decoding, composition quality or a verified release.

The [retained baseline](previous/equipment-workshop-1.0.0.json) is a **derived two-level selection**, not the original historical v1.0.0 distribution: **14,180 bytes**, SHA-256 `f6be571a46086ed78ce18178d90326456eb4ebd114baef5e127d7656cee77002`, recorded at source revision `48d775a7b16e02a4949ef30c68eee21f3c8a6bab`. [The projection receipt](../../../docs/migrations/retained-pack-source.json) records the changed source identities. Preserve this selected baseline byte-for-byte; do not format or regenerate it.

[pack-source.json](pack-source.json) changes only pack semver to `1.1.0` and retains empty generated `levelVisuals`. The builder enforces equality with the retained baseline apart from that semver. Image names/descriptions are presentation sidecars. The campaign identity is `equipment-workshop/1/7bbeedba8b221cf4`; an explicit progress migration accepts compatible retained-level progress from `equipment-workshop/1/3fc2cf073da368b4`. Removed levels do not reappear through old saves.

If regeneration or a derived variant is needed, preserve its parent and record the separate output, actual dimensions, tool route and visual review. Do not resize, crop, recolor, quantize or recompress these originals through the build script, Python, Node or an image CLI. Header/hash checks and the runtime's `contain` drawing preserve the embedded original bytes.

Each selected file must be a distinct regular PNG, at most 4 MiB, with measured **4:3** dimensions. All existing image/pack budgets still apply. The report records exact source hashes, dimensions, raw bytes, encoded characters, pixel totals, generated bytes and whether the pack meets the under-12-MiB art target. A distinct hash does not prove a distinct or attractive composition. Actual browser installation must fully decode both retained images and inspect masked play, complete rewards, reduced effects and gallery replay.

## Check or deliberately rebuild

Run from the repository root, using the repository's supported Node runtime:

```sh
node scripts/build-workshop-pack.mjs
node scripts/build-workshop-pack.mjs --write
node scripts/build-workshop-pack.mjs
node --test scripts/test-build-workshop-pack.mjs
```

The first/default command is **read-only** and reports missing or stale generated content. After reviewing the source and images, explicit `--write` atomically replaces only `game/content/packs/equipment-workshop.json`; it never writes the PNGs, provenance, baseline or source recipe. Invalid inputs leave the previous generated pack in place. A normal formatting-only change to generated JSON can pass the default semantic comparison; embedded image bytes must still match exactly. Only the optional `--write` CLI flag is accepted.

`buildWorkshopPack({root, write = false})` returns `{pack, report}` for trusted local tooling. The injectable root supports isolated tests. Fixed file paths, regular-directory/file checks, bounded reads and source comparisons prevent an image or output symlink from redirecting normal operations. This local builder is not a multiwriter authoring service; do not edit its selected sources during a build. The tests use temporary copies of these actual selected Workshop PNGs for exact embedding, filesystem and semantic rejection cases; they do not certify browser decoding. Header mutations exist only as rejected temporary metadata fixtures.

Keep the [Homeward builder](../../../scripts/build-homeward-pack.mjs), its source PNGs/generated pack and all existing replay proof bytes unchanged. Rebuilding the retained pictures needs no discovery or recording command. Runtime pack validation/build already discovers the same indexed Workshop path. Follow [authored art](../../../docs/authored-art.md) for public pack import/export and [the Workshop guide](../../../docs/equipment-workshop.md) for its established equipment routes. Returning collected pictures deliberately resolve to the currently installed art edition; installing art does not itself award another clear, score or seal.
