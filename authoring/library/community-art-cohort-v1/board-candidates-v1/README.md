# Board derivatives — review candidates

Prepared through the actual Asset Studio native Canvas path in Chrome, then exported
and reimported as `ukrainian-pixel-scenes-r5.rlart`. No source original was edited.
The three wide candidates are 1152×576. Workshop classic is 768×576 with the entire
picture in a 768×384 rectangle at (0,96), preserving 4:3 board geometry with ink bars.
All four use nearest-pixel sampling from declared pixel-art sources, not stretching.

`collection.json` retains all seven file records and exact provenance. To import it
through Studio, choose this JSON and the four PNGs here **plus the three original
PNGs in the parent folder**. Do not import the older parent `collection.json` in the
same selection. Export preserves their bytes; regenerating through a different
browser is not guaranteed to produce identical PNG encoding.

See [byte and browser evidence](../../../../docs/verification/actor-batch-10/README.md).
These outputs require deliberate pixel-grid cleanup, native-size actor contrast,
cultural review and approved runtime bindings. In particular, the Poltava source's
shutters and beam details remain unresolved; this resizing does not correct them.
They are not published missions, approved DroneAid branding or production assets.
