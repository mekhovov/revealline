The Canva document was reviewed through its viewing UI: pages 2 (mark), 8 (type), 9 (colors), and 10 (photography). It specifies blue `#5b81fd`, yellow `#ffd601`, black `#0a0c0e`, and white; bright accents should be used with care and sufficient text contrast. Display type is Unbounded, alternative Kyiv Type Sans, body Inter. The game keeps the player's selected UI typography while presenting the official outlined wordmark unchanged. Photo guidance favors actual drones and community activity.

All downloaded files are exact originals. `sources.json` records Drive identities, original names and SHA-256 hashes without temporary download URLs.

The source named **DroneAid dark.svg** is the white-letter variant for dark backgrounds. It is copied to runtime `droneaid-wordmark-light.svg` (light lettering). No inversion, recoloring or path edits are applied. CSS frames its central logo, removing only the original export's empty surrounding space from the displayed viewport. Both SVG variants have no scripts or external asset references.

The background is a 2000×1545 PNG poster, **DroneAid Hamburg cover11.png**. Its real drone panels are framed with CSS; embedded promotional copy remains outside the live menu's visible artwork area. The runtime PNG is a byte-for-byte copy. There is no generated replacement or destructive crop. Existing one-time arrival and analog receiver effects remain; image-specific canal/cloud warping is disabled for this photograph.

Scope: the main `droneaid-nl-community` edition, publicly `?edition=droneaid`. Six campaign illustrations, the legacy DroneAid scene, compact logo/icon receipt assets, rewards and progression identities are unchanged.
