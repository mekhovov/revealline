# Wider Ukraine Atlas role candidates

Three fresh original bodies address the narrow Scout, Interceptor and Fiber silhouettes in the [preserved seven-role cohort](../ukraine-role-presentations/README.md). The round ivory swallow, cobalt chevron and coral barrel bobbin remain separate, independently replaceable source candidates. The other four roles and every v1 byte remain unchanged. This is not runtime adoption, a completed animation collection or production approval.

[Open the comparison preview](index.html) through a repository-root static server. It uses the unchanged shared `paintRole`, `playerPaintSize` and procedural wing renderer. Each row compares v1 and v3 at 128px inspection, fixed 20px and fixed 32px. Heading, light/dark backgrounds, wing visibility, four held flap phases, speed, pause and reduced motion are authoring controls. They do not simulate class abilities, collisions or gameplay.

The first three image edits widened the shapes but returned RGB8 with a painted checkerboard. One background-extraction edit per role also returned RGB8. All six failed outputs, their exact tool files and complete prompts remain recorded in the three [lineage records](provenance/scout.json); files ending `-v2-alpha.png` describe an attempted correction, **not actual alpha**. They are rejected as transparent body candidates.

The successful route generated three new originals without image input. These v3 files have RGBA8 headers and are **1254 × 1254**, despite requesting 1024 square. They are fresh works informed by the same design brief, not exact pixel-preserving edits. All default tool outputs are preserved without stripping metadata, cropping, stretching, resampling or code background removal. Colors and details vary as documented: Scout fills much of its frame, Interceptor uses brighter cobalt, and Fiber keeps a taller cap and an offset spool.

The [three records](variants.json) keep the existing 1.25-cell contained body and compact 20px policy. Each wing recipe is separate. Roots sit slightly inside the body shoulder bases; stronger midtone wing colors aim to remain visible on cream and dark backgrounds. The inherited conservative envelope check bounds the entire moving wing polygon inside the original frame. This is not a collider, an attachment-continuity measurement or proof of visual readability.

The verifier uses the unchanged full RGBA decoder for only the three fresh candidates. Rejected RGB attempts receive exact-byte/header checks and cannot become selected paths. Provenance records retain every prompt and image parent. `--tool-originals` additionally checks default tool-file copies; `--record PATH` writes only a new receipt.

Full CRC, scanline and alpha verification passed for all three selected originals, totaling 2,319,303 bytes. All nine default tool outputs match their preserved copies. The four new source-model cases passed on Node 22 and Node 20; the earlier seven-role tests were not repeated. Root accepted all three fresh originals as a source-art direction.

In the actual shared-painter study, the north-facing bodies span **16px Scout, 14px Interceptor and 15px Fiber** in a fixed 20px image frame, compared with 8px for each v1 body. The diagnostic counts pixels with alpha at least 128 and a brightest RGB channel of at least 80. At 32px, the body widths are 24, 24 and 25px. No original was stretched or cropped to achieve these spans.

The first wing study found an occluded Interceptor pose. Reducing only Scout and Interceptor's candidate fold amounts exposed their wings. The final sampled study covered four headings and four flap phases: all 144 combinations at 20, 32 and 128px had visible exterior wing pixels connected to the body through an eight-neighbor alpha-at-least-128 path. This is a finite raster diagnostic, not continuous animation, contrast or perceptual proof.
