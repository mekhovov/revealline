02 / ARTWORK

A place people recognize.

Assign registered originals to the home page and identity. Every media file carries its own byte count, hash and publication decision.

Install icons use a registered 512 pixel square derivative with its matching 192 pixel dependency. Fonts and icons travel with the selected brand’s declared assets. Media admission checks bytes and dependencies; it does not approve final artwork, trademark use or human playtesting.

Add or replace original media

Use Asset Studio, save the bytes in your source workspace, and update the catalog’s asset record. The compiler checks the actual bytes before a preview is admitted.
