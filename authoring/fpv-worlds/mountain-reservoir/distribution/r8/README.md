# Mountain Reservoir r8

Eight bilingual, land-side challenges in one original reservoir scene, with
sixteen optional demonstrations: every route in Self-level and Acro. This
download is external content for the FPV Worlds player. It does not replace or
enlarge the default 196-challenge, 14-world catalogue.
With only this optional world installed, the player has **204 authored
challenges across 15 worlds**. The remaining three D5 worlds are separate work.

- [Playable world pack](mountain-reservoir.r8.rlpack) — import through Library.
- [Editable project ZIP](mountain-reservoir.r8.zip) — import through the creator.
- [Sixteen demonstrations](mountain-reservoir.r8.proofs.json) — import after the
  exact playable pack; unavailable dependencies are never treated as verified.

When downloading from GitHub, use the file's raw download. Keep the files and
their hashes together. The public web deployment is not required to serve the
repository's `authoring/` tree. Preparing the simulator offline and installing a
world are separate actions; save both before disconnecting.

| Course                   | Focus                                                          |
| ------------------------ | -------------------------------------------------------------- |
| Shoreline check-in       | Shore lookouts and return to the launch pad                    |
| Western dam crest        | Climb before the solid dam and land on its cap                 |
| Intake controls          | Inspect the closed land-side station and land on its gallery   |
| Dry spillway descent     | Follow the supported concrete chute to its apron               |
| Exterior service passage | Low flight through the real gap outside the closed hut         |
| Rock terrace climb       | Rise before each shelf and land on the upper rock terrace      |
| Shoreline circuit        | Ordered scenic circuit on the land side of the inspection rail |
| Maintenance roof landing | Align above the closed hut before touching down on its roof    |

The current player assigns generic Explore / Intermediate / 4 min metadata to
all imported cards. These are not individual activity classifications or
measured durations; use the distinct course briefs above. Improving imported
card metadata requires a separate host change and does not alter this frozen
world or its recordings.

The yellow rail marks the lake-facing boundary. The reservoir and distant ridges
are scenery outside the shared flight area; this release offers no water
landing, buoyancy, island flight or simulated hydraulics. Painted doors/windows
are closed surfaces. Course geometry provides the actual solids.

All scene geometry and the single mineral texture are original CC0 work; see
[source license](../../source/LICENSE.md). The source recipe, prepared GLB and
all sixteen demonstrations are reproducible with the pinned repository tools.
See [qualification and retained failures](../../README.md).
The pack's authoring status records its generation checkpoint; this release
manifest and the pinned receipts record subsequent qualification without changing
the already verified pack identity.

This is a bounded original world increment. Actual functional and visual checks
do not imply commercial-art parity, physical-device performance or completion of
the broader world-art programme.
