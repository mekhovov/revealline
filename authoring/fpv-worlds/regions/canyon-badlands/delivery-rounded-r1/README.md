# Canyon arrival — rounded regional preview source

This immutable delivery preserves the accepted rounded terrain and grounded rock
composition. Its complete paired grid is **384 × 384 metres**, with nine cells per
layer and one authored basin starting point. The separate 768 m terrain study and
the rejected earlier drainage revisions are not included or replaced.

Original authored terrain surrounds 27 formations derived from the CC0 Canyon
Terrain Asset by loafbrr_1 / loafbrr. `source-provenance.json` preserves exact archive
and model hashes; `README-upstream.txt` preserves the source license notice. Its
references to Godot addons and an HDRI describe the upstream project; those files
are not runtime dependencies and are not shipped here.

Only `delivery.json` and its declared files are fetched by the player. Preparation,
provenance, licensing and verification receipts are review documents beside that
closure. All source/payload bytes remain unchanged.

## Verified and still required

The production regional downloader verifies all 39 responses. Source verification
recompiles 18 canonical GLBs, checks 2,247 corridor sweeps and 27 grounded/solid rock
formations. Production controlled flight traverses 14 routes in both modes without
contacts, and four deliberately obstructed flights hit the visible solids. The
complete receipts are included here and described in
`docs/fpv-canyon-commanded-delivery.md`.

This commit does not add a default Library row. Exact normal-player download,
storage/reload, presentation, flight/recovery and package checks remain admission
gates. This is a stylized, bounded source preview, not a finished realistic region,
an 8 km map, device-FPS evidence or a long-session/offline acceptance claim.
