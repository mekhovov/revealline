# Lunar composition-r2: supported antenna and readable survey structures

The original mixed native review found two below-terrain cameras and an unconvincing table-like dish. The camera fix is separate. The geometry audit then confirmed that all four dish piers stopped roughly 1.7 m below its curved underside. This revision fixes that physical model gap, adds an open three-strut feed receiver, and assigns the original alloy palette to survey roofs and the dish. The existing source, generated composition-r1, frozen9151/9161 reviews and negative evidence are preserved.

Each pier top is resolved from actual shell triangles across its footprint, with a small deliberate overlap. An independent serialized-mesh verifier confirms all four grounded piers touch the shell across nine footprint samples each and the three feed struts meet the dish. It does not trust the generator's planned bounding boxes. The receiver is above the dish; existing under-dish and exterior flight corridors remain open. A new Dish supports camera and an adjusted Survey dish target expose both the real connections and receiver silhouette.

All 72 terrain payload files, all six spawn poses and the grid match composition-r1 byte for byte. Only manifest revision metadata changes for the matching pair. The added solids are compiled into the same canonical render/collision triangles; there are no invisible proxies or shader-created openings. No physics changes.

Verification: 57 GLBs have zero validator errors/warnings; 2,724 local-route sweeps and seven connecting routes pass. The 24 local and14 connecting commanded flights run both self-level and Acro through the actual shared production authority, with zero route contacts. Intentional ground/roof contact, paused-input and disposal scenarios remain valid. Peak charged geometry is561,576 bytes; retained plus staged1,123,152 bytes stays below8 MiB. All117 regenerated files are deterministic. All13 camera sightlines pass the bounded exact-terrain clearance check.

The optional Lunar regolith/survey-material implementation is a separate PR; it is not bundled into this source revision. A combined native source review is still required before source acceptance or any immutable delivery/Library admission. This remains a sparse, fictional768 m composition with terrestrial flight physics, not finished lunar art, low gravity, vacuum simulation, an8 km world or proven hours-long gameplay.

Reproduce source generation in a new output folder, then run `verify-preparation.mjs`, `verify-commanded-flight.mjs`, and `verify-supports.mjs NEW_SOURCE OLD_R1_SOURCE`. `prepare-connections.mjs` emits the separate seven-link scenario for the same clearance and commanded-flight verifiers. `verify-cameras.mjs` checks the13 review viewpoints. Exact receipts are stored beside these tools.
