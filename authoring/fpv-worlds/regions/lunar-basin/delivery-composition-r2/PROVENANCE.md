# Original Lunar source

Terrain, rock formations and survey structures were authored for this project. No third-party model, texture, geographic dataset or simulator scene is included. The reference links in the provenance file informed the fictional design only; no NASA or LPI data, imagery or logos are bundled.

The immutable payload preserves composition-r2, its six start poses and all source hashes. Material profiles are independent runtime features and are not serialized as untrusted delivery hints. This is an early 768 m study with terrestrial drone physics. It is not surveyed lunar terrain, finished representative art or player admission.
